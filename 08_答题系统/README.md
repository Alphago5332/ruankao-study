# 08_答题系统 · 填空专练

> 从知识点清单抽取高频必考点 → 填空题型 → 即时判分 → 错题自动入库 → 答对自动进入下一题

## 目录

- [`index.html`](index.html) — 答题系统主页（直接浏览器打开）
- [`题库.json`](题库.json) — 填空题题库（与 HTML 内嵌同步，便于版本管理）
- [`../tools/audit_bank.js`](../tools/audit_bank.js) — **题库体检脚本**（查重 / 查键冲突 / 查答案分布）

## 核心特性

| 特性 | 说明 |
|---|---|
| **填空题型** | 题干中 `____` 处为可填 input，单空/多空/并列空都支持 |
| **即时判分** | 填完按 Enter 或点「提交」；宽松匹配（忽略空格、标点、大小写） |
| **答对自动下一题** | 答对延迟 1.2s 自动跳下一题；答错显示「跳过 / 下一题」 |
| **错题本** | 答错的自动收录，底部可点直接重做；支持导出为 .md |
| **进度联动** | 自动检测 `1.x_知识点清单_可勾选.html` 的勾选状态；答对题目后将自动同步勾选 |
| **章节隔离** | 章节 tab 切换；进度统计按章节展示 |
| **持久化** | 全部状态存 localStorage，刷新/重启浏览器不丢失 |

## 出题策略

按优先级：
1. **未答对 + 答错过**（最高优先级，先扫盲）
2. **未答过**（新题）
3. **全部答对**（随机复习）

## ⚠️ 已知跨库重复（2026-09-16 全量体检）

**答题系统的填空题与各节 `*_考点自测题.html` 的选择题存在系统性考点重叠**，阈值 0.45 下命中 **33 组**：

| 节 | 命中 | 说明 |
|---|---|---|
| 1.3 现代化创新发展 | **12** | 12 题**全部**与该节自测题同考点，最严重 |
| 1.4 数字中国 | 6 | 含 1.4-B1 与自测题 Q10 **近乎逐字相同（90%）** |
| 1.5 数字化转型与元宇宙 | 5 | 含 1.5-A3 / 1.5-A1 与自测题 Q4 / Q1 高度重合（88% / 85%） |
| 1.2 现代化基础设施 | 4 | 1.2-D1 / 1.2-B3 / 1.2-B1 / 1.2-B2 |
| 2.1 信息技术及其发展 | 2 | 2.1-A1（68%）、2.1-B3（54%） |
| 1.1 信息与信息化 | 1 | 1.1-C1 与自测题 Q10（53%） |

**成因**：给某节补答题系统题库时，是从**同一份必考清单**里挑点出题，而该节自测题（22 题）已覆盖了清单全部必考点 → 两边必然撞。**最严重的一批是「近乎逐字重复」**（≥0.85，7 组），做完自测题再进答题系统等于把答案默写一遍，失去检验价值。

### ⚠️ 工具的局限：D 段只抓「文字像」，抓不到「考点同」

题干相似度是**下界**。人工按考点逐题比对 1.4，实际重合度高得多 —— 答题系统 1.4 的 12 题里 **10 题**与该节自测题同考点：

| A2 数字经济本质（技术经济范式） | Q1 继农业/工业经济之后 | ⚠️ 同题干的另半句 |
| A3 统计分类 5 类·第 5 类归属 | Q3 同 | ❌ 同考点 |
| A4 数据价值化三化（资本化） | Q7 资源化 / Q8 资本化两方式 | ❌ 同考点族 |
| B1 数字政府着力点 | Q10 同（**程度 90%**） | ❌ 近乎逐字 |
| B2 数字政府五特征「协云智数动」 | Q11 反向考「不属于的特征」 | ❌ 同考点 |

**1.4 实际只有 2 题（A1、D2）是自测题没覆盖的新考点**。也就是说：1.4 这节的答题系统题，学完自测题之后基本只剩「重复默写」的价值。

**待决**：是否要把答题系统彻底改成「只考该节自测题未覆盖的考点」（纯增量复习）。处理前先保留原题，避免误伤已积累的错题本记录。


## 已知非缺陷（跑体检时会以「参考项」出现）

| 现象 | 为什么不是问题 |
|---|---|
| 多条题挂同一个清单键（如 1.3-B2/B3/B4 都挂 `B3`） | 一条清单条目常含多个命题点（如「两化融合四方面」含业务/产品/产业衍生三个侧面），各出一题正是为了**分侧面验证**；答对任一条即勾选该条目，重复勾选是**幂等**的 |
| 同一答案出现 2 次（如「网络」出现在 1.2-B6 与 2.1-B2） | 考点不同（工业互联网「网络化协同」vs ARP/RARP 的**网络层**归属），只是答案字面相同 |

真正的**重复题**（同题干 + 同答案）为 0 —— 2026-09-16 全量体检结论。

## 与可勾选 HTML 的联动机制

启动后扫描 localStorage 中所有形如 `01_教材笔记/.../知识点清单.md:L行号` 的 key（这是 `1.x_知识点清单_可勾选.html` 写入的命名空间）。

| 检测到 | 顶部面板 |
|---|---|
| 有勾选数据 | 🔗 已检测到 N 个清单，M 项已掌握。答对自动同步。 |
| 无勾选数据 | ⚠ 未检测到。请先在 1.x 可勾选版打卡。 |

**v1 状态**：仅读取并展示，后续会扩展为「答对题目 → 自动同步勾选到对应章节」。

## 使用流程

1. **打开 `index.html`**（直接双击 / WorkBuddy 预览均可）
2. **选择章节**（1.1 / 1.2 / 全部）
3. **填空 → 提交**：判分即时反馈
4. **答对**：自动进入下一题
5. **答错**：显示正确答案 + 提示 + 出处；自动入错题本
6. **底部错题本**：点击任意错题可立即重做

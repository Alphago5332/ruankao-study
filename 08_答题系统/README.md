# 08_答题系统 · 填空专练

> 从知识点清单抽取高频必考点 → 填空题型 → 即时判分 → 错题自动入库 → 答对自动进入下一题

## 目录

- [`index.html`](index.html) — 答题系统主页（直接浏览器打开）
- [`题库.json`](题库.json) — 填空题题库（与 HTML 内嵌同步，便于版本管理）
- [`../tools/audit_bank.js`](../tools/audit_bank.js) — **题库体检脚本**（查重 / 查键冲突 / 查答案分布）

## 核心特性

| 特性 | 说明 |
|---|---|
| **填空题型** | 题干中 `____` 处为可填 input，单空/多空/并列空都支持 |
| **即时判分** | 填完按 Enter 或点「提交」；宽松匹配（忽略空格、标点、大小写） |
| **答对自动下一题** | 答对延迟 1.2s 自动跳下一题；答错显示「跳过 / 下一题」 |
| **错题本** | 答错的自动收录，底部可点直接重做；支持导出为 .md |
| **进度联动** | 自动检测 `1.x_知识点清单_可勾选.html` 的勾选状态；答对题目后将自动同步勾选 |
| **章节隔离** | 章节 tab 切换；进度统计按章节展示 |
| **持久化** | 全部状态存 localStorage，刷新/重启浏览器不丢失 |

## 出题策略

按优先级：
1. **未答对 + 答错过**（最高优先级，先扫盲）
2. **未答过**（新题）
3. **全部答对**（随机复习）

> C 段 近似重复扫描：Dice 二元组相似度，抓「同考点换说法」（参考项，模板句「下列不属于…」会假阳性）
> D 段 **跨库重复**：答题系统题 ≈ 该节自测题（同考点做了两遍 —— 这是真正值得处理的重复）
> 示例：`node tools/audit_bank.js 1.4 0.45`（只看 1.4、阈值降到 0.45）；退出码 0 = 干净，2 = 有待处理项。

> 🔁 **批量改题**：`node tools/patch_bank.js tools/patches/<补丁>.js` —— 按 id 替换 `QUESTION_BANK` 里**整行**的题目对象。补丁文件导出 `[ [旧id, 新整行文本(自带 8 空格缩进)], ... ]`。
> 为什么用脚本而不是直接编辑：① 桌面端会用旧缓冲区回写文件，同一文件多点手改容易被回滚；② 脚本会**顺手校验行尾逗号**（数组末元素不能带逗号、其余必须带）—— 这正是历史上「漏逗号导致整个 `<script>` 崩（`Unexpected token '{'`）」的那个坑；③ 一次读-改-写 + 立即 `chk_html` 最稳。
> ⚠️ 脚本内部的「是否数组末元素」判定必须用 `/^\s*\][,]?\s*$/` 匹配下一行 —— 数组收尾行是 `      ],`（末尾**带**逗号，因为后面还有下一节的 key），用 `/\]\s*$/` 会永远不匹配、导致全部误报。

## 跨库重复处理进度（2026-09-16）

**问题**：答题系统的填空题与各节 `*_考点自测题.html` 的选择题存在**系统性考点重叠**。全量体检（阈值 0.45，198 题参与比对）初始命中 **33 组**。

**成因**：给某节补答题系统题库时，是从**同一份必考清单**里挑点出题，而该节自测题（20~22 题）已覆盖该清单全部必考点 → 两边必然撞。最严重的一批是「近乎逐字重复」（≥0.85，7 组），做完自测题再进答题系统等于把答案默写一遍，失去检验价值。

**处理口径（用户 2026-09-16 确认）**：只清「**同一考点 + 同一问法**」的重复 → 重写为**不同角度**（反向错误项 / 内涵填空 / 名称·数值对照 / 层级·定位辨析）；**被重写的题换新 id（加 `b` 后缀）**，本地旧的对错记录自动失效、新题从头作答；**保留**「同考点但问法不同」的题。

## 与可勾选 HTML 的联动机制

启动后扫描 localStorage 中所有形如 `01_教材笔记/.../知识点清单.md:L行号` 的 key（这是 `1.x_知识点清单_可勾选.html` 写入的命名空间）。

| 检测到 | 顶部面板 |
|---|---|
| 有勾选数据 | 🔗 已检测到 N 个清单，M 项已掌握。答对自动同步。 |
| 无勾选数据 | ⚠ 未检测到。请先在 1.x 可勾选版打卡。 |

4. **答对**：自动进入下一题

6. **底部错题本**：点击任意错题可立即重做

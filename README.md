## 备考要点

- **刷题主力**：软考达人（免费无广告，PC + 小程序 + APP）
- **刷题优先级**：真题以 2023 下半年 ~ 2026 上半年为主；2019 年前为旧教材，仅作练手
- **论文重点**：2023 下第 2 批、2025 上均考了「绩效域」（第 4 版新增），须至少备 1 篇绩效域方向论文
- **报名须知**：2025 年起报名必须「国家网络身份认证 APP」扫码 + 人脸识别

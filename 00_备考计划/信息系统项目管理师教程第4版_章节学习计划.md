> **整体节奏**：8 个月备考中，本计划覆盖前 4 个月（打基础 + 强化阶段），后续转入真题 + 论文

## 一、第 4 版教材的"结构性变化"（与第 3 版对比）

先认清新版，才能分清主次：

| 变化点 | 第 4 版新增/强化 | 备考影响 |
|---|---|---|
| **绩效域（第 16 章）** | **全新章节**，PMBOK 第 7 版核心思想引入 | ⭕ 论文高频，2023 下第 2 批、2025 上都考过，必须备 1 篇 |
| **配置与变更管理（第 17 章）** | 从原"整体管理"中拆出独立 | ⭕ 上午 + 案例常考（配置库、变更控制流程） |
| **项目集 / 项目组合（第 18、19 章）** | 单独成章 | 上午选择 + 论文备选方向 |
| **战略 / 治理 / 流程（第 20–22 章）** | 新版加强组织级视角 | 案例题背景层必读 |
| **项目经理角色（第 23 章）** | 单独成章，含 PMI 人才三角 | 上午偶考 |
| **法律法规与标准（第 24 章）** | 合并 + 新增《数据安全法》《个保法》《密码法》 | ⭕ 上午选择题必考（近 3 年每年 2~3 题） |

| **IT 基础（第 1–3 章）** | 信息化、信息系统治理、信息技术发展（含 AI/区块链/隐私计算等） | ⭕ 上午占分 30%~40%，必须吃透 |

> **结论**：第 4 版 = "项目管理（核心）+ IT 治理（新版强化）+ 法规（新版重点）"。
> 不要再用第 3 版的旧资料来对照！尤其绩效域、配置变更、数据安全法。

## 二、学习总目标（学完能干什么）

学完这本教材，你要能在考场上：

1. **综合知识（上午 75 题）**：90 分钟内稳定 50+ 分，对项目管理、IT 基础、法规三大板块的"看到关键词就能选"条件反射。
2. **案例分析（下午主观）**：能在 90 分钟内识别题型（计算题/找错纠偏/纯理论），写出"判卷人能踩点"的标准化答案。
3. **论文（下午 2 选 1）**：20 分钟审题 + 60 分钟写 2000~2500 字，能把项目素材（fault-simulator / H3C-NMS）套进任何十大知识域 + 绩效域方向。
4. **知识框架**：能从一张白纸默写出 **5 大过程组 × 10 大知识域 × 8 大绩效域** 的对应关系图。

## 三、学习方法论（贯穿全书）

### 1. 三轮阅读法（每章适用）

| 轮次 | 目标 | 方法 | 时长占比 |
|---|---|---|---|
| **通读（1 遍）** | 建框架、知术语 | 看目录、读小标题、扫正文，跳过细节 | 30% |
| **精读（2 遍）** | 抓考点、画重点 | 配合视频课、做笔记、画思维导图 | 50% |
| **刷题（2 遍）** | 验理解、记常考 | 软考达人/章节题、错题本 | 20% |

### 2. 笔记法：康奈尔 5 区笔记

每章一页笔记：
- **线索栏（左 1/3）**：写问题（如"挣值分析 EV/EAC 公式？"）
- **笔记区（右 2/3）**：写答案 + 关键定义
- **总结区（底部 5 行）**：写"本章一句话总结 + 案例应用方向"

### 3. 艾宾浩斯复习节奏

| 学习时间 | 当天 | +1 天 | +3 天 | +7 天 | +14 天 |
|---|---|---|---|---|---|
| 第 1 周 | 学新章 | 复习旧章 | — | — | — |
| 第 2 周 | 学新章 | 复习 2 周前 | 复习上周 | — | — |
| 第 3 周起 | 每周固定 30 分钟复盘前 2 周重点 | | | | |
| **冲刺阶段** | **2 天 1 轮全章节复盘** | | | | |

### 4. 错题本格式

每题记 4 项：
- 题目考点（如"配置项变更流程"）
- 错选选项 + 为什么错
- 正选 + 出处（页码）
- 关联知识点（与哪些章节相连）

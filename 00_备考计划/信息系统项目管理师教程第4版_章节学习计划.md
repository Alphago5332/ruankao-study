## 二、学习总目标（学完能干什么）

学完这本教材，你要能在考场上：

1. **综合知识（上午 75 题）**：90 分钟内稳定 50+ 分，对项目管理、IT 基础、法规三大板块「看到关键词就能选」。
2. **案例分析（下午主观）**：90 分钟内识别题型（计算题 / 找错纠偏 / 纯理论），写出「判卷人能踩点」的标准化答案。
3. **论文（下午 2 选 1）**：20 分钟审题 + 60 分钟写 2000~2500 字，能把项目素材（fault-simulator / H3C-NMS）套进任一知识域 + 绩效域方向。
4. **知识框架**：能从一张白纸默写出 **5 大过程组 × 10 大知识域 × 8 大绩效域** 的对应关系图。

## 三、学习方法论（贯穿全书）

### 1. 三轮阅读法（每章适用）

| 轮次 | 目标 | 方法 | 时长占比 |
|---|---|---|---|
| **通读** | 建框架、知术语 | 看目录、读小标题、扫正文，跳过细节 | 30% |
| **精读** | 抓考点、画重点 | 配合视频课、做笔记、画思维导图 | 50% |
| **刷题** | 验理解、记常考 | 软考达人章节题、错题本 | 20% |

### 2. 笔记法：康奈尔 5 区笔记

每章一页笔记：
- **线索栏（左 1/3）**：写问题（如「挣值分析 EV / EAC 公式？」）
- **笔记区（右 2/3）**：写答案 + 关键定义
- **总结区（底部 5 行）**：写「本章一句话总结 + 案例应用方向」

### 3. 艾宾浩斯复习节奏

| 学习时间 | 当天 | +1 天 | +3 天 | +7 天 | +14 天 |
|---|---|---|---|---|---|
| 第 1 周 | 学新章 | 复习旧章 | — | — | — |
| 第 2 周 | 学新章 | 复习 2 周前 | 复习上周 | — | — |
| 第 3 周起 | 每周固定 30 分钟复盘前 2 周重点 | | | | |
| **冲刺阶段** | **2 天 1 轮全章节复盘** | | | | |

### 4. 错题本格式

每题记 4 项：题目考点 / 错选选项 + 为什么错 / 正选 + 出处（页码）/ 关联知识点。

## 十、特别提醒（针对你这种非科班 + 真实项目背景）

1. **不要被第 1~5 章劝退**：作为智能体开发工程师，你对 AI / Kafka / 网络 / 安全有基础认知，这 5 章应该是「确认已知 + 补漏」，不需要死背。
2. **你的论文素材是黄金资源**：fault-simulator、H3C-NMS 都是天然的「项目管理案例」。**学完第 6、8、9、10 章后立刻动笔写一段项目背景**，考试时直接套用。
3. **绩效域论文（W9）必须完成**：这是新版红利，你在前沿 AI 领域工作，「团队绩效域」或「不确定性绩效域」对你最契合。
4. **法规章节（W12）别只靠刷题**：用表格速记法，一次性背完数据安全法 / 著作权法 / 招标投标法核心条款。
5. **计算题（W5、W6、W11）是成败关键**：高项考生挂在案例的 80% 都是计算题失分。每天 2~3 道，连续 2 周必有手感。
6. **第 20~23 章不要恋战**：这四章合计约 6~8 分，通读扫盲即可，时间要留给第 10、11、15、18 章。

## 口径备忘（2026-09-21 核对）

### 3.1 口径（清华社样章 PDF + 三方交叉核对）

- 核对方式：3.1.1、3.1.2 主体（含图 3-1 / 3-2、表 3-1、图 3-3）以**清华社样章 PDF 逐字原文**为准；核心内容后半、3.1.3、3.1.4 由**信管网第 4 版大纲考点 + 科科过教材原文连载 + 搜狐考情解析**三方交叉核对
- 3.1 四处高危误记已修正：
  1. **官方小节结构是 3.1.1~3.1.4**（部分机构讲义漏掉 3.1.4「IT治理方法与标准」，或把 COBIT / ITSS / 38500 并进别的节）
  2. **两套四词别混**：治理流程 / 作用 =「统筹、评估、指导、监督」；治理活动定义 =「统筹、指导、监督、改进」
  3. **ISO/IEC 38500 六原则是「收购」**（不是「采购 / 获取」）、是「一致性」（不是「合规」）
  4. **COBIT 的 EDM 是治理领域**（董事会 + 执行管理层负责）；APO / BAI / DSS / MEA 是管理领域（高级和中级管理层负责）
- 第 3 章为**第 4 版新增章**：2023 上及以前的旧真题没有对应题，练题以 2024 以后回忆题 + 教辅章节题为主

### 3.2 口径（2026-09-22 四方交叉核对）

- 核对方式：样章 PDF 不含 3.2 正文；以**信管网第 4 版教材直播课讲义**（含审计风险四类逐字定义、审计内容表格）+ **爱企查第 4 版知识摘编** + **希赛 / 环球真题解析**（解析标注教材 3.2.x 页码）+ **CSDN 逐章手敲笔记**四方交叉核对，口径一致
- 3.2 高危误记已修正：
  1. **GB/T 34690.4 = 审计导则**（勿与 3.1 的 GB/T 34960 治理系列混）：IT 审计定义与「审计人员要求」都出自 34690.4
  2. **审计目的的落点 = 促进组织实现 IT 目标**；「保护信息资产安全」是 IT 目标不是审计目的
  3. **方法六法 ≠ 技术四类**：抽样 / 计算机辅助 / 大数据是技术；方法 = 访调检观试码
  4. **符合性 / 实质性测试只在实施阶段**；后续审计「不是一次新的审计」
  5. **数据三性「完整可靠有效」vs 系统三性「安全可靠有效」**修饰对象不同

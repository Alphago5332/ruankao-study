## 易混防坑

1. **GB/T 34960（治理）vs GB/T 34690.4（审计导则）**——两个国标号只差一位数，审计定义和「审计人员要求」都出自 34690.4
2. **「保护信息资产的安全」是 IT 目标不是审计目的**——审计目的的落点是「促进组织实现 IT 目标」
3. **数据三性「完整可靠有效」vs 系统三性「安全可靠有效」**——修饰对象不同，对调即错
4. **固有风险 = 没控制就出错（活动自带）**；**控制风险 = 内控没拦住（与审计无关）**；**检查风险 = 审计没查出（可由审计方调控）**；**总体审计风险 = 单个控制目标的各类风险总和**——四选一题干有「内部控制」选控制、有「活动本身」选固有、有「预定程序未发现」选检查
5. **方法六法 vs 技术四类**：抽样 / 计算机辅助 / 大数据是技术；方法里没有抽样法、穿行法、复核法
6. **属性抽样（频率估计，有多少）vs 变量抽样（金额估计，值多少）**——别把「金额」配给属性抽样
7. **符合性测试 / 实质性测试只在实施阶段**；「发出审计通知书」是准备阶段的终点；「归档管理」在终结阶段
8. **后续审计不是一次新的审计**，是前一次审计的有机组成部分——判断题常客
9. **审计底稿三级复核** = 审计机构负责人 → 部门负责人 → 项目负责人（或项目经理），由大到小；归档后由**档案管理部门**管理
10. **内控三层别串**：组织层面看治理管理事项（战略 / 架构 / 外包 / 监督…）、一般控制看系统平台策略（应用系统 / 数据库 / 操作系统 / 网络）、应用控制看业务流程的输入 / 处理 / 输出
11. **「得到控制、监督并遵循最佳实践要求的合理保证」**是**信息系统项目审计**的专属定位句
12. 本章旧真题无存货（第 4 版新增章），练题以本节自测题 + 2024 以后回忆题 + 教辅章节题为主

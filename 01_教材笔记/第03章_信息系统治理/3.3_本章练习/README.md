## 章节重点（整章收束）

第 3 章是**第 4 版新增重点章（综合知识约 3~4 分，考频持续上升）**，特点：

- **全部是选择题考点**：无计算、无案例论文主线；题型只有三类——**框架归属 / 标准归属 / 职责层次**
- **旧真题零覆盖**：2023 上及以前无对应题，只能靠教材口径 + 本仓题库
- **两个标准别混**：GB/T **34960** = 治理系列（3.1）；GB/T **34690.4** = 审计导则（3.2）

**整章最容易丢分的 8 处**（考前只看这一块）：

1. **治理活动定义「统筹、指导、监督、改进」≠ 治理流程「统筹、评估、指导、监督」**——一个含「改进」、一个含「评估」，本节最高频对调陷阱
2. **COBIT 的 EDM 是治理领域**（董事会 + 执行管理层）；APO / BAI / DSS / MEA 是管理领域（高级和中级管理层）
3. **ISO/IEC 38500 三任务 = 评估、指导、监督**；六原则 =「责战收性一人」（是「收购」不是「采购」，是「一致性」不是「合规」）
4. **GB/T 34960.1 三大治理域 = 顶层设计、管理体系、资源**（口诀「顶管资」）
5. **审计风险三分类对号**：固有（无控制时易错）/ 控制（内控体系没拦住）/ 检查（审计程序没发现）
6. **方法六法 ≠ 技术四类**：方法 = 访调检观试码（含程序代码检查法）；抽样 / 计算机辅助 / 大数据是技术
7. **ISO/IEC 38500 不是审计准则**——它是 3.1 的治理标准，出现在 3.2 准则清单里就是调包项
8. **审计四阶段顺序**：准备 → 实施 → 终结 → 后续；后续审计「不是一次新的审计」；符合性 / 实质性测试只在实施阶段

> - **「IT 原则」= 组织高层关于如何使用 IT 的陈述**（不是「IT 架构」——架构是数据 / 应用 / 基础设施的逻辑，标准化一体化）

> - **COBIT**：EDM（评估指导监控）是**治理**领域，董事会和执行管理层负责；APO / BAI / DSS / MEA 是**管理**领域，高级和中级管理层负责
> - **ISO/IEC 38500**：2008 年 4 月发布；六原则「责任、战略、收购、性能、一致性、人的行为」（「收购」不是「采购」，「一致性」不是「合规」）；三任务「评估、指导、监督」

## 易混防坑

1. **「统筹·评估·指导·监督」（治理流程 / 作用）vs「统筹·指导·监督·改进」（治理活动）**——评估 / 改进一字之差，年年有人混
2. **价值交付 = 创造业务价值；风险管理 = 保护业务价值**——固定配对别对调
3. **「组织高层关于如何使用 IT 的陈述」= IT 原则**；「数据、应用和基础设施的逻辑」= IT 架构
4. **驱动链条方向**：原则驱动架构 → 架构决定基础设施 → 基础设施能力决定应用 → 投资被以上全部驱动（不是反过来）
5. **治理域 = 计划、构建、运维与监控**；「统筹、评估、指导、监督」是治理流程，「评估、指导、监督」是 38500 三任务——三套四词 / 三词各归各位
6. 「对 IT 治理效率起**决定性作用**」的是 **IT 治理组织**（治理机构设置与权限划分）
7. 最高管理层职责动词是「**证实 · 证实 · 指导 · 指导**」；「IT 需求的提出和响应」在**业务与服务执行层**
8. **COBIT 的 EDM 是治理领域**（董事会 + 执行管理层），APO / BAI / DSS / MEA 是管理领域（高级和中级管理层）——四选一题最爱把负责者对调
9. ISO/IEC 38500 六原则里是「**收购**」（Acquisition），不是「采购 / 获取」；三任务是「评估、指导、监督」
10. GB/T 34960.**1 = 通用要求**（模型和框架 / 原则 / 三域治理要求）、34960.**2 = 实施指南**（实施框架 / 环境 / 过程）——编号别接反
11. 「评审 IT 管理体系的**适宜性、充分性和有效性**」挂在**机制保障**任务下
12. 本章旧真题无存货（第 4 版新增章），练题以本节自测题 + 2024 以后回忆题 + 教辅章节题为主

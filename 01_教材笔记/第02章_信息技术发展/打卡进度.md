## 口径备忘（2026-09-15 ~ 2026-09-16 核对）

### 2.1 口径（清华社官方样章 PDF）

- 核对方式：清华社官网样章 PDF `https://www.tup.com.cn/upload/books/yz/099830-02.pdf`（含 2.1.1 / 2.1.2 完整正文）
- 该 PDF 文字层为 CJK 无 ToUnicode 映射，`pypdf` 提取会乱码，**必须用 `pymupdf`（`import pymupdf`）提取**
- 2.1 三处常见误记已修正：① 2.1.1 **没有**「五大部件」；② OSI 是「从下到上」；③ **DAS 与 NAS/SAN 不在同一层级**（中间隔一层「网络化存储 FAS」）

### 2.2 口径（三方交叉核对，样章 PDF 不覆盖）

- ⚠️ **样章 PDF 只覆盖到 2.1.2**，2.1.3~2.1.5 与**整个 2.2 节都不在样章内**
- 2.2 口径由**信管网「第 4 版大纲考点」+ 科科过 / 51CTO「教材原文」连载 + 腾讯云「陪你读懂」连载**三处交叉核对后确定
- 2.2 四处高危误记已修正：
  1. **教材没有「4V」这个说法**——2.2.3 用的是「数据海量 / 数据类型多样 / 数据价值密度低 / 数据处理速度快」四条中文表述；业界 4V 中的「真实性」不在教材里
  2. **区块链是「四大类」**（公有链 / 联盟链 / 私有链 / **混合链**），不是三类；且教材用词是「**多中心化**」而非「去中心化」，数据结构叫「**改进的默克尔树**」
  3. **虚拟现实主要特征是 5 条**（沉浸性 / 交互性 / **多感知性** / 构想性 / **自主性**），业界常说的「VR 三特征（3I）」教材不采用
  4. **教材 2.2.2 正文没有「公有云 / 私有云 / 混合云 / 社区云」部署模式段落**（属中级教材与业界口径），不要用它覆盖教材的「三种服务类型」

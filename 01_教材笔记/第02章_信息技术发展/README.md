# 第 2 章 信息技术发展

> 《信息系统项目管理师教程（第 4 版）》第 2 章学习笔记

**考情定位**：**上午卷最大分值块（6~12 题）**，是当前备考阶段性价比最高的章节。全部落在上午选择题，**不考案例、不考论文**；题型固定为三类——术语 / 协议的**层级归属**、分类与顺序的**排序**、特征与定义的**匹配**。涵盖计算机软硬件、计算机网络（OSI / TCP-IP / SDN / 5G）、存储与数据库（DAS/NAS/SAN、数据仓库）、信息安全，以及新一代信息技术（物联网 / 云计算 / 大数据 / 区块链 / 人工智能 / 虚拟现实）。

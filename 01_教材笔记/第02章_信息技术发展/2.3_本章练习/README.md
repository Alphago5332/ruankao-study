## 章节重点（整章收束）

第 2 章是**上午卷最大分值块（6~12 题）**，也是**当前备考阶段性价比最高的一章**：

- **全部落在上午选择题**：不考案例、不考论文
- **题型只有三类**：术语 / 协议的**层级归属**、分类与顺序的**排序**、特征与定义的**匹配**
- **唯一需要算的**：数据量单位换算（**1PB = 1024TB · 1EB = 1024PB · 1ZB = 1024EB**）
- **没有推理空间**：会就是会、不会就是不会——**唯一办法是把表格默写到条件反射**

**整章最容易丢分的 8 处**（考前只看这一块）：

1. **ARP / RARP 属网络层**（不是应用层）——2.1.2 最高频陷阱
2. **OSI 教材原文是「从下到上」**；广域网协议在**最下面三层**
3. **DAS 与 NAS/SAN 不在同一层级**（中间隔「网络化存储 FAS」）；NAS 传文件、SAN 传数据块
4. **数据仓库「基础＝数据源 / 核心＝数据的存储与管理」**别对调
5. **教材没有「4V」**——四条中文特征＝数据海量 / 类型多样 / 价值密度低 / 处理速度快
6. **IaaS / PaaS / SaaS 三个反向陷阱**（在线办公＝SaaS、虚拟机＝IaaS、云数据库＝PaaS）
7. **区块链是「四大类」含混合链**、用的是「**多中心化**」；**VR 是 5 条特征**（不是 3I）
8. **RFID 属传感器技术**、**容器属操作系统虚拟化**、**「软件定义一切」属软件 /「可信计算」属信息安全**

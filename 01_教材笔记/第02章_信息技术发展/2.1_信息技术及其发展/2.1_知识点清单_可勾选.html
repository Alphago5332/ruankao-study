一、必背清单

模块 A ｜ 信息技术总论 + 计算机软硬件（2.1 / 2.1.1）

信息技术是以微电子学为基础的计算机技术和电信技术的结合而形成的，对声音的、图像的、文字的、数字的和各种传感信号的信息进行获取、加工、处理、存储、传播和使用的技术。信息技术是实现信息化的手段，是信息系统建设的基础。

按表现形态的不同，信息技术可分为硬技术（物化技术）与软技术（非物化技术）：

形态别称含义举例
硬技术物化技术各种信息设备及其功能传感器、服务器、智能手机、通信卫星、笔记本电脑
软技术非物化技术有关信息获取与处理的各种知识、方法与技能语言文字技术、数据统计分析技术、规划决策技术、计算机软件技术
记法：硬 = 物化（能拿在手上的设备）；软 = 非物化（知识 / 方法 / 技能）

计算机硬件（Computer Hardware）是指计算机系统中由电子、机械和光电元件等组成的各种物理装置的总称；这些物理装置按系统结构的要求构成一个有机整体，为计算机软件运行提供物质基础。

⚠️ 第 4 版 2.1.1 只有两段（硬件定义 + 软硬件关系），没有「运算器 / 控制器 / 存储器 / 输入设备 / 输出设备五大部件」的展开——那是计算机硬件基础类教材的通用口径，别当本节考点背

计算机软件（Computer Software）是指计算机系统中的程序及其文档：

• 程序：是计算任务的处理对象和处理规则的描述；必须安装入机器内部才能工作
• 文档：是为了便于了解程序所需的阐明性资料；一般是给人看的，不一定安装入机器
判别口诀：程序进机器，文档给人看
• 互相依存：硬件是软件赖以工作的物质基础；软件的正常工作是硬件发挥作用的重要途径
• 协同发展：计算机软件随硬件技术的迅速发展而发展，而软件的不断发展与完善又促进硬件的更新，两者密切交织发展，缺一不可
• 计算机系统必须配备完善的软件系统才能正常工作，从而充分发挥其硬件的各种功能
• ⚠️ 结论句（最爱出判断题）：在许多情况下，计算机的某些功能既可以由硬件实现，也可以由软件来实现；因此硬件与软件在一定意义上来说没有绝对严格的界线

模块 B ｜ 计算机网络（2.1.2 · 本节最高频考点）

在计算机领域中，网络就是用物理链路将各个孤立的工作站或主机相连在一起，组成数据链路，从而达到资源共享和通信的目的。凡将地理位置不同、并具有独立功能的多个计算机系统通过通信设备和线路连接起来，且以功能完善的网络软件（网络协议、信息交换方式及网络操作系统等）实现网络资源共享的系统，均可称为计算机网络。

三要素：地理位置不同 + 具有独立功能 + 通过通信设备和线路连接（有网络软件）

六类：个人局域网（PAN）· 局域网（LAN）· 城域网（MAN）· 广域网（WAN）· 公用网（Public Network）· 专用网（Private Network）。

分组记忆：作用范围四项（PAN < LAN < MAN < WAN）+ 使用者两项（公用网 / 专用网）
⚠️ 教材只给中英文全称，没给覆盖距离数字。「PAN≈10m / LAN≈1km / MAN 5~50km / WAN 几十~几千 km」是教辅补充，别当教材原文记

网络协议是为计算机网络中进行数据交换而建立的规则、标准或约定的集合，由语义、语法、时序三个要素组成：

要素教材原文通俗对应
语义解释控制信息每个部分的含义，它规定了需要发出何种控制信息、完成的动作以及做出什么样的响应要做什么
语法用户数据与控制信息的结构与格式，以及数据出现的顺序要怎么做
时序对事件发生顺序的详细说明做的顺序
口诀：义 · 法 · 时（语义做什么 / 语法怎么做 / 时序什么顺序）

国际标准化组织（ISO）和国际电报电话咨询委员会（CCITT）联合制定的开放系统互连参考模型（Open System Interconnect，OSI），目的是为异种计算机互连提供一个共同的基础和标准框架，并为保持相关标准的一致性和兼容性提供共同的参考。

• OSI 采用了分层的结构化技术，从下到上共分：物理层、数据链路层、网络层、传输层、会话层、表示层和应用层
• 广域网协议是在 OSI 参考模型的最下面三层操作，定义了在不同的广域网介质上的通信
口诀：物 · 数 · 网 · 传 · 会 · 表 · 应（自下而上）
⚠️ 教材原文是「从下到上」；部分教辅写成「从上到下」，方向别记反

PPP 点对点协议 · ISDN 综合业务数字网 · xDSL（DSL 数字用户线路的统称：HDSL、SDSL、MVL、ADSL）· DDN 数字专线 · x.25 · FR 帧中继 · ATM 异步传输模式。

记忆：P·I·x·D·x·F·A 七个。真题干扰项常用「NVL」「IEEE 802.3」「HTTP」冒充广域网协议

IEEE 802 规范定义了网卡如何访问传输介质（如光缆、双绞线、无线等），以及如何在传输介质上传输数据的方法，还定义了传输信息的网络设备之间连接的建立、维护和拆除的途径。遵循 IEEE 802 标准的产品包括网卡、桥接器、路由器以及其他一些用来建立局域网络的组件。

TCP/IP 在一定程度上参考了 OSI，将 OSI 的七层简化为四层：应用层、传输层、网络层、网络接口层。教材给出三条合并理由：

1. 应用层、表示层、会话层三个层次提供的服务相差不是很大 → 在 TCP/IP 中合并为应用层一个层次

2. 传输层和网络层在网络协议中地位十分重要 → 作为独立的两个层次

3. 数据链路层和物理层的内容相差不多 → 归并为网络接口层一个层次

层次协议 / 功能
应用层FTP（文件传输）· TFTP（简单文件传输）· HTTP（超文本传输）· SMTP（简单邮件传输）· DHCP（动态主机配置）· Telnet（远程登录）· DNS（域名系统）· SNMP（简单网络管理）
传输层TCP 和 UDP，负责提供流量控制、错误校验和排序服务
网络层IP · ICMP（网际控制报文）· IGMP（网际组管理）· ARP（地址解析）· RARP（反向地址解析），处理信息的路由和主机地址解析
网络接口层兼并了物理层和数据链路层，既是传输数据的物理媒介，也可为网络层提供一条准确无误的线路
⚠️⚠️ 本节最高频陷阱：ARP / RARP 属网络层，不属于应用层；应用层合并的是 OSI 的会话层 + 表示层 + 应用层（三层，不是两层）
别丢分：TFTP 也是应用层协议

SDN（Software Defined Network）是一种新型网络创新架构，是网络虚拟化的一种实现方式，可通过软件编程的形式定义和控制网络；其通过将网络设备的控制面与数据面分离开来，实现了网络流量的灵活控制，使网络变得更加智能。

• 控制层：包括具有逻辑中心化和可编程的控制器，可掌握全局网络信息，方便运营商和科研人员管理配置网络和部署新协议等
• 数据层：包括哑交换机（与传统的二层交换机不同，专指用于转发数据的设备），仅提供简单的数据转发功能，可以快速处理匹配的数据包
• 两层之间采用开放的统一接口（如 OpenFlow 等）进行交互；控制器通过标准接口向交换机下发统一标准规则
• 整体架构由下到上（由南到北）分三个平面：
平面内容
数据平面由交换机等网络通用硬件组成，各网络设备之间通过不同规则形成的 SDN 数据通路连接
控制平面包含逻辑上为中心的 SDN 控制器，掌握全局网络信息，负责各种转发规则的控制
应用平面包含各种基于 SDN 的网络应用，用户无须关心底层细节就可以编程、部署新应用
• 三类接口：
接口连接方向标准情况
南向接口 CDPI（Control-Data-Plane Interface）控制平面 ↔ 数据平面具有统一的通信标准，最主要应用 OpenFlow 协议
北向接口 NBI（NorthBound Interface）控制平面 ↔ 应用平面并非统一标准，允许用户根据自身需求定制开发各种网络管理应用
东西向接口多控制器之间使控制器具有可扩展性，为负载均衡和性能提升提供技术保障
• OpenFlow 最基本的特点是基于流（Flow）的概念来匹配转发规则，每个交换机维护一个流表（Flow Table）；流表的建立、维护和下发都是由控制器完成的
口诀：控数分离 · 南向 OpenFlow 统一 · 北向不统一 · 东西向管多控制器
⚠️ 方位别接反：南（South）接硬件/数据平面，北（North）接应用平面

• 技术基础：在正交频分多址（OFDMA）和多入多出（MIMO）基础技术上，5G 为支持三大应用场景，采用了灵活的全新系统设计
• 频段：与 4G 支持中低频不同，考虑到中低频资源有限，5G 同时支持中低频和高频频段——中低频满足覆盖和容量需求，高频满足在热点区域提升容量的需求；5G 针对中低频和高频设计了统一的技术方案，并支持百 MHz 的基础带宽
• 为支持低时延、高可靠，5G 采用短帧、快速反馈、多层/多站数据重传等技术

模块 C ｜ 存储和数据库（2.1.3）

• 按服务器类型分：封闭系统的存储（封闭系统主要指大型机等服务器）和开放系统的存储（开放系统指基于包括麒麟、欧拉、UNIX、Linux 等操作系统的服务器）
• 开放系统的存储分为：内置存储和外挂存储
• 外挂存储根据连接的方式分为：直连式存储（DAS）和网络化存储（FAS，Fabric-Attached Storage）
• 网络化存储根据传输协议又分为：网络接入存储（NAS）和存储区域网络（SAN）
链条记忆：服务器类型（封闭/开放）→ 内置 / 外挂 → 连接方式（DAS / FAS）→ 传输协议（NAS / SAN）
⚠️ DAS 与 NAS/SAN 不在同一层级：外挂存储先分「连接方式」，得到 DAS 与 FAS；FAS 再按「传输协议」分 NAS 与 SAN。别把三者当同层并列做分类题
类型定义核心特点（技术与应用）
内置存储直接集成在服务器内部的存储安装简单，适合单个服务器独立使用，容量扩充能力低
DAS通过线缆直接连接服务器的外挂存储数据传输协议为 SCSI / FC / ATA，传输对象为数据块，适合中小组织服务器捆绑磁盘（JBOD），文档共享程度低
NAS通过 TCP/IP 网络连接的存储设备支持 NFS / CIFS 等文件共享协议，异种操作系统可共享，安装管理简单，适合中小组织、SOHO 族及部门级文件共享，文档共享程度高
SAN基于光纤通道（FC）的专用存储网络传输数据块，集中式管理需专用工具，容量扩充能力高，适合大型组织、数据中心、大型资料库和数据库，网络环境复杂
选型口诀：文件共享选 NAS · 数据库高性能选 SAN · 单机外接是 DAS
一句话辨析：NAS 传文件（文件级）、SAN 传数据块（块级）、DAS 靠线缆直连

存储虚拟化（Storage Virtualization）是「云存储」的核心技术之一：它把来自一个或多个网络的存储资源整合起来，向用户提供一个抽象的逻辑视图，用户可以通过这个视图中的统一逻辑接口来访问被整合的存储资源；用户在访问数据时并不知道真实的物理位置。

• 直接好处：提高存储利用率 · 降低存储成本 · 简化大型、复杂、异构的存储环境的管理工作
• 数据存储是类似于文件系统的逻辑容器，它隐藏了每个存储设备的特性，形成一个统一的模型，为虚拟机提供磁盘
⚠️ 原话是「存储虚拟化是云存储的核心技术之一」——别被「服务器虚拟化」「网络虚拟化」带偏

绿色存储（Green Storage）技术是指从节能环保的角度出发，用来设计生产能效更佳的存储产品，降低数据存储设备的功耗，提高存储设备每瓦性能的技术。

• 绿色存储是一个系统设计方案，贯穿于整个存储设计过程，包含存储系统的外部环境、存储架构、存储产品、存储技术、文件系统和软件配置等多方面因素
• 核心是设计运行温度更低的处理器和更有效率的系统，生产更低能耗的存储系统或组件，降低产品所产生的电子碳化合物
• 最终目的：提高所有网络存储设备的能源效率，用最少的存储容量来满足业务需求，从而消耗最低的能源
• 收口句：以绿色理念为指导的存储系统最终是存储容量、性能、能耗三者的平衡
三个「更」不要混：更佳能效 · 更低功耗 · 更高每瓦性能；平衡三项 = 容量 / 性能 / 能耗

数据结构模型是数据库系统的核心。它描述了在数据库中结构化和操纵数据的方法：结构部分规定了数据如何被描述（例如树、表等）；操纵部分规定了数据的添加、删除、显示、维护、打印、查找、选择、排序和更新等操作。

常见的数据结构模型有三种：层次模型、网状模型和关系模型；层次模型和网状模型又统称为格式化数据模型。

模型教材原文关键限定
层次模型数据库系统最早使用的一种模型，用「树」结构表示实体集之间的关联，实体集（用矩形框表示）为结点，树中各结点之间的连线表示关联每个结点表示一个记录类型，联系是父子之间的一对多联系；任何一个给定的记录值只能按其层次路径查看，没有一个子女记录值能够脱离双亲记录值而独立存在
网状模型用网状结构表示实体类型及其实体之间的联系是一种可以灵活地描述事物及其之间关系的数据库模型；网状数据库是导航式（Navigation）数据库——用户在操作数据库时不但说明要做什么，还要说明怎么做（查找语句中不但要说明查找对象，还要规定存取路径）
关系模型在关系结构的数据库中用二维表格的形式表示实体以及实体之间的联系的模型以集合论中的关系概念为基础发展起来；无论是实体还是实体间的联系，均由单一的结构类型「关系」来表示
口诀：层次＝树 · 网状＝网＋导航式 · 关系＝二维表
⚠️ 易错三连：①「最早使用」＝层次模型；②「导航式」＝网状模型；③格式化数据模型 = 层次 + 网状（关系模型不算）

数据库根据存储方式分为关系型数据库（SQL）和非关系型数据库（Not Only SQL，NoSQL）。

• 关系型数据库：采用关系模型作为数据的组织方式，是在一个给定的应用领域中，所有实体及实体之间联系的集合；支持事务的 ACID 原则：
字母英文中文
AAtomicity原子性
CConsistency一致性
IIsolation隔离性
DDurability持久性

（这四种原则保证在事务过程当中数据的正确性）

• 非关系型数据库：是分布式的、非关系型的、不保证遵循 ACID 原则的数据存储系统；不需要固定的表结构，通常也不存在连接操作；在大数据存取上具备关系型数据库无法比拟的性能优势

为了满足中高层管理人员预测、决策分析的需要，在传统数据库的基础上产生了能够满足预测、决策分析需要的数据环境——数据仓库。

模块 D ｜ 信息安全（2.1.4）

信息安全强调信息（数据）本身的安全属性，主要包括：

属性英文教材原文
保密性Confidentiality信息不被未授权者知晓的属性
完整性Integrity信息是正确的、真实的、未被篡改的、完整无缺的属性

口诀：报完用（保密 / 完整 / 可用）

信息必须依赖其存储、传输、处理及应用的载体（媒介）而存在，因此针对信息系统，安全可以划分为四个层次：设备安全、数据安全、内容安全、行为安全。

口诀：设 · 数 · 内 · 行（由表及里、由静到动）
⚠️ 是「四个层次」，不是三层
• 信息系统一般由计算机系统、网络系统、操作系统、数据库系统和应用系统组成。与此对应，信息系统安全主要包括：计算机设备安全、网络安全、操作系统安全、数据库系统安全和应用系统安全等
• 网络安全技术主要包括：防火墙 · 入侵检测与防护 · VPN · 安全扫描 · 网络蜜罐技术 · 用户和实体行为分析技术等
口诀：防入 V · 扫蜜行（防火墙 / 入侵检测与防护 / VPN / 安全扫描 / 网络蜜罐 / 用户和实体行为分析）

将明文数据加密成密文，然后将密文数据送入网络传输或存入计算机文件，而且只给合法收信者分配密钥；合法收信者接收到密文后，实行与加密变换相逆的变换，去掉密文的伪装并恢复出明文，这一过程称为解密（Decryption）。

• ⚠️ 加密技术包括两个元素：算法和密钥
• 密钥加密技术的密码体制分为对称密钥体制和非对称密钥体制两种，相应地数据加密的技术分为两类：
类别别名密钥关系教材代表适用场景
对称加密私人密钥加密加密密钥和解密密钥相同数据加密标准（DES）算法为典型代表大量数据快速加密
非对称加密公开密钥加密加密密钥和解密密钥不同；加密密钥可以公开而解密密钥需要保密通常以 RSA 算法为代表密钥交换、数字签名
口诀：对称 = DES（快 · 密钥难管）；非对称 = RSA（慢 · 密钥好管）
⚠️ 两个元素是「算法 + 密钥」，不是「算法 + 密文」

用户和实体行为分析（User and Entity Behavior Analytics，UEBA）提供了用户画像及基于各种分析方法的异常检测，结合基本分析方法（利用签名的规则、模式匹配、简单统计、阈值等）和高级分析方法（监督和无监督的机器学习等），用打包分析来评估用户和其他实体（主机、应用程序、网络、数据库等），发现与用户或实体标准画像或行为异常的活动所相关的潜在事件。

• 定位：虽然大多数的攻击可能来自组织以外，但最严重的损害往往是由内部人员造成的；只有管理好内部威胁，才能保证信息和网络安全
关键词三连：用户画像 + 异常检测 + 内部威胁（三处都落在「内」，看到「内部人员造成损害」选 UEBA）

网络安全态势感知是在大规模网络环境中，对能够引起网络态势发生变化的安全要素进行获取、理解、显示，并据此预测未来网络的安全发展趋势。

• 它是一种基于环境的、动态的、整体的洞悉安全风险的能力
• 安全态势感知的前提是安全大数据

时序**。**语义**＝要做什么（解释控制信息每个部分的含义，规定发出何种控制信息、完成什么动作、做出什么响应）；**语法**＝要怎么做（用户数据与控制信息的结构与格式、数据出现的顺序）；**时序**＝做的顺序（对事件发生顺序的详细说明） 8. **国际标准化组织（ISO）**和**国际电报电话咨询委员会（CCITT）**联合制定。七层自下而上：**物理层、数据链路层、网络层、传输层、会话层、表示层、应用层**。广域网协议在**最下面三层**操作 9. **PPP 点对点协议 · ISDN 综合业务数字网 · xDSL（HDSL/SDSL/MVL/ADSL）· DDN 数字专线 · x.25 · FR 帧中继 · ATM 异步传输模式**。**NVL 不是**广域网协议（真题高频干扰项） 10. **802.3 = 以太网的 CSMA/CD 载波监听多路访问/冲突检测协议**（有线以太网）；**802.11 = 无线局域网 WLAN 标准协议**；**802.5 = 令牌环 Token Ring 协议**；**802.6 = 城域网 MAN 协议** 11. 简化为**应用层、传输层、网络层、网络接口层**四层。理由：①应用层、表示层、会话层**服务相差不大**→合并为应用层；②传输层和网络层**地位十分重要**→作为独立的两个层次；③数据链路层和物理层**内容相差不多**→归并为网络接口层 12. **应用层**：FTP、TFTP、HTTP、SMTP、DHCP、Telnet、DNS、SNMP；**传输层**：TCP、UDP（提供流量控制、错误校验和排序服务）；**网络层**：IP、ICMP、IGMP、ARP、RARP（处理路由和主机地址解析）。**ARP / RARP 属于网络层** 13. 核心思想 = **将网络设备的控制面与数据面分离开来**（软件编程定义和控制网络，是网络虚拟化的一种实现方式）。架构由下到上（由南到北）：**数据平面**（交换机等网络通用硬件，靠 SDN 数据通路连接）→ **控制平面**（逻辑上为中心的 SDN 控制器，掌握全局网络信息，负责转发规则控制）→ **应用平面**（各种基于 SDN 的网络应用） 14. **南向接口 CDPI** 连接控制平面与**数据平面**（**具有统一通信标准**，最主要应用 **OpenFlow** 协议）；**北向接口 NBI** 连接控制平面与**应用平面**（**并非统一标准**，允许定制开发）；**东西向接口**连接**多控制器之间**（提供可扩展性、负载均衡和性能提升保障） 15. 三大特点：**高速率、低时延、大连接**。场景：**eMBB 增强移动宽带**（面向移动互联网流量爆炸式增长）· **uRLLC 超高可靠低时延通信**（面向工业控制、远程医疗、自动驾驶等垂直行业）· **mMTC 海量机器类通信**（面向智慧城市、智能家居、环境监测等以传感和数据采集为目标的应用） 16. **同时支持中低频和高频频段**：中低频满足**覆盖和容量**需求，高频满足**在热点区域提升容量**需求；针对两者设计**统一的技术方案**，支持**百 MHz 的基础带宽**。为支持低时延高可靠采用**短帧、快速反馈、多层/多站数据重传**等技术 17. 分为**封闭系统的存储**（主要指大型机等服务器）和**开放系统的存储**（基于麒麟、欧拉、UNIX、Linux 等操作系统的服务器）；开放系统的存储分**内置存储**和**外挂存储**。**DAS 按「连接的方式」**与外挂存储并列（同属该层的是网络化存储 FAS），**NAS 与 SAN 按「传输协议」**在网络化存储 FAS 之下 18. **DAS**：线缆直连，协议 SCSI/FC/ATA，传**数据块**，文档共享程度**低**，适合中小组织服务器捆绑磁盘 JBOD；**NAS**：走 TCP/IP 网络，支持 **NFS/CIFS** 文件共享协议，异种操作系统可共享，文档共享程度**高**，适合中小组织、SOHO 族及部门级文件共享；**SAN**：基于**光纤通道（FC）**的专用存储网络，传**数据块**，集中管理需专用工具，容量扩充能力**高**，适合大型组织、数据中心、大型资料库和数据库。口诀：**文件共享选 NAS · 数据库高性能选 SAN · 单机外接是 DAS** 19. 因为它把来自一个或多个网络的存储资源**整合起来**，向用户提供**抽象的逻辑视图**，用户通过**统一逻辑接口**访问，且**访问数据时并不知道真实物理位置**。三项好处：**提高存储利用率 · 降低存储成本 · 简化大型、复杂、异构的存储环境的管理工作** 20. 绿色存储技术是指从**节能环保**的角度出发，用来**设计生产能效更佳的存储产品**，**降低数据存储设备的功耗**，**提高存储设备每瓦性能**的技术。三者平衡 = **存储容量 · 性能 · 能耗** 21. **层次模型 · 网状模型 · 关系模型**；**层次模型和网状模型合称格式化数据模型**。**「最早使用」＝层次模型**；**「导航式数据库」＝网状模型** 22. **A 原子性（Atomicity）· C 一致性（Consistency）· I 隔离性（Isolation）· D 持久性（Durability）**。NoSQL 四类：**键值数据库（Redis）· 列存储数据库（HBase）· 面向文档数据库（MongoDB）· 图形数据库（Neo4j）** 23. 四特征 = **面向主题的 · 集成的 · 非易失的 · 随时间变化的**数据集合，用于支持管理决策。**数据源是系统的基础**；**数据的存储与管理是整个数据仓库系统的核心**。ROLAP：基本数据与聚合数据均在 **RDBMS**；MOLAP：均在**多维数据库**；HOLAP：**基本数据在 RDBMS、聚合数据在多维数据库** 24. **保密性（Confidentiality，不被未授权者知晓）· 完整性（Integrity，正确的、真实的、未被篡改的、完整无缺）· 可用性（Availability，可以随时正常使用）**。四个层次：**设备安全 · 数据安全 · 内容安全 · 行为安全**。信息系统安全主要包括**计算机设备安全、网络安全、操作系统安全、数据库系统安全和应用系统安全** 25. 网络安全技术包括**防火墙 · 入侵检测与防护 · VPN · 安全扫描 · 网络蜜罐技术 · 用户和实体行为分析技术**等。加密技术两个元素 = **算法和密钥**。**对称加密**（私人密钥加密）：加解密密钥**相同**，代表 **DES**；**非对称加密**（公开密钥加密）：加解密密钥**不同**，加密密钥可公开、解密密钥需保密，代表 **RSA** 26. UEBA 提供**用户画像**及基于各种分析方法的**异常检测**（结合基本分析方法与高级分析方法），评估用户和其他实体，发现异常行为相关的潜在事件；核心是防范**内部威胁**（最严重的损害往往由内部人员造成）。态势感知：在**大规模网络环境**中对能够引起网络态势变化的**安全要素**进行**获取、理解、显示**，并据此**预测未来网络的安全发展趋势**；关键是①海量多元异构数据的汇聚（融合）②面向多类型的网络安全威胁评估 ③网络安全态势评估与决策支撑 ④网络安全态势可视化 27. **计算机软硬件**：硬件向**超高速、超小型、平行处理、智能化**发展，软件**「软件定义一切」**成为主流；**网络技术**：网络与通信技术**日益密切甚至融为一体**，**5G 成为当前主流**（NB-IoT、eMTC、IIoT、URLLC 等充分发展）；**存储和数据库**：向**模型拓展、架构解耦**演进；**信息安全**：过渡到以**可信计算理念**为核心，技术朝**标准化和集成化**发展

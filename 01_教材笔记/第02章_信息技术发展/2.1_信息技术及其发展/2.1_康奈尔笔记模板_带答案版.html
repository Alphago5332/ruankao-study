2.1 总论 · 2.1.1 计算机软硬件
1信息技术定义与形态分类
  • 定义：信息技术是以微电子学为基础的计算机技术和电信技术的结合而形成的，对声音的、图像的、文字的、数字的和各种传感信号的信息进行获取、加工、处理、存储、传播和使用的技术
  • 地位：信息技术是实现信息化的手段，是信息系统建设的基础
  • 按表现形态分为两类：硬技术（物化技术）＝各种信息设备及其功能（传感器、服务器、智能手机、通信卫星、笔记本电脑）；软技术（非物化技术）＝有关信息获取与处理的知识、方法与技能（语言文字技术、数据统计分析技术、规划决策技术、计算机软件技术）
判别法：能拿在手上的设备 = 硬技术（物化）；知识 / 方法 / 技能 = 软技术（非物化）。第 2 章开篇还强调「信息技术与信息化、信息系统密不可分」
2计算机软硬件：定义 · 程序与文档 · 界线结论
  • 硬件：计算机系统中由电子、机械和光电元件等组成的各种物理装置的总称；按系统结构要求构成有机整体，为计算机软件运行提供物质基础
  • 软件＝程序及其文档。程序是计算任务的处理对象和处理规则的描述，必须安装入机器内部才能工作；文档是为了便于了解程序所需的阐明性资料，一般是给人看的，不一定安装入机器
  • 关系：互相依存——硬件是软件赖以工作的物质基础，软件的正常工作是硬件发挥作用的重要途径；两者协同发展、密切交织发展，缺一不可
  • 界线结论句：计算机的某些功能既可以由硬件实现，也可以由软件来实现，因此硬件与软件在一定意义上来说没有绝对严格的界线
一对高频对比：程序进机器，文档给人看。⚠️ 第 4 版 2.1.1 只有两段，没有「五大部件（运算器 / 控制器 / 存储器 / 输入 / 输出）」的展开，别把硬件基础课的内容当本节考点
2.1.2 计算机网络
3网络分类（按作用范围）与协议三要素
  • 六类：个人局域网（PAN）· 局域网（LAN）· 城域网（MAN）· 广域网（WAN）· 公用网（Public Network）· 专用网（Private Network）
  • 三要素：语义——解释控制信息每个部分的含义，规定需要发出何种控制信息、完成的动作以及做出什么样的响应（要做什么）；语法——用户数据与控制信息的结构与格式，以及数据出现的顺序（要怎么做）；时序——对事件发生顺序的详细说明（做的顺序）
六类分两组记：作用范围四项（PAN / LAN / MAN / WAN）＋使用者两项（公用网 / 专用网）。口诀 义 · 法 · 时。⚠️ 教材未给各类网络的覆盖距离数字（「PAN≈10m」等是教辅补充）
4OSI 参考模型与广域网协议
  • 制定者：国际标准化组织（ISO）和国际电报电话咨询委员会（CCITT）联合制定；目的是为异种计算机互连提供共同的基础和标准框架
  • 七层（自下而上）：物理层 → 数据链路层 → 网络层 → 传输层 → 会话层 → 表示层 → 应用层（OSI 采用分层的结构化技术）
  • 广域网协议在 OSI 参考模型的最下面三层操作，定义了在不同广域网介质上的通信
  • 广域网协议：PPP 点对点协议 · ISDN 综合业务数字网 · xDSL（DSL 数字用户线路统称：HDSL、SDSL、MVL、ADSL）· DDN 数字专线 · x.25 · FR 帧中继 · ATM 异步传输模式
口诀 物 · 数 · 网 · 传 · 会 · 表 · 应。⚠️ 教材原文是「从下到上」；部分教辅写成「从上到下」，方向别记反。广域网协议记忆串 P·I·x·D·x·F·A；「NVL」不是广域网协议（真题高频干扰项）
5IEEE 802 协议族（只背四个编号）
  • 802.3 = 以太网的 CSMA/CD 载波监听多路访问/冲突检测协议（有线以太网）
  • 802.11 = 无线局域网 WLAN 标准协议（手机热点属 802.11）
  • 802.5 = 令牌环 Token Ring 协议；802.6 = 城域网 MAN 协议
  • 遵循 IEEE 802 标准的产品：网卡、桥接器、路由器等建立局域网络的组件
802 规范定义三件事：网卡如何访问传输介质（光缆 / 双绞线 / 无线）· 如何在介质上传输数据 · 设备之间连接的建立、维护和拆除途径。其余编号只留印象：802.1 概论 / 802.2 LLC / 802.4 令牌总线 / 802.7 FDDI
6TCP/IP 四层 · 三条合并理由 · 协议归属
  • 四层：应用层 · 传输层 · 网络层 · 网络接口层
  • 三条理由：① 应用层、表示层、会话层服务相差不大 → 合并为应用层；② 传输层和网络层在网络协议中地位十分重要 → 作为独立的两层；③ 数据链路层和物理层内容相差不多 → 归并为网络接口层
  • 应用层：FTP · TFTP · HTTP · SMTP · DHCP · Telnet · DNS · SNMP
  • 传输层：TCP 和 UDP，负责提供流量控制、错误校验和排序服务
  • 网络层：IP · ICMP（网际控制报文）· IGMP（网际组管理）· ARP（地址解析）· RARP（反向地址解析），处理信息的路由和主机地址解析
  • 网络接口层：兼并了物理层和数据链路层，既是传输数据的物理媒介，也可为网络层提供一条准确无误的线路
⚠️⚠️ 本节最高频陷阱：ARP / RARP 属于网络层，不属于应用层；应用层合并的是 OSI 的会话层 + 表示层 + 应用层三层；TFTP 也是应用层协议
7软件定义网络 SDN：三个平面 · 三类接口
  • 核心思想：将网络设备的控制面与数据面分离开来，通过软件编程的形式定义和控制网络，实现网络流量的灵活控制；SDN 是网络虚拟化的一种实现方式
  • 架构（由下到上 / 由南到北）：数据平面（交换机等网络通用硬件，靠 SDN 数据通路连接）→ 控制平面（逻辑上为中心的 SDN 控制器，掌握全局网络信息、负责转发规则控制）→ 应用平面（各种基于 SDN 的网络应用，用户无须关心底层细节即可编程部署）
  • 南向接口 CDPI：控制平面 ↔ 数据平面，具有统一的通信标准，最主要应用 OpenFlow 协议
  • 北向接口 NBI：控制平面 ↔ 应用平面，并非统一标准，允许用户定制开发网络管理应用
  • 东西向接口：多控制器之间通信，使控制器具有可扩展性，为负载均衡和性能提升提供技术保障
  • 数据层中的交换机称哑交换机（专指用于转发数据的设备）；OpenFlow 最基本的特点是基于流（Flow）的概念来匹配转发规则，每个交换机维护一个流表（Flow Table），其建立、维护和下发均由控制器完成
方位别接反：南（South）接数据平面 / 硬件，北（North）接应用平面；口诀 控数分离 · 南向 OpenFlow 统一 · 北向不统一 · 东西向管多控制器
85G：三大特点 · 三大场景 · 关键指标
  • 三大特点：高速率 · 低时延 · 大连接
  • 三大应用场景（ITU 定义）：eMBB 增强移动宽带——面向移动互联网流量爆炸式增长；uRLLC 超高可靠低时延通信——面向工业控制、远程医疗、自动驾驶等对时延和可靠性要求极高的垂直行业；mMTC 海量机器类通信——面向智慧城市、智能家居、环境监测等以传感和数据采集为目标的场景
  • 技术基础：在正交频分多址（OFDMA）和多入多出（MIMO）基础上采用灵活的全新系统设计
  • 频段：与 4G 支持中低频不同，5G 同时支持中低频和高频频段——中低频满足覆盖和容量，高频满足热点区域提升容量；支持百 MHz 的基础带宽
  • 为支持低时延高可靠，采用短帧、快速反馈、多层/多站数据重传等技术
  • 必背四个指标：空口时延 1ms（4G 是 10ms）· 峰值速率 20Gbps（4G 是 10）· 连接数密度 100 万/km²（4G 是 10）· 用户体验速率 0.1~1Gbps（4G 是 10M）。其余四项了解：流量密度 10 Tb/s·km² · 移动性 500 km/h · 能效 100 倍 · 频道效率 3 倍
场景口诀 e 高（速率）· u 低（时延）· m 多（连接）。⚠️ 5G 特点里没有「宏基站」（真题干扰项）
2.1.3 存储和数据库
9存储分类线索与 DAS / NAS / SAN
  • 分类线索（两层递进）：按服务器类型分 封闭系统的存储（主要指大型机等服务器）/ 开放系统的存储（基于麒麟、欧拉、UNIX、Linux 等操作系统）→ 开放系统的存储分 内置存储 / 外挂存储 → 外挂存储按连接方式分 DAS（直连式存储） 与 FAS（网络化存储） → 网络化存储按传输协议分 NAS（网络接入存储） 与 SAN（存储区域网络）
  • DAS：通过线缆直接连接服务器；协议 SCSI / FC / ATA，传数据块，适合中小组织服务器捆绑磁盘（JBOD），文档共享程度低
  • NAS：通过 TCP/IP 网络连接；支持 NFS / CIFS 文件共享协议，异种操作系统可共享，安装管理简单，适合中小组织、SOHO 族及部门级文件共享，文档共享程度高
  • SAN：基于光纤通道（FC）的专用存储网络；传数据块，集中式管理需专用工具，容量扩充能力高，适合大型组织、数据中心、大型资料库和数据库，网络环境复杂
选型口诀：文件共享选 NAS · 数据库高性能选 SAN · 单机外接是 DAS。⚠️ DAS 与 NAS/SAN 不在同一层级：外挂存储先按连接方式分，NAS/SAN 是「网络化存储 FAS」再按传输协议分出来的
10存储虚拟化 与 绿色存储
  • 存储虚拟化是「云存储」的核心技术之一：把来自一个或多个网络的存储资源整合起来，向用户提供抽象的逻辑视图，用户通过视图中的统一逻辑接口访问被整合的资源，访问数据时并不知道真实的物理位置
  • 三项好处：提高存储利用率 · 降低存储成本 · 简化大型、复杂、异构的存储环境的管理工作；数据存储是类似文件系统的逻辑容器，隐藏各设备特性形成统一模型，为虚拟机提供磁盘
  • 绿色存储：从节能环保角度出发，用来设计生产能效更佳的存储产品，降低数据存储设备的功耗，提高存储设备每瓦性能的技术；是一个系统设计方案，贯穿整个存储设计过程
  • 核心：设计运行温度更低的处理器和更有效率的系统，降低产品产生的电子碳化合物；最终目的：提高所有网络存储设备的能源效率，用最少的存储容量满足业务需求，消耗最低的能源
  • 收口：以绿色理念为指导的存储系统最终是存储容量、性能、能耗三者的平衡
⚠️ 原话是「存储虚拟化是云存储的核心技术之一」，别被「服务器虚拟化 / 网络虚拟化」带偏；绿色存储三个「更」：更佳能效 / 更低功耗 / 更高每瓦性能
11数据结构模型 · 数据库类型 · 数据仓库
  • 数据结构模型是数据库系统的核心；三种模型：层次模型 · 网状模型 · 关系模型；层次模型和网状模型又统称为格式化数据模型
  • 层次模型：数据库系统最早使用的一种模型，用「树」结构表示实体集关联，实体集为结点，联系是父子之间的一对多；记录值只能按层次路径查看，子女记录值不能脱离双亲记录值独立存在
  • 网状模型：用网状结构表示实体类型及联系，可灵活描述事物及其关系；网状数据库是导航式（Navigation）数据库——操作时不但说明要做什么，还要说明怎么做（查找语句要规定存取路径）
  • 关系模型：用二维表格的形式表示实体以及实体之间的联系；以集合论中的关系概念为基础，实体和联系均由单一的结构类型「关系」表示
  • ACID（关系型数据库支持）：A 原子性 Atomicity · C 一致性 Consistency · I 隔离性 Isolation · D 持久性 Durability
  • 非关系型（NoSQL）：分布式的、非关系型的、不保证遵循 ACID 原则，不需要固定表结构，通常不存在连接操作，在大数据存取上有无法比拟的性能优势。四类：键值数据库（Redis）· 列存储数据库（HBase）· 面向文档数据库（MongoDB）· 图形数据库（Neo4j）
  • 数据仓库四特征：面向主题的 · 集成的 · 非易失的 · 随时间变化的数据集合，用于支持管理决策（为满足中高层管理人员预测、决策分析的需要而产生）
  • 体系结构四部分：① 数据源——是数据仓库系统的基础、整个系统的数据源泉；② 数据的存储与管理——是整个数据仓库系统的核心，按主题组织，分组织级数据仓库与部门级数据仓库（数据集市）；③ 联机分析处理（OLAP）服务器——按多维模型组织数据，进行多角度多层次分析；④ 前端工具——查询 / 报表 / 分析 / 数据挖掘工具（数据分析工具针对 OLAP 服务器，报表与数据挖掘工具针对数据仓库）
  • OLAP 三种实现：ROLAP 基本数据与聚合数据均在 RDBMS；MOLAP 均在多维数据库；HOLAP 基本数据在 RDBMS、聚合数据在多维数据库
三锚点：最早使用 = 层次｜导航式 = 网状｜格式化数据模型 = 层次 + 网状（关系不算）。四特征口诀 面向主题 · 集成 · 非易失 · 随时间变化。⚠️「基础」是数据源、「核心」是数据的存储与管理，别对调。ETL = 清洗 / 转换 / 加载（从数据源抽取 → 清洗转换 → 按数仓模型加载）
2.1.4 信息安全 · 2.1.5 发展趋势
12信息安全（CIA · 四层次 · 加密 · UEBA · 态势感知）＋ 2.1.5 四方向趋势
信息安全（2.1.4）
  • CIA 三属性：保密性 Confidentiality（信息不被未授权者知晓）· 完整性 Integrity（信息是正确的、真实的、未被篡改的、完整无缺的）· 可用性 Availability（信息可以随时正常使用）。口诀 报完用
  • 四个层次：设备安全 · 数据安全 · 内容安全 · 行为安全。口诀 设数内行
  • 信息系统安全五个方面：计算机设备安全 · 网络安全 · 操作系统安全 · 数据库系统安全 · 应用系统安全
  • 网络安全技术：防火墙 · 入侵检测与防护 · VPN · 安全扫描 · 网络蜜罐技术 · 用户和实体行为分析技术。口诀 防入 V · 扫蜜行
  • 加密技术两个元素＝算法和密钥；对称加密（私人密钥加密）加解密密钥相同，代表 DES；非对称加密（公开密钥加密）加解密密钥不同、加密密钥可公开而解密密钥需保密，代表 RSA
  • UEBA（用户和实体行为分析）：提供用户画像及基于各种分析方法的异常检测，评估用户和其他实体（主机、应用程序、网络、数据库等），发现异常活动相关的潜在事件；关键是防范内部威胁——最严重的损害往往由内部人员造成
  • 网络安全态势感知：在大规模网络环境中对能够引起网络态势变化的安全要素进行获取、理解、显示，并据此预测未来网络的安全发展趋势；是基于环境的、动态的、整体的能力，前提是安全大数据。关键技术四项：① 海量多元异构数据的汇聚（融合） ② 面向多类型的网络安全威胁评估 ③ 网络安全态势评估与决策支撑 ④ 网络安全态势可视化
信息技术的发展（2.1.5 四方向）
  • 计算机软硬件：硬件向超高速、超小型、平行处理、智能化发展（体积越来越小、速度越来越高、容量越来越大、功耗越来越低、可靠性越来越高）；软件越来越丰富、功能越来越强大，「软件定义一切」成为当前发展主流
  • 网络技术：计算机网络与通信技术联系日益密切，甚至是已经融为一体；5G 成为当前的主流；面向物联网 / 低时延场景的 NB-IoT（窄带物联网）与 eMTC（增强型机器类型通信）、IIoT（工业物联网）与 URLLC（低延时高可靠通信）等技术将充分发展
  • 存储和数据库：数据量的不断爆炸式增长推动数据库技术向模型拓展、架构解耦方向演进
  • 信息安全：传统安全理念过渡到以可信计算理念为核心的计算机安全；信息安全标准的研究与制定、产品和服务的集成和融合，引领技术向标准化和集成化发展
⚠️ 最易互换两个词：「软件定义一切」属软件趋势（不是「软件定义网络」）；「可信计算」属信息安全趋势。另注意「四个层次」（设备/数据/内容/行为）与「五个方面」（计算机设备/网络/操作系统/数据库系统/应用系统）是两个不同维度的划分，别混为一谈
总结区 本节本质 + 考点地图
本节本质：2.1 是第 2 章的开篇节，也是上午卷最大分值块（第 2 章 6~12 题）的主力。全节没有计算，题型固定为三类——协议 / 术语的层级归属、分类与顺序的排序、特征与定义的匹配。本节五小节其实是「一台信息系统的五个部件」：软硬件（算）→ 网络（传）→ 存储数据库（存）→ 信息安全（保）→ 发展趋势（往哪走）。
考点地图（按考频排序）：① TCP/IP 各层协议归属（ARP/RARP 在网络层、应用层合并会话+表示+应用三层）→ ② OSI 七层顺序（物数网传会表应）与广域网协议 → ③ DAS / NAS / SAN 的层级与选型（文件选 NAS、数据库选 SAN、单机是 DAS）→ ④ SDN 三个平面 + 三类接口（南向 OpenFlow 统一、北向不统一、东西向管多控制器）→ ⑤ 5G 三大场景 eMBB/uRLLC/mMTC 与空口时延 1ms → ⑥ 数据仓库四特征 + 体系结构「基础＝数据源 / 核心＝数据的存储与管理」→ ⑦ 信息安全 CIA + 四个层次 + 网络安全技术 + 对称 DES / 非对称 RSA → ⑧ 数据结构三大模型（最早＝层次、导航式＝网状、格式化＝层次+网状）→ ⑨ NoSQL 四类及代表 → ⑩ 网络协议三要素 + 802.3 / 802.11 → ⑪ 存储虚拟化 / 绿色存储 → ⑫ UEBA + 态势感知四技术 + 2.1.5 四方向趋势。
⚠️ 口径陷阱：① ARP / RARP 属网络层，不是应用层；② 应用层合并的是 OSI 的三层（会话+表示+应用）；③ OSI 教材原文是「从下到上」；④ 第 4 版 2.1.1 没有「五大部件」；⑤ 教材未给 PAN/LAN/MAN/WAN 的覆盖距离数字；⑥ DAS 与 NAS/SAN 不同层级（NAS/SAN 属网络化存储 FAS）；⑦ 存储虚拟化是「云存储」的核心技术，不是服务器虚拟化；⑧ 数据仓库「基础＝数据源 / 核心＝数据的存储与管理」别对调；⑨ 关系型支持 ACID，非关系型不保证遵循 ACID；⑩ 是「四个层次」（设备/数据/内容/行为），不是三层；⑪ 加密技术两个元素是「算法 + 密钥」；⑫「软件定义一切」属软件趋势，「可信计算」属安全趋势。

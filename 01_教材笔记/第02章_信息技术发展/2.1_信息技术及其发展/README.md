> - **第 4 版 2.1.1 只有两段**（硬件定义 + 软硬件关系），**没有「运算器 / 控制器 / 存储器 / 输入设备 / 输出设备五大部件」**的展开——那是计算机硬件基础类教材的通用口径，别当本节考点
> - 网络按作用范围的六类，教材**只给中英文全称，未给覆盖距离数字**（「PAN≈10m / LAN≈1km」是教辅补充）
> - OSI 教材原文是「**从下到上**」共分七层；部分教辅写成「从上到下」
> - **广域网协议在 OSI 的最下面三层操作**（不是最上面三层）
> - **ARP / RARP 属于网络层**（教材网络层协议明确为 IP、ICMP、IGMP、ARP、RARP）——本节最高频陷阱
> - **存储虚拟化是「云存储」的核心技术之一**（不是服务器虚拟化）；**DAS 与 NAS/SAN 不在同一层级**：外挂存储先按「连接的方式」分 DAS 与网络化存储（FAS），FAS 再按「传输协议」分 NAS 与 SAN
> - **数据仓库体系结构**：**数据源 = 系统的基础**，**数据的存储与管理 = 系统的核心**（两词每年都有人搞反）
> - 「**四个层次**」（设备 / 数据 / 内容 / 行为）与「**五个方面**」（计算机设备 / 网络 / 操作系统 / 数据库系统 / 应用系统）是两个不同维度的划分
> - 「**软件定义一切**」属**计算机软件**趋势；「**可信计算**」属**信息安全**趋势——最易互换的两个词

## 学习目标

- [ ] 说清**信息技术的两种形态**（硬技术=物化技术 / 软技术=非物化技术）与各自的举例；背出信息技术「以微电子学为基础的计算机技术和电信技术的结合」的定义
- [ ] 背出**计算机软硬件**的定义与关系：软件 = **程序 + 文档**（程序必须装入机器、文档给人看）；结论句「**硬件与软件在一定意义上来说没有绝对严格的界线**」
- [ ] 背熟**网络协议三要素**（语义 / 语法 / 时序）对应的通俗表述，**OSI 七层自下而上顺序**（物数网传会表应），**广域网协议七个**（PPP / ISDN / xDSL / DDN / x.25 / FR / ATM）
- [ ] 背熟 **IEEE 802.3（以太网 CSMA/CD）与 802.11（WLAN）**；**TCP/IP 四层 + 三条合并理由 + 各层协议归属**（应用层八协议 / 传输层 TCP·UDP / 网络层 IP·ICMP·IGMP·ARP·RARP）
- [ ] 说清 **SDN 核心思想（控制面与数据面分离）+ 三个平面（数据 / 控制 / 应用，由南到北）+ 三类接口**（南向 CDPI 有统一标准·主用 OpenFlow；北向 NBI 非统一标准；东西向管多控制器）
- [ ] 背出 **5G 三大特点 / 三大应用场景（eMBB / uRLLC / mMTC）** 与**关键指标**（空口时延 1ms、峰值速率 20Gbps、连接数密度 100 万/km²、用户体验速率 0.1~1Gbps）
- [ ] 背出**存储两层分类线索**与 **DAS / NAS / SAN** 的协议、传输对象、共享程度、适用场景；掌握选型口诀**「文件共享选 NAS · 数据库高性能选 SAN · 单机外接是 DAS」**
- [ ] 背出**存储虚拟化**（云存储核心技术）与**绿色存储**（容量 · 性能 · 能耗三者平衡）
- [ ] 背出**三大数据结构模型**（层次=最早·树 / 网状=导航式 / 关系=二维表）、**格式化数据模型 = 层次 + 网状**、**ACID**、**NoSQL 四类及代表**
- [ ] 背出**数据仓库四特征**（面向主题 / 集成 / 非易失 / 随时间变化）与**体系结构四部分的「基础 / 核心」归属**、**OLAP 三种实现（ROLAP / MOLAP / HOLAP）** 的数据存放
- [ ] 背出**信息安全 CIA 三属性**（中英文）、**四个层次**、**网络安全技术六项**、**加密两元素（算法 + 密钥）与对称 DES / 非对称 RSA**
- [ ] 说清 **UEBA（用户画像 + 异常检测 + 内部威胁）** 与**网络安全态势感知四技术**；背出 **2.1.5 四方向趋势**的关键词

## 易混防坑

1. **ARP / RARP 属网络层**，不属于应用层——本节最高频陷阱
2. **应用层合并的是 OSI 的三层**（会话层 + 表示层 + 应用层），不是两层；**TFTP** 也是应用层协议
3. OSI 是「**从下到上**」七层；**广域网协议在最下面三层**操作
4. **第 4 版 2.1.1 没有「五大部件」**内容，别按计算机硬件课的口径背
5. 教材**未给** PAN / LAN / MAN / WAN 的覆盖距离数字
6. IEEE 802 只需牢靠 **802.3 = 以太网（有线）**、**802.11 = WLAN（无线）**；802.5 = 令牌环、802.6 = 城域网
7. **SDN 南向接数据平面（有统一标准 · OpenFlow）· 北向接应用平面（无统一标准）**，方位别接反
8. 5G 三大特点里**没有「宏基站」**；NB-IoT / eMTC 属 2.1.5 的趋势技术，**不是** 5G 三大场景
9. **DAS 与 NAS/SAN 不同层级**：外挂存储 →（连接方式）DAS / FAS →（传输协议）NAS / SAN
10. **DAS 文档共享程度低、NAS 高**；**NAS 传文件、SAN 传数据块**
11. **存储虚拟化是「云存储」的核心技术**，不是服务器虚拟化
12. 绿色存储的「三者平衡」= **容量 · 性能 · 能耗**（不含安全 / 速度）
13. **层次 = 最早使用**；**网状 = 导航式**；**格式化数据模型 = 层次 + 网状**（关系模型不算）
14. 关系型**支持** ACID、非关系型**不保证遵循** ACID；NoSQL 四类 = 键值 / 列存储 / 面向文档 / 图形（Redis / HBase / MongoDB / Neo4j）
15. 数据仓库「**基础 = 数据源**」「**核心 = 数据的存储与管理**」，别对调；OLAP 按**多维模型**组织数据（不是二维表格）
16. 信息安全是「**四个层次**」（设备 / 数据 / 内容 / 行为），不是三层；「五个方面」是另一个维度
17. 加密技术两个元素 = **算法 + 密钥**；对称（私人密钥）密钥**相同** → DES；非对称（公开密钥）密钥**不同** → RSA
18. 「**软件定义一切**」属**软件**趋势；「**可信计算**」属**信息安全**趋势

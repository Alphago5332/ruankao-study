## 学习目标

- [ ] 背出**新一代信息技术的四个「化」基础**（智能化 / 系统化 / 微型化 / 云端化）与**六大技术**名单，说清它「是信息化发展的主要趋势，也是信息系统集成领域未来的重要业务范畴」
- [ ] 背出**物联网定义**（三个要素）与 **T2T / H2T / H2H** 三种互连，说清 **M2M** 的三种解释
- [ ] 背熟**物联网三层架构**各层的组成与职责（感知层＝识别物体、采集信息的来源；网络层＝**中枢**；应用层＝**和用户的接口**），记住**感知层设备清单**与「**以太网交换机不属于感知层**」这一真题
- [ ] 背出**物联网三项关键技术**（传感器技术 / 传感网 / 应用系统框架），说清 **RFID 属「传感器技术」**、赋予物联网**可跟踪性**；背出 **MEMS 五部件**与**应用系统框架 5 个技术部分**、**产业链五环节**
- [ ] 背出**云计算定义**（四种资源 + 「快速、按需、弹性」），背熟 **IaaS / PaaS / SaaS 各自提供的服务**与**三个反向陷阱**（在线办公→SaaS / 虚拟机→IaaS / 云数据库→PaaS）
- [ ] 说清**云计算四项关键技术**，能辨析**虚拟化 vs 多任务 vs 超线程**，知道**容器属操作系统虚拟化、代表环境是 Docker**；背出 **ABE 访问控制 4 个参与方**与**云安全研究的两个方面**
- [ ] 背出**大数据定义**（落点是「信息资产」）与**四个过程**，背熟**四大主要特征**、**「最显著特征＝数据处理速度快」**、**1PB/1EB/1ZB 换算链**
- [ ] 背出**大数据四类技术架构**、获取技术三步（采集 / 整合 / 清洗）与 **DPI·DFI 属带宽管理**、**Hadoop / Spark / Storm 的分工**、**存储三路线**、**可视化五类**
- [ ] 背出**区块链定义四要素**与**四大类链**，背熟**七大典型特征**（含「时序数据→可追溯性」「不可篡改」机理）、**三项关键技术**（分布式账本是核心之一）与**共识机制分析四维度**
- [ ] 背出**人工智能定义**（落点是「技术科学」）、**发展六阶段**、**技术研究三聚焦**、**四种新型学习方法**、**三大关键技术**；背熟**专家系统 6 个组成部分**与 **NLP 九项应用**
- [ ] 背出**人工智能应用和发展的三句原话**（「不能用」→「可以用」→ 距离「很好用」有瓶颈）与**趋势原话**（专用 → 通用）
- [ ] 背出**虚拟现实定义**（落点是「计算机系统」，虚拟世界是**全体虚拟环境的总称**）、**五大主要特征**、**按沉浸性/交互程度分类的演进链**（桌面 → 沉浸式 → 分布式 → AR / 元宇宙）与**四项关键技术**的归属辨析

## 易混防坑

1. **教材没有「4V」**——四条中文特征＝数据海量 / 类型多样 / 价值密度低 / 处理速度快；「真实性」不在其中
2. **「区分于传统数据挖掘的最显著特征」＝数据处理速度快**，不是「价值密度低」
3. **区块链是「四大类」**（含**混合链**），不是三类；教材用「**多中心化**」不用「去中心化」；数据结构是「**改进的**默克尔树」
4. **VR 主要特征是 5 条**（多感知性、自主性），不是业界「3I」
5. **RFID 属「传感器技术」**（不是独立的通信技术），它给物联网带来**可跟踪性**
6. **网络层是物联网的「中枢」**；「和用户的接口」是**应用层**
7. **应用系统框架 5 个技术部分**＝机器 / 传感器硬件 / 通信网络 / 中间件 / 应用（不是「感知层+网络层+应用层」）
8. **IaaS / PaaS / SaaS 三个反向陷阱**：在线办公软件＝SaaS；虚拟机 / 存储＝IaaS；虚拟的操作系统 / 数据库管理系统 / Web 应用＝PaaS
9. **容器属操作系统虚拟化**（不是硬件虚拟化）；最受欢迎的容器环境是 **Docker**
10. **云安全研究有两个方面**（保护云自身 + 用云保护用户），别只答一个
11. **ABE 访问控制 4 个参与方**＝数据提供者 / 可信第三方授权中心 / 云存储服务器 / 用户（2023 下真题）
12. **DPI / DFI 是带宽管理技术（用于网络流量采集）**，不是数据清洗技术
13. **看到「实时 / 在线」只选 Storm**；「离线复杂」是 Hadoop，「离线快速」是 Spark
14. **专家系统是 6 个部分**（人机交互界面 / 知识库 / 推理机 / 解释器 / 综合数据库 / 知识获取），**AI 发展是 6 个阶段**，别混
15. **四种新型学习方法**＝迁移 / 强化 / 多核 / 多视图（**没有深度学习**）；**神经网络 ⊂ 机器学习**、**强化学习 ⊂ 机器学习**
16. **「语音识别」「中文 OCR」都属 NLP 的应用**
17. **动态环境建模技术**＝建立虚拟环境模型（虚拟环境的建立是 VR 技术的**核心内容**）；**信息同步 / 模型标定 / 数据转换 / 识别与合成**属**系统集成技术**
18. **教材 2.2.2 没有部署模式段落**（公有云/私有云/混合云/社区云属中级与业界口径），别用它覆盖「三种服务类型」

2.2 总论 · 2.2.1 物联网
1新一代信息技术总论 + 物联网定义与三种互连
  • 四化奠基：信息技术在智能化、系统化、微型化、云端化的基础上不断融合创新，促进了新一代信息技术的诞生；新一代信息技术与信息资源充分开发利用形成的新模式、新业态，是信息化发展的主要趋势，也是信息系统集成领域未来的重要业务范畴
  • 六大技术：物联网 · 云计算 · 大数据 · 区块链 · 人工智能 · 虚拟现实
  • 物联网定义：物联网（The Internet of Things）是指通过信息传感设备，按约定的协议将任何物品与互联网相连接，进行信息交换和通信，以实现智能化识别、定位、跟踪、监控和管理的网络
  • 三种互连：物品与物品（Thing to Thing，T2T）· 人与物品（Human to Thing，H2T）· 人与人（Human to Human，H2H）
  • M2M：许多学者讨论物联网时会引入 M2M 概念，可解释为人与人（Man to Man）、人与机器（Man to Machine）或机器与机器（Machine to Machine）
口诀：四化奠基（智系微云）→ 六大技术（物云大区人虚）。定义三要素 = 信息传感设备 + 约定的协议 + 任何物品与互联网相连；四大功能动词 = 识别 / 定位 / 跟踪 / 监控 / 管理。⚠ T2T / H2T / H2H 三个缩写必须能对上号
2物联网三层架构（必考）
  • 感知层：由各种传感器构成，包括温度传感器、二维码标签、RFID 标签和读写器、摄像头、GPS 等感知终端；是物联网识别物体、采集信息的来源
  • 网络层：由各种网络组成，包括互联网、广电网、网络管理系统和云计算平台等；是整个物联网的中枢，负责传递和处理感知层获取的信息
  • 应用层：是物联网和用户的接口；它与行业需求结合以实现物联网的智能应用
口诀 感知采集 → 网络传递处理 → 应用落地（采 · 传 · 用）。⚠ 真题（2023 上）：「（ ）不属于物联网感知层设备」→ 答 以太网交换机；摄像头 / 温度传感器 / 二维码标签都是感知层。⚠ 「中枢」挂的是网络层，「和用户的接口」挂的是应用层
3物联网三项关键技术 + 产业链
  • ① 传感器技术：传感器是一种检测装置，「感受」被测量信息并变换成电信号等输出；是实现自动检测和自动控制的首要环节，也是物联网获取物理世界信息的基本手段。射频识别技术（RFID）是物联网中使用的一种传感器技术——可通过无线电信号识别特定目标并读写相关数据，而无须建立机械或光学接触；RFID 技术让物品能够「开口说话」，赋予了物联网可跟踪性（能随时掌握物品的准确位置及其周边环境）。RFID 是简单的无线系统，由询问器（阅读器）和很多应答器（标签）组成
  • ② 传感网：微机电系统（MEMS）由 微传感器 · 微执行器 · 信号处理和控制电路 · 通信接口 · 电源 等部件组成，是一体化的微型器件系统；目标是把信息的获取、处理和执行集成在一起。MEMS 赋予了普通物体新的「生命」——有了属于自己的数据传输通路、存储功能、操作系统和专门的应用程序，从而形成庞大的传感网
  • ③ 应用系统框架：以机器终端智能交互为核心的、网络化的应用与服务，涉及 5 个重要技术部分：机器 · 传感器硬件 · 通信网络 · 中间件 · 应用；该框架基于云计算平台和智能网络，依据传感网数据进行决策、改变对象的行为控制和反馈
  • 产业链：传感器和芯片 · 设备 · 网络运营及服务 · 软件与应用开发 · 系统集成；应用领域包括智能电网、智慧物流、智能家居、智能交通、智慧农业、环境保护、医疗健康、城市管理（智慧城市）、金融服务与保险业、公共安全等
三连速记：免接触读写 · 物品「开口说话」· 赋予物联网可跟踪性。MEMS 五部件口诀「感 · 执 · 号 · 通 · 电」；应用系统框架五部分口诀「机 · 感 · 通 · 中 · 用」；产业链五环节「芯 → 设备 → 网络 → 软件 → 集成」。⚠ 教材明确 RFID 是一种传感器技术
2.2.2 云计算
4云计算定义与三种服务类型（年年必考）
  • 定义：云计算是一种基于互联网的计算方式，将网络上配置为共享的软件资源、计算资源、存储资源和信息资源，按需求提供给网上的终端设备和终端用户；实现了「快速、按需、弹性」的服务（随时通过宽带网络接入「云」，按实际需求获取或释放资源，按需求动态扩展）
  • IaaS 基础设施即服务：向用户提供计算机能力、存储空间等基础设施方面的服务
  • PaaS 平台即服务：向用户提供虚拟的操作系统、数据库管理系统、Web 应用等平台化的服务
  • SaaS 软件即服务：向用户提供应用软件（如 CRM、办公软件等）、组件、工作流等虚拟化软件的服务；SaaS 一般采用 Web 技术和 SOA 架构
口诀：I 搭硬件 · P 搭平台 · S 直接用软件；判别法 = 看服务商交付什么。⚠ 三个反向陷阱：「在线办公软件」→ SaaS（不是 PaaS）；「租用虚拟机 / 存储」→ IaaS（不是 PaaS）；「云数据库 / 开发运行环境」→ PaaS（不是 IaaS）。⚠ 教材正文没有「公有云 / 私有云 / 混合云 / 社区云」部署模式段落（属中级与业界口径），别用它覆盖「三种服务类型」
5云计算四项关键技术（虚拟化 / 云存储 / 多租户与访问控制 / 云安全）
  • 四大关键技术：虚拟化技术 · 云存储技术 · 多租户和访问控制管理 · 云安全技术（口诀 虚 · 存 · 权 · 安）
  • 虚拟化技术：广义术语，指计算元件在虚拟的基础上而不是真实的基础上运行；可扩大硬件容量、简化软件重新配置；CPU 虚拟化可单 CPU 模拟多 CPU 并行，允许一个平台同时运行多个操作系统，各应用在相互独立的空间内运行而互不影响
  • 三者区别：多任务＝在一个操作系统中多个程序同时并行运行；虚拟化技术＝可同时运行多个操作系统，每个 OS 中都有多个程序运行、每个 OS 都运行在一个虚拟的 CPU 或虚拟主机上；超线程技术＝只是单 CPU 模拟双 CPU 平衡程序运行性能，两个模拟 CPU 不能分离、只能协同工作
  • 容器：容器（Container）技术是一种全新意义上的虚拟化技术，属于操作系统虚拟化的范畴（由操作系统提供虚拟化支持）；目前最受欢迎的容器环境是 Docker；容器把单个操作系统的资源划分到孤立的组中，以更好地平衡有冲突的资源使用需求
  • 云存储技术：分布式文件系统是云存储技术中的重要组成部分，在维持兼容性的基础上提升系统复制和容错功能；通过云集群管理实现可拓展性，解决网络存储、联合存储、多节点存储、备份处理、负载均衡等问题
  • 多租户和访问控制管理：访问控制管理是云计算应用的核心问题之一；研究集中在云计算访问控制模型 · 基于 ABE 密码体制的云计算访问控制 · 云中多租户及虚拟化访问控制研究；云中多租户及虚拟化访问控制是云计算的典型特征；基于 ABE 密码机制的云计算访问控制包括 4 个参与方：数据提供者 · 可信第三方授权中心 · 云存储服务器 · 用户；常见模型有基于任务 / 基于属性 / 基于 UCON / 基于 BLP 的访问控制
  • 云安全技术：两个方面——① 云计算技术本身的安全保护工作（数据完整性及可用性、隐私保护性、服务可用性）；② 借助于云服务的方式来保障客户端用户的安全防护需求（基于云计算的病毒防治、木马检测技术等）。主要包含：云计算安全性 · 保障云基础设施的安全性 · 云安全技术服务
一句话辨析：多任务＝一个 OS 跑多程序；虚拟化＝多个 OS 各跑多程序；超线程＝单 CPU 假装双 CPU 且不可分离。⚠ 容器属操作系统虚拟化；ABE 四个参与方是 2023 下真题原题；云安全两个方面是「保护云自身 + 用云保护用户」一内一外
2.2.3 大数据
6大数据定义 · 四个过程 · 四大主要特征
  • 定义：大数据（Big Data）指无法在一定时间范围内用常规软件工具进行捕捉、管理和处理的数据集合，是具有更强的决策力、洞察发现力和流程优化能力的海量、高增长率和多样化的信息资产（落点是「信息资产」）
  • 四个过程：从数据源到最终价值实现一般经过 数据准备 → 数据存储与管理 → 数据分析和计算 → 数据治理和知识展现
  • 四大主要特征：数据海量（TB → PB → EB，甚至 ZB）· 数据类型多样（分结构化数据和非结构化数据，后者含网络日志、音频、视频、图片、地理位置信息等）· 数据价值密度低（价值密度高低与数据总量大小成反比；1 小时视频有用数据可能仅一二秒，需靠机器算法做价值「提纯」）· 数据处理速度快（这是大数据区分于传统数据挖掘的最显著特征）
  • 单位换算链：1PB = 1024TB · 1EB = 1024PB · 1ZB = 1024EB
口诀 量 · 样 · 值 · 速。⚠⚠ 最大陷阱：教材用的是「数据海量 / 数据类型多样 / 数据价值密度低 / 数据处理速度快」四条中文表述，教材正文没有「4V」这个说法（Volume/Variety/Value/Velocity 属业界口径，且「真实性」不在教材四条里）。「最显著特征」这一问的答案只能是「数据处理速度快」
7大数据四类技术架构
  • 四类：大数据获取技术 · 分布式数据处理技术 · 大数据管理技术 · 大数据应用和服务技术
  • ① 大数据获取技术：集中在 数据采集 · 整合 · 清洗 三方面。数据采集靠分布式爬取、分布式高速高可靠性数据采集、高速全网数据映像技术；对网络流量的采集可使用 DPI 或 DFI 等带宽管理技术；数据整合在数据采集和实体识别基础上实现数据到信息的高质量整合；数据清洗按正确性条件和数据约束规则清除不合理和错误数据、修复重要信息，保证数据完整性
  • ② 分布式数据处理技术：核心是将任务分解成许多小的部分，分配给多台计算机进行处理，通过并行工作机制达到节约整体计算时间、提高计算效率；主流系统三个：Hadoop（离线的、复杂的大数据处理）· Spark（离线的、快速的大数据处理）· Storm（在线的、实时的大数据处理）
  • ③ 大数据管理技术：集中在 大数据存储 · 大数据协同 · 安全隐私。存储三条路线：采用 MPP 架构的新型数据库集群（列存储、粗粒度索引）· 围绕 Hadoop 衍生的相关大数据技术（扩展和封装 Hadoop 应对传统关系型数据库较难处理的场景）· 大数据一体机（集成的服务器、存储设备、操作系统、数据库管理系统）。多数据中心协同靠分布式工作流引擎实现工作流调度、负载均衡。隐私技术集中于新型数据发布技术，⚠ 教材明确数据信息量与隐私之间存在矛盾，目前没有非常好的解决办法
  • ④ 大数据应用和服务技术：含 分析应用技术 与 可视化技术。可视化通过交互式视觉表现帮助人们探索和理解复杂数据，集中在 文本可视化 · 网络（图）可视化 · 时空数据可视化 · 多维数据可视化 · 交互可视化；技术方面关注原位交互分析、数据表示、不确定性量化和面向领域的可视化工具库
口诀：获取三步「采集 → 整合 → 清洗」；三系统「Hadoop 离线复杂 · Spark 离线快速 · Storm 在线实时」（看到「实时/在线」只选 Storm）；存储三路「MPP 集群 / Hadoop 生态 / 大数据一体机」；可视化五类「文 · 图 · 时空 · 多维 · 交互」。⚠ DPI / DFI 是带宽管理技术（采集用），不是清洗技术
2.2.4 区块链
8区块链定义 · 四大类 · 七大典型特征
  • 定位：区块链技术具有多中心化存储、隐私保护、防篡改等特点，提供了开放、分散和容错的事务机制，成为新一代匿名在线支付、汇款和数字资产交易的核心
  • 定义四要素：区块链可理解为以非对称加密算法为基础，以改进的默克尔树（Merkle Tree）为数据结构，使用共识机制、点对点网络、智能合约等技术结合而成的一种分布式存储数据库技术
  • 四大类：公有链（Public Blockchain）· 联盟链（Consortium Blockchain）· 私有链（Private Blockchain）· 混合链（Hybrid Blockchain）
  • 七大典型特征：多中心化 · 多方维护 · 时序数据 · 智能合约 · 不可篡改 · 开放共识 · 安全可信
    要点对应
    • 多中心化：链上数据的验证、核算、存储、维护和传输均依赖分布式系统结构，用纯数学方法代替中心化组织机构在节点间构建信任关系
    • 多方维护：激励机制确保所有节点均可参与数据区块的验证，并通过共识机制选择特定节点把新产生的区块加入链中
    • 时序数据：运用带时间戳信息的链式结构存储数据，为数据添加时间维度属性，从而实现数据信息的可追溯性
    • 不可篡改：相邻区块间后序区块可对前序区块进行验证；篡改某一区块需递归修改该区块及其所有后序区块，而每次哈希重新计算代价巨大且须在有限时间内完成
    • 开放共识：每台物理设备均可作为节点，任意节点可自由加入且拥有一份完整的数据库拷贝
    • 安全可信：靠基于非对称加密技术对链上数据加密；各节点靠共识算法形成的算力抵御外部攻击，保证数据不被篡改和伪造
七特征口诀 中 · 维 · 时 · 约 · 篡 · 共 · 信。⚠⚠ 最大陷阱：教材是「四大类」（含混合链），不是常说的「公有链 / 联盟链 / 私有链」三类。⚠ 教材用「多中心化」而非「去中心化」；数据结构叫「改进的默克尔树」；归因速记：时序数据 → 可追溯性
9区块链三项关键技术 + 共识机制四维度
  • ① 分布式账本：是区块链技术的核心之一。核心思想是交易记账由分布在不同地方的多个节点共同完成，且每一个节点保存一个唯一、真实账本的副本，它们可以参与监督交易合法性并共同为其作证；账本里任何改动都会在所有副本中被反映出来，反应时间在几分钟甚至几秒内；记账节点足够多，理论上除非所有节点被破坏，整个系统非常稳健，从而保证账目数据的安全性。账本存储的资产指法律认可的合法资产（金融、实体、电子等任何形式的有价资产）；安全性靠公私钥及签名控制访问权 + 共识规则决定更新由一个、一部分人或所有参与者共同完成
  • ② 加密算法：区块数据的加密是区块链研究和关注的重点，作用是保证数据在网络传输、存储和修改过程中的安全；区块链系统的加密算法一般分为 散列（哈希）算法 和 非对称加密算法
  • ③ 共识机制：共识算法能保证分布式的计算机或软件程序协作一致，对系统输入输出做出正确的响应。思想是在没有中心点总体协调的情况下，某记账节点提议区块数据增减并广播给所有参与节点，各节点按一定规则和机制计算处理是否达成一致。常用机制：PoW · PoS · DPoS · Paxos · PBFT
  • 共识机制分析四维度：合规监管（是否支持超级权限节点对全网节点、数据进行监管）· 性能效率（交易达成共识被确认的效率）· 资源消耗（耗费的 CPU、网络输入输出、存储等资源）· 容错性（防攻击、防欺诈的能力）
三技术口诀 账本 · 加密 · 共识；四维度口诀 管 · 效 · 耗 · 容。⚠ 「分布式账本是区块链技术的核心之一」这句教材原话要能填；两大要点＝每节点保存唯一真实账本副本 + 改动会在所有副本中被反映
2.2.5 人工智能 · 2.2.6 虚拟现实
10人工智能：定义 · 六阶段 · 三聚焦 · 三关键技术
  • 定义：人工智能是指研究和开发用于模拟、延伸和扩展人类智能的理论、方法、技术及应用系统的一门技术科学（落点是「技术科学」，三个动词是模拟 / 延伸 / 扩展）
  • 发展六阶段：起步发展期（1956 年至 20 世纪 60 年代初）→ 反思发展期（60 年代初至 70 年代初）→ 应用发展期（70 年代初至 80 年代中）→ 低迷发展期（80 年代中至 90 年代中）→ 稳步发展期（90 年代中至 2010 年）→ 蓬勃发展期（2011 年至今）
  • 技术研究三聚焦：热点技术 · 共性技术 · 新兴技术；四种新型学习方法＝迁移学习 · 强化学习 · 多核学习 · 多视图学习（⚠ 没有「深度学习」）；自然语言处理的特征提取、语义分类、词嵌入等基础技术与智能自动问答、机器翻译等应用研究也取得成果；以知识图谱、专家系统为逻辑的系统化分析不断突破
  • 三大关键技术：机器学习 · 自然语言处理 · 专家系统
  • 机器学习：一种自动将模型与数据匹配，并通过训练模型对数据进行「学习」的技术；神经网络是机器学习的一种形式（出现在 20 世纪 60 年代，用于分类型应用程序，靠输入、输出、变量权重或「特征」分析问题）；强化学习是机器学习的另外一种方式（制订了目标，且迈向目标的每一步都会得到某种形式的奖励）；机器学习模型以统计为基础，比传统「手工」分析模型更准确但也更复杂、难以解释；自动化机器学习模型更容易创建且能揭示更多数据细节
六阶段口诀 起步 → 反思 → 应用 → 低迷 → 稳步 → 蓬勃（一条高开—低落—再起的曲线）。归属三连：神经网络 ⊂ 机器学习、强化学习 ⊂ 机器学习、机器学习以统计为基础。⚠ 强化学习关键词＝「目标 + 每一步的奖励」
11NLP · 专家系统 · AI 应用和发展
  • 自然语言处理（NLP）：计算机科学领域与人工智能领域中的一个重要方向，研究能实现人与计算机之间用自然语言进行有效通信的各种理论和方法；主要应用于 9 项：机器翻译 · 舆情监测 · 自动摘要 · 观点提取 · 文本分类 · 问题回答 · 文本语义对比 · 语音识别 · 中文 OCR
  • 专家系统：是一个智能计算机程序系统，通常由 6 个部分构成：人机交互界面 · 知识库 · 推理机 · 解释器 · 综合数据库 · 知识获取；内部含有大量某个领域专家水平的知识与经验，能进行推理和判断、模拟人类专家的决策过程，解决需要人类专家处理的复杂问题；简言之是模拟人类专家解决领域问题的计算机程序系统。专家系统的发展已经历了三个阶段，正向第四代过渡和发展
  • 应用和发展：经过 60 多年发展，人工智能在 算法、算力（计算能力）和算料（数据） 等方面取得重要突破，正处于从「不能用」到「可以用」的技术拐点，但是距离「很好用」还存在诸多瓶颈；实现从专用人工智能向通用人工智能的跨越式发展，既是下一代人工智能发展的必然趋势，也是研究与应用领域的重大挑战
NLP 九项口诀 译 · 情 · 摘 · 观 · 分 · 答 · 比 · 听 · 认；专家系统六部分口诀 界 · 库 · 机 · 释 · 数 · 取（最核心两件＝知识库 + 推理机）；三「料」＝算法 · 算力 · 算料。⚠ 三句引号原话最易考：「不能用」→「可以用」→ 距离「很好用」有瓶颈；趋势方向是专用 → 通用，别接反。⚠「语音识别」与「中文 OCR」都属 NLP 的应用
12虚拟现实：定义 · 五大特征 · 演进 · 四项关键技术
  • 定义：虚拟现实（Virtual Reality，VR）是一种可以创立和体验虚拟世界的计算机系统；其中虚拟世界是全体虚拟环境的总称（落点是「计算机系统」）
  • 五大主要特征：沉浸性 · 交互性 · 多感知性 · 构想性（也称想象性）· 自主性
  • 发展演进：按照其「沉浸性」程度的高低和交互程度的不同，虚拟现实技术已经从 桌面虚拟现实系统 → 沉浸式虚拟现实系统 → 分布式虚拟现实系统 等，向着增强式虚拟现实系统（Augmented Reality，AR）和元宇宙的方向发展
  • 四项关键技术：
    ① 人机交互技术
    一种新型的利用 VR 眼镜、控制手柄等传感器设备，能让用户真实感受到周围事物存在的一种三维交互技术
    ② 传感器技术
    是 VR 技术更好地实现人机交互的关键
    ③ 动态环境建模技术
    虚拟环境的建立是 VR 技术的核心内容；目的是获取实际环境的三维数据，并根据应用需要利用获取的三维数据建立相应的虚拟环境模型；三维数据可用 CAD 技术或非接触式的视觉建模技术获取，两者结合可有效提高数据获取效率
    ④ 系统集成技术
    由于 VR 系统中包括大量的感知信息和模型，因此系统的集成技术至关重要；集成技术包括信息同步技术 · 模型标定技术 · 数据转换技术 · 数据管理模型 · 识别与合成技术等
⚠⚠ 最大陷阱：业界常说「VR 三特征（3I）＝沉浸性 / 交互性 / 构想性」，但教材写的是 5 条，多出「多感知性」和「自主性」。四技术口诀 交互 · 传感 · 建模 · 集成；归属辨析：「建立虚拟环境模型」→ 动态环境建模技术；「信息同步 / 数据转换 / 模型标定 / 识别与合成」→ 系统集成技术；「VR 眼镜 / 控制手柄三维交互」→ 人机交互技术
总结区 本节本质 + 考点地图
本节本质：2.2 是第 2 章的收束节，把 2.1 的「技术底座」接到了「六大新一代信息技术」上。全节**没有计算**（唯一的数字化内容是**数据量单位换算**），题型固定为三类——定义与特征的匹配、层级与分类的排序、关键技术的归属。本节内部主线是一条链：物联网（感知与连接）→ 云计算（算力供给）→ 大数据（数据资产）→ 区块链（信任机制）→ 人工智能（智能算法）→ 虚拟现实（交互界面），即「感 → 算 → 数 → 信 → 智 → 显」。
考点地图（按考频排序）：① 云计算三种服务类型 IaaS / PaaS / SaaS（年年必考，三方反向陷阱）→ ② 大数据四大主要特征＋「最显著特征＝处理速度快」＋单位换算 → ③ 物联网三层架构（感知层设备清单 + 「中枢」归网络层）→ ④ 区块链七大特征 + 四大类链（「四大类」「多中心化」）→ ⑤ 人工智能三大关键技术 + 专家系统 6 部分 → ⑥ VR 五大特征 + 四项关键技术归属 → ⑦ Hadoop / Spark / Storm 分工 → ⑧ 虚拟化 vs 多任务 vs 超线程＋容器属操作系统虚拟化 → ⑨ ABE 访问控制四参与方＋云安全两方面 → ⑩ 区块链三技术（分布式账本为核心之一）＋共识机制四维度 → ⑪ NLP 九项应用 → ⑫ 物联网三项关键技术（RFID 属传感器技术）+ 产业链五环节。
⚠️ 口径陷阱：① 教材没有「4V」这个说法，四条中文表述＝数据海量 / 类型多样 / 价值密度低 / 处理速度快；② 区块链是「四大类」含混合链（不是三类），用词是「多中心化」不是「去中心化」；③ VR 是 5 条特征（多感知性、自主性），不是 3I；④ RFID 是「传感器技术」；⑤ 网络层是物联网的「中枢」，应用层才是「和用户的接口」；⑥ 容器属操作系统虚拟化；⑦ 云安全是「保护云自身 + 用云保护用户」两方面；⑧ DPI / DFI 属带宽管理（采集）；⑨ 「实时/在线」数据处理只选 Storm；⑩ 教材 2.2.2 正文没有公有云 / 私有云 / 混合云 / 社区云部署模式；⑪ 专家系统是六个部分，AI 发展是六个阶段，别混；⑫ 「语音识别、中文 OCR 属 NLP 应用」。

## 易混防坑

1. **术语澄清**：讲的是「**信息安全系统工程**」（ISSE），**不是**「信息系统安全工程」——后者字面会误解为「安全地建一个信息系统」
2. **两组术语**：信息系统（业 + 安）/ 信息系统工程（业工 + 安工）——「系统」与「工程」两层别串行
3. **安全空间三维**：X 机制 / **Y OSI 网络参考模型** / Z 服务——中间是 OSI，**不是「安全技术」**
4. **三组数量别对调**：安全机制 **9** / 安全服务 **6** / 安全技术 **6** / 安全空间五属性 **5**
5. **安全机制 9 项 vs 安全服务 6 项**：「数据保密服务」是**服务**不是机制；「平台安全 / 数据安全 / 安全防范体系」是**机制**
6. **安全技术含「数据挖掘」**——这一项别漏，也别把它错当成安全服务
7. **对等实体认证 vs 数据源点认证**：前者确认对方实体合法性、真实性；后者确保数据**发自真正的源点**——别对调
8. **WPDRRC**：预警·保护·检测·反应·**恢复·反击**（六个环节）；组织安全防范体系核心 = **EISRM**
9. **ISSE-CMM 别与软件 CMM / CSMM 混**：它是「信息安全**系统工程**」CMM，适用工程 / 获取 / 评估三类组织
10. **有害事件三组成 = 威胁 + 脆弱性 + 影响**（不是「风险 + 威胁 + 脆弱性」）
11. **ISSE-CMM 域维 = 22 个过程域**：11 个**安全工程过程域**（PA01~PA11）+ 11 个**项目 / 组织过程域**（PA12~PA22）——「保证质量」属后者
12. **5 级能力级别**：**非规充量持**——L2「规划和跟踪级」、L3「充分定义级」，**别套用软件 CMM 的「已定义级 / 量化管理级」**
13. 旧真题（第 3 版第 3 章同源）可刷「信息安全工程」部分；**2023 下以后第 5 章真题优先**

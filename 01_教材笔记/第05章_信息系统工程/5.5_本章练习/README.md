## 章节重点（整章收束）

第 5 章综合知识约 **5~8 题**，是上午题「提分大户」；内容与第 3 版第 3 章同源，**旧真题有对应题可刷**。特点：

- **全部是选择题考点**：无计算主线；题型四类——**分类归属 / 定义挖空 / 数量配对 / 层次排序**
- **数字型考点极密**：五大风格 / 三类评估方式 / 需求三层次 / 七原则 / 三类设计模式 / 三类数据模型 / 备份三策略 / 可视化七类 / 集成四原则 / 七子系统 / EAI 四层次 / 安全机制 9 / 服务 6 / 技术 6 / 8 类工程 / 22 过程域 / 5 级能力
- **教材页数分布提示重点**：5.1.2 需求分析 7 页、5.4.4 工程体系架构 7 页，是两处绝对重头

**整章最容易丢分的 8 处**（考前只看这一块）：

1. **五大架构风格归属**：层次结构 → 调用/返回；事件驱动 → 独立构件；解释器 → 虚拟机；黑板系统 → 仓库（四条归属错一条就丢分）
2. **敏感点（单个质量属性）vs 权衡点（多个）**；三类评估方式中**基于场景最常用**，ATAM / SAAM / CBAM **都属场景法**
3. **SA 的核心是数据字典**（不是 DFD）；三模型配对「数据-**E-R** / 功能-**DFD** / 行为-**STD**」；**UML 五视图 ≠ 4+1 视图**
4. **白盒黑盒三线同时对应**（别名 / 阶段 / 方法）；**静态测试不运行程序**（桌前检查 / 代码走查 / 代码审查，无「边界值分析」）
5. **三组「数量 + 配对」大混战**：安全机制 **9** / 安全服务 **6** / 安全技术 **6**（技术含数据挖掘）· 安全空间五属性「认权完加不可否认」· 数据可视化 **7** 类
6. **RPO 丢数据量 / RTO 恢复时间**（年年对调）；备份策略教材用词「**差分**」非「差异」；**备份是容灾的基础**（容灾是工程不只是技术）
7. **一句话两个「核心」**：「网络的核心」= **传输子系统** vs「网络应用的核心」= **服务子系统**；**数据集成是 EAI 唯一白盒**；异构数据集成教材说「**两种 + 另一类**」
8. **三套 CMM 别混**：ISSE-CMM（域维 **22** 过程域 = 安全工程 **11** 个 + 项目组织 11 个；五级「**非规充量持**」）· CMMI（初始/已管理/已定义/量化管理/优化）· CSMM（初始/项目规范/组织改进/量化提升/创新引领，4 域 20 子域 161 要求）

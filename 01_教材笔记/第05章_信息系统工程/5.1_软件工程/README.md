## 易混防坑

1. **SA 核心是数据字典**，不是 DFD；「数据-E-R / 功能-DFD / 行为-STD」三对配对年年考、别对调
2. **层次结构 → 调用/返回**；**事件驱动 → 独立构件**；**解释器 → 虚拟机**；**黑板系统 → 仓库**——风格归属四个最高频对位
3. **「影响多个质量属性」= 权衡点**（敏感点只影响一个）；ATAM / SAAM / CBAM 都是**基于场景**的评估方式
4. **QFD 判别词**：「想当然」= 期望需求、「实现越多越满意」= 常规需求、「兴奋需求 / 范围外」= 意外需求
5. **UML 五视图 ≠ 4+1 视图**：教材口径是逻辑 / 进程 / 实现 / 部署 / 用例；「用例视图是最基本的需求分析模型」
6. **白盒三线**：别名「结构测试」+ 阶段「单元测试」+ 方法「逻辑覆盖」；**黑盒三线**：别名「功能测试」+ 阶段「集成/确认/系统」+ 方法「等价类/边界值」——三线错一条就掉坑
7. **静态测试**不运行程序（桌前检查 / 代码走查 / 代码审查 + 文档检查单），且**静态方法也可实现白盒测试**
8. **蓝绿 = 两套环境整体切换（域名解析）**；**金丝雀 = 小流量灰度验证**——两者对调是高频坑
9. **CSMM ≠ CMMI**：教材 5.1.6 讲 **CSMM**，五级「初始 / 项目规范 / 组织改进 / 量化提升 / 创新引领」；CMMI 的「已管理 / 已定义」不在 CSMM 序列里
10. **概要设计 = 总体结构设计**（别称，不是新阶段）；SD 基本原则**高内聚低耦合**
11. **部署层次 Build → Ship → Run**：编译出包 → 装依赖 → 启动环境，顺序别乱；**不可变服务器**= 只打补丁、不做其他更改
12. 旧真题（第 3 版第 3 章同源）可刷「软件工程」部分；**2023 下以后第 5 章真题优先**

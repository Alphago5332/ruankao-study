> - **四大原则 = 开放性、结构化、先进性、主流化**；开放性 = 遵循**工业开放标准**（三「可」= 可互操作 / 可移植 / 可伸缩）；结构化 = **自顶向下逐层模块化分解**

> - **EAI 黑白盒**：表示集成**黑盒** / 数据集成**白盒**（唯一白盒） / 控制集成**黑盒**
> - **语法·语义·语用**：网络集成解决**语法**、数据集成解决**语义**、应用集成解决**语用**
> - COM 的对象是**二进制代码对象**（DLL / EXE）；**「提升到应用层」→ COM+**

## 易混防坑

1. **网络集成子系统数**：高项第 4 版 = **七个**（含服务器子系统、网络操作系统）；中级第 3 版 = **五大**——别混卷
2. **异构数据集成方法**：教材口径 **两种**（过程式 / 声明式）+ **另一类**（中间件）——**别答「三种」**
3. **黑白盒配对**：表示集成**黑盒** / 数据集成**白盒**（唯一）/ 控制集成**黑盒**——「业务逻辑层黑盒集成」指**控制集成**
4. **语法·语义·语用**：网络=语法 / 数据=语义 / 应用=语用——三句一一对应别接错
5. **过程式 vs 声明式**：过程式 = 点对点（Ad-hoc）+ Wrapper / Mediator；声明式 = 统一建模 + **推理机制**——别对调
6. **数据集成四层次**：基本（通用标识符 + 数据丢失）/ 多级视图（三级两级映射）/ 模式（语义冲突 + 三等价）/ 多粒度（综合 + 细化）
7. **COM vs COM+**：COM 对象是**二进制代码对象**（DLL / EXE）；COM+ 把组件**提升到应用层**
8. **.NET vs J2EE 技术清单**：C# / VB / ASP.NET / ADO.NET → .NET；EJB / Servlet / JSP → J2EE
9. **「网络应用的核心」= 服务子系统**；「网络的核心」= 传输——一句话两个「核心」分属不同子系统
10. **EDA** 的要点是「**模块之间不需要知道对方**」+「发布 / 订阅」+「一事件多订阅者」——反向表述（必须知道对方）是错误项
11. 旧真题（第 3 版第 3 章同源）可刷「系统集成」部分；**2023 下以后第 5 章真题优先**

## 口径备忘（2026-10-09 核对）

### 5.1 口径（三方交叉核对）

- 核对方式：**第 4 版纸质教材手敲整理（CSDN 两个独立版本）+ 信管网考点考题梳理 + 知犀思维导图**三方交叉核对；清华社样章 PDF **不含第 5 章**，无法逐字比对
- 5.1 高危误记已固化：
  1. **SA 的核心是数据字典**（不是 DFD）；三模型配对「数据-E-R / 功能-DFD / 行为-STD」别对调
  2. **架构风格归属**：层次结构→调用/返回；事件驱动→独立构件；解释器→虚拟机；黑板系统→仓库
  3. **敏感点影响单个质量属性；权衡点影响多个**（=多个质量属性的敏感点）；ATAM / SAAM / CBAM 都**基于场景**（最常用）
  4. **QFD 判别词**：「想当然」=期望需求、「实现越多越满意」=常规需求、「兴奋需求/范围外」=意外需求
  5. **UML 五视图**（逻辑/进程/实现/部署/用例）是教材口径，「用例视图是最基本的需求分析模型」；**≠ 架构师考试的「4+1 视图」**
  6. **白盒 = 结构测试 = 单元测试 = 逻辑覆盖**；**黑盒 = 功能测试 = 集成/确认/系统测试 = 等价类/边界值**——三线同时对上
  7. **概要设计又称总体结构设计**；SD 基本原则高内聚低耦合
  8. **蓝绿部署 = 新旧两版本域名解析整体切换、可快速回滚**；**金丝雀部署 = 少量用户灰度先行**——别对调
  9. **CSMM ≠ CMMI**：CSMM（5.1.6 讲的模型）五级「初始 / 项目规范 / 组织改进 / 量化提升 / 创新引领」，结构 = 4 能力域 / 20 能力子域 / 161 能力要求
  10. **部署层次 Build→Ship→Run**（编译出包→装依赖→启动环境）；**不可变服务器** = 除打补丁外不做任何更改

### 5.2 口径（2026-10-09 多方交叉核对）

- 5.2 高危误记已固化：
  1. **元数据 = 关于数据的数据**；**数据元 = 数据库、文件和数据交换的基本数据单元**（三要素：对象 / 特性 / 表示「对特表」）
  2. **建模四步产出**：需求分析→数据流图；**概念模型设计→E-R 图**；**逻辑模型设计→关系模式**；物理模型设计→针对具体 DBMS
  3. **提取法「新上旧下」**：新建系统→自上而下（Top-Down）；已建系统→自下而上（Down-Top）
  4. **图描述（IDEFIX/UML）→实体和实体相互关系**；**数据字典→数据集、单个实体、属性的摘要信息**
  5. **数据标准化 = 实现数据共享的基础**；五大内容「元元模分管」；管理四阶段「需制批施」
  6. **数据备份是数据容灾的基础、是数据高可用的最后一道防线**；**数据容灾是应用容灾的子集**；容灾是**工程**不只是技术
  7. **RPO = 灾难发生时允许丢失的数据量；RTO = 系统恢复的时间**（P 丢数据、T 恢复时间）
  8. 备份策略三件教材用词是「**差分备份**」不是「差异备份」；四结构 DAS / 基于LAN / LAN-FREE / SERVER-FREE
  9. **评价两法「直比间推」**（与参照信息对比=直接；利用相关信息推断=间接）；**清理三步「析检修」**（分析→检测→修正）
  10. **挖掘五任务「总关分聚孤」**、流程五阶段「定备挖评用」；**可视化七类**（一/二/三/多维+时态+层次+网络）；**检索四方法含数据挖掘**（教材原口径）
  11. **安全机制五项「身存密审推」**（身份认证/存取控制/数据库加密/数据审计/推理控制）；**标识和认证=第一道安全防线**
  12. ⚠️ **两处「三完整」跨小节**：5.2.1 关系完整性约束（实体/参照/用户定义）≠ 5.2.5 数据库安全三种完整性（数据库/操作/语义）

  1. **系统集成「专指计算机系统的集成」**；三内容 = 技术环境 / 数据环境 / 应用程序 的集成
  2. **四大原则 = 开放性、结构化、先进性、主流化**；开放性 = 遵循**工业开放标准**（三「可」= 互操作 / 移植 / 伸缩）；结构化 = **自顶向下逐层模块化分解**；先进性 = **目前 + 未来**两层意义
  3. **网络集成体系框架高项第 4 版 = 七个子系统**（传输 / 交换 / 安全 / 网管 / **服务器** / **网络操作系统** / 服务）；中级第 3 版 = 五大子系统（无服务器子系统和网络操作系统）
  4. 「**网络的核心**」= 传输子系统；「**网络应用的核心**」= 服务子系统——一句话两个「核心」别串
  5. **数据仓库技术是数据集成的关键**；数据集成四层次「基·多视·模·多粒」
  6. **异构数据集成方法教材口径 = 两种**（过程式 / 声明式）+ **另一类**（中间件）——**别答「三种」**；过程式 = 点对点 Ad-hoc + Wrapper/Mediator；声明式 = 统一建模 + 推理机制
  7. **多级视图集成** = 底层（局部模型）→ 中间层（公共模型）→ 高层（综合模型），**两级映射**；**模式集成**三等价 = 属性 / 关联 / 类
  8. **软件集成五大构件标准** = CORBA / COM / DCOM 与 COM+ / .NET / J2EE；**COM 对象 = 二进制代码对象（DLL/EXE）**，五特征「对·客·语·进·可」
  9. **.NET 涉及 VB·C++·C#·JScript·ASP.NET·ADO.NET**；**J2EE 涉及 EJB·Java Servlets API·JSP·XML**，体系结构四层 = 客户端层 / 服务器端组件层 / EJB / 信息系统层；**「提升到应用层」= COM+**
  10. **应用集成（EAI）技术三要求** = 互操作性 / 可移植性 / 透明性；可协调连接组件三件 = API / 事件驱动型操作 / 数据映射
  11. **EAI 四层次 + 黑白盒**：表示集成**黑盒** / 数据集成**白盒**（唯一）/ 控制集成**黑盒**；「在业务逻辑层上进行黑盒集成」→ 控制集成
  12. **语法·语义·语用**：**网络集成解决语法、数据集成解决语义、应用集成解决语用**（教材 P169 原句）

## 易混防坑

1. **两套「四要素」**：运维能力建设 = 人员 / 过程 / 技术 / 资源（4 项，口诀「人过技资」）；智能运维能力要素 = 人员 / 技术 / 过程 / 数据 / 算法 / 资源 / 知识（7 项，口诀「人技过数算资知」）——**四要素 ⊆ 七要素**，多点「数据 / 算法 / 知识」
2. **四个数据管理模型量词**：DCMM **五等级**（+8 能力域）· DGI **三维度**（+10 组件）· DCAM **四组件** · DAMA **十一域**（+7 要素）
3. **DCMM 稳健级 vs 量化管理级**：稳健级 = 组织层面标准化流程 +「实现组织**绩效目标**」的重要资产；量化管理级 =「获取**竞争优势**」的重要资源 + 量化分析监控
4. **教材用「保密性」**（Confidentiality），不是「机密性」；CIA 是基础但**并非全部**（还需合规性、可追溯性）
5. **智能运维两组四环节别混**：「场景实现」= 场景分析 · **场景构建** · 场景交付 · **效果评估**；「能力应用」= 场景分析 · **能力构建** · 服务交付 · **迭代调优**
6. **等保两个五级**：安全保护等级五级（按**破坏后果**：公民→社会→国家）≠ 安全保护能力五级（GB/T 22239，按**威胁源 + 恢复程度**）
7. **「能力要素」是构建智能运维能力的基础**（真题原句，最爱挖空）
8. **元数据管理属数据架构**、**指标数据属数据标准**——DCMM 能力项最爱挂错域
9. **人员三岗位「管技操」**（管理类 / 技术类 / 操作类）；**资源四件**「知识库 / 服务台 / 备件库 / 运维工具」
10. 本章旧真题无存货（第 4 版新增章），练题以本节自测题 + 2024 以后回忆题 + 教辅章节题为主

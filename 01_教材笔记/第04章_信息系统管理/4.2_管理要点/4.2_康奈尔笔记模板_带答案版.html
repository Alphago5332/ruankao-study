4.2.1 数据管理
1数据管理的定义
  • 定义：数据管理是指通过规划、控制与提供数据和信息资产的职能，包括开发、执行和监督有关数据的计划、策略、方案、项目、流程、方法和程序，以获取、控制、保护、交付和提高数据和信息资产价值
  • DAMA：国际数据管理协会，指出数据资源管理致力于发展和处理组织数据全生命周期的适当的构建、策略、实践和程序
  • 数据管理框架：是对组织的管理平台或能够产生业务数据的平台产生的数据进行统一的跟踪、协调、管理的功能模型
口诀：三职能「规划 · 控制 · 提供」+ 五价值「获取 · 控制 · 保护 · 交付 · 提高」；DAMA = 国际数据管理协会
2DCMM 的 8 个核心能力域（国标 GB/T 36073）
  • 数据战略（数据战略规划 / 数据战略实施 / 数据战略评估）
  • 数据治理（数据治理组织 / 数据制度建设 / 数据治理沟通）
  • 数据架构（数据模型 / 数据分布 / 数据集成与共享 / 元数据管理）
  • 数据应用（数据分析 / 数据开放共享 / 数据服务）
  • 数据安全（数据安全策略 / 数据安全管理 / 数据安全审计）
  • 数据质量（数据质量需求 / 数据质量检查 / 数据质量分析 / 数据质量提升）
  • 数据标准（业务术语 / 参考数据和主数据 / 数据元 / 指标数据）
  • 数据生存周期（数据需求 / 数据设计和开发 / 数据运维 / 数据退役）
八域口诀「战略治理架构 · 应用安全质量 · 标准生存周期」；能力项个数「三三四三三四四四」（共 28 项）。⚠️ 元数据管理属数据架构、指标数据属数据标准（别挂错域）
3DCMM 的 5 个成熟度等级
  • 初始级：数据需求管理主要在项目级体现，没有统一的管理流程，主要被动式管理
  • 受管理级：组织意识到数据是资产，根据管理策略要求制定了管理流程，指定相关人员进行了初步管理
  • 稳健级：数据已被当作实现组织绩效目标的重要资产，在组织层面制定系列的标准化管理流程，促进数据管理的规范化
  • 量化管理级：数据被认为是获取竞争优势的重要资源，数据管理的效率能量化分析和监控
  • 优化级：数据被认为是组织生存和发展的基础，相关管理流程能实时优化，能在行业内进行最佳实践分享
五等级口诀「初受稳量优」。⭐ 真题落点：从稳健级开始强调「数据管理的规范化」「数据被当作实现组织绩效目标的重要资产」。⚠️ 稳健级（绩效目标 / 标准化流程）≠ 量化管理级（竞争优势 / 量化分析监控）
4数据管理的四个常用模型
  • DCMM（数据管理能力成熟度模型）：5 个等级 + 8 个核心能力域
  • DGI（数据治理框架）：从组织结构、治理规则和治理过程三个维度提出 10 个关键通用组件
  • DCAM（数据管理能力评价模型）：4 个组件（基础 / 执行 / 分析 / 应用），强调团队协作（流程）、标准执行和资金支持
  • DAMA（数据管理模型）：11 个数据管理职能领域 + 7 个基本环境要素，构成「DAMA 数据管理知识体系」
量词口诀「DCMM 五等级 · DGI 三维度 · DCAM 四组件 · DAMA 十一域」——四个量词（等级 / 维度 / 组件 / 职能领域）别接错
4.2.2 运维管理
5IT 运维能力模型（GB/T 28827.1）
  • 标准：GB/T 28827.1《信息技术服务 运行维护 第 1 部分：通用要求》定义了 IT 运维能力模型
  • 三部分：治理要求 · 运行维护服务能力体系 · 价值实现
  • ⭐ 真题落点：运行维护服务能力体系为价值实现赋能
  • 能力建设：在治理要求指导下，根据服务场景识别服务能力需求，围绕人员、过程、技术、资源四要素，策划、实施、检查和改进运行维护能力体系
三部分「治理 · 能力体系 · 价值」；能力建设四要素「人过技资」；管理四阶段「策划 · 实施 · 检查 · 改进」
6能力建设四要素与四种「做事」
  • 人员能力 = 选人做事：运维人员一般分为管理类、技术类和操作类三种岗位
  • 资源能力 = 保障做事：资源包括知识库、服务台、备件库以及运行维护工具
  • 技术能力 = 高效做事：发现问题和解决问题的技术
  • 过程 = 正确做事：服务级别、服务报告、事件、问题、变更、发布、配置等过程
配对口诀「人员选人做事 · 资源保障做事 · 技术高效做事 · 过程正确做事」（四者别对调）；人员三岗位「管技操」；资源四件「知识库 · 服务台 · 备件库 · 运维工具」
7智能运维能力框架（T/CESA 1172）
  • 标准：T/CESA 1172《信息技术服务 智能运维 通用要求》（中国电子工业标准化技术协会团体标准）
  • 五部分：组织治理 · 智能特征 · 智能运维场景实现 · 能力域 · 能力要素
  • 其中能力要素是构建智能运维能力的基础（真题原句）
  • 组织通过场景分析、场景构建、场景交付和效果评估四个过程，基于数据管理能力域的高质量数据，结合分析决策能力域做判断，驱动自动控制能力域执行运维操作，实现质量可靠、安全可控、效率提升、成本降低
五部分口诀「治理 · 特征 · 场景 · 能力域 · 要素」；能力要素是基础（这是真题原句，最爱挖空）
8智能运维能力要素（7 项）与智能特征（7 项）
能力要素（7 项）
  • 人员 · 技术 · 过程 · 数据 · 算法 · 资源 · 知识
  • 算法聚焦异常检测、根因分析、故障预测、知识图谱、健康诊断、决策分析，具备有穷性、确切性、有效性；资源配置算力 / 带宽 / 存储
智能特征（7 项）
  • 能感知 · 会描述 · 自学习 · 会诊断 · 可决策 · 自执行 · 自适应
  • 会描述 = 直观友好地编排、展现和表达运维场景信息；会诊断 = 对人、活动和对象进行分析定位并判断原因
能力平台（三能力域）
  • 数据管理 · 分析决策 · 自动控制——数据管理提供高质量数据、分析决策做判断/结论、自动控制执行运维操作
⚠️ 别与「能力建设四要素」（人过技资）混：四要素 ⊆ 七要素，智能运维多「数据 / 算法 / 知识」。七要素口诀「人技过数算资知」、七特征口诀「感描学诊决执适」
9智能运维「两组四环节」与运维场景三类
智能运维场景实现的四过程
  • 场景分析 · 场景构建 · 场景交付 · 效果评估（能力框架层面的描述）
能力应用的四个关键环节
  • 场景分析 · 能力构建 · 服务交付 · 迭代调优（落地实施层面，以运维场景为中心）
运维场景按复杂程度划分
  • 单一场景 · 复合场景 · 全局场景
⚠️ 两组四环节最爱对调：框架层 = 场景构建 / 效果评估，应用层 = 能力构建 / 迭代调优。场景三类口诀「单复全」
4.2.3 信息安全管理
10CIA 三要素与信息安全管理体系
  • 核心：保障信息的保密性、完整性、可用性
  • 保密性 Confidentiality：确保信息只被授权者读取
  • 完整性 Integrity：确保信息不被篡改、真实有效
  • 可用性 Availability：确保信息和系统在需要时能正常使用
  • CIA 是信息安全设计的基础，但并非全部，还需结合合规性、可追溯性等其他要求
信息安全管理体系（全生命周期的系统工程）
  • 建立安全管理机构和团队 · 制定安全策略和规划 · 实施风险管理 · 制定业务持续性计划和灾难恢复计划 · 选择和部署安全措施 · 规范配置和变更管理 · 开展安全审计和监控 · 处理安全事件 · 开展安全意识培训
CIA 口诀「保完可」；⚠️ 教材口径是「保密性」（不是「机密性」）
11网络安全等级保护（等保 2.0）：安全保护等级五级
  • 定位：等保 2.0 是我国网络安全的核心制度，把「信息系统安全」扩展为「网络安全」，覆盖信息系统、通信网络设施、数据资源等
  • 第一级：对公民、法人和其他组织的合法权益造成损害，但不危害国家安全、社会秩序和公共利益
  • 第二级：对合法权益严重损害，或对社会秩序和公共利益造成危害，但不危害国家安全
  • 第三级：对社会秩序和公共利益造成严重危害，或对国家安全造成危害
  • 第四级：对社会秩序和公共利益造成特别严重危害，或对国家安全造成严重危害
  • 第五级：对国家安全造成特别严重危害
五级「公民 → 社会 → 国家」逐级递进；两级出现「严重」、两级出现「特别严重」，第五级只挂「国家安全特别严重」
12安全保护能力五级（GB/T 22239）
  • 第一级：防护个人的、拥有很少资源的威胁源；受损后恢复部分功能
  • 第二级：防护外部小型组织、拥有少量资源的威胁源；能发现重要安全漏洞并处置；受损后一段时间内恢复部分功能
  • 第三级：统一安全策略下防护外部有组织的团体、拥有较为丰富资源的威胁源；能及时发现、监测攻击行为；受损后较快恢复绝大部分功能
  • 第四级：统一安全策略下防护国家级别的、敌对组织的拥有丰富资源的威胁源；受损后迅速恢复所有功能
  • 第五级：教材从略
看两列：威胁源（个人 / 小型组织 / 有组织团体 / 国家级）+ 恢复程度（部分 / 一段时间内部分 / 绝大部分 / 所有）。⚠️ 与上一问的「安全保护等级五级」不是一个东西（一个按破坏后果、一个按威胁源 + 恢复能力）
总结区 本节本质 + 考点地图
本节本质：4.2 把 4.1 的方法论落到「数据 / 运维 / 安全」三件事。全节没有计算，题型是「数量配对 + 归属辨析 + 名称配对」三类，数字型考点极密集（管理要点 3 聚焦 / DCMM 8 域 5 级 / 4 个数据模型 / 4 要素 4 做事 / 智能运维 7 要素 7 特征 3 能力域 3 类场景 / CIA 3 要素 / 等保 2 个五级）。

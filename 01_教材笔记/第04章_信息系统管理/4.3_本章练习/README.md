## 章节重点（整章收束）

第 4 章是**第 4 版新增章（综合知识约 2~3 题）**，且近年考情**「管理要点」（4.2）比「管理方法」（4.1）更常出题**。特点：

- **全部是选择题考点**：无计算、无案例论文主线；题型三类——**框架归属 / 模型名称配对 / 关键词辨析**
- **数字型考点密集**：4 要素 / 4 领域 / 3 战略三角 / 4 钻石 / 3 架构模式 / 4+11+6 运维活动 / 5 阶段 / 8 能力域 / 5 等级 / 4 模型 / 7 要素 / 7 特征 / 5 级等保
- **旧真题零覆盖**：2023 上及以前无对应题，只能靠教材口径 + 本仓题库

**整章最容易丢分的 8 处**（考前只看这一块）：

1. **四组「要素组」大混战**：信息系统四要素（人/技/流/数）· 莱维特钻石（任务/结构/信息与控制/人员）· 矩阵框架（硬/软/网/数）· 运维能力建设四要素（人/过/技/资）——每组归属的模型必须一一配对
2. **智能运维能力要素 7 项 ⊃ 运维四要素**：多出的正是**数据、算法、知识**三项
3. **稳健级**（绩效目标重要资产）vs **量化管理级**（竞争优势重要资源 + 量化监控）——两级对调是 DCMM 最高频陷阱
4. **四个数据管理模型量词**：DCMM 五等级 · DGI 三维度（10 组件）· DCAM 四组件 · DAMA 十一域（7 要素）
5. **两组四环节别对调**：场景实现 = 场景分析·**场景构建**·场景交付·**效果评估**；能力应用 = 场景分析·**能力构建**·服务交付·**迭代调优**
6. **事件管理 = 快速恢复**（治标）vs **问题管理 = 根因防复发**（治本）
7. **等保「两个五级」不是一回事**：安全保护等级（破坏后果：公民→社会→国家）vs 安全保护能力（GB/T 22239：威胁源 + 恢复程度）
8. **国标号配对**：GB/T **36073** = DCMM · GB/T **28827.1** = IT 运维通用要求 · GB/T **22239** = 等保基本要求 · **T/CESA 1172** = 智能运维通用要求

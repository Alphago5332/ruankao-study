### 4.1 口径（四方交叉核对）

- 核对方式：**信管网第 4 版大纲考点 + 爱企查第 4 版知识摘编 + CSDN 逐章备考笔记 + 教辅口诀版**四方交叉核对；清华社样章 PDF 含 1.1~1.5 与 2.1.1 / 2.1.2，**不含第 4 章**，无法逐字比对
- 4.1 高危误记已修正：
  1. **两套「四要素」别混**：组织机制战略 = 莱维特钻石「任务 · 结构 · 信息与控制 · 人员」；信息系统战略 = 矩阵框架「硬件 · 软件 · 网络 · 数据」
  2. **「基于 Web 的架构」是 SOA 的别称**（表 4-3 的「别称术语」列），**不是第四种架构模式**——三模式 = 集中式（主机架构）/ 分布式（基于服务器的架构）/ SOA（基于 Web 的架构）
  3. **事件管理 = 快速恢复服务**（治标）与 **问题管理 = 根因分析、防复发**（治本）不可对调
  4. **SIPOC 属定义阶段**（定义核心流程视图的首选工具）；**价值流分析属分析阶段**
  5. **DMAIC → DMADV 只在第 4、5 阶段替换**（改进→设计、控制→验证）；DMAIC 用于现有过程改进、DMADV 用于设计新产品 / 过程
  6. **四大领域落点**：含「采购」「与业务流程整合」的是**设计和实施**；出现「一致性管理」的是**优化和持续改进**
  7. 「监督系统的设计和结构、监控整体性能」属**管理**层；「压倒一切」修饰**业务战略**
- 第 4 章为**第 4 版新增章**：2023 上及以前的旧真题没有对应题，练题以 2024 以后回忆题 + 教辅章节题为主

### 4.2 口径（四方交叉核对，2026-10-08）

- 核对方式同 4.1：**信管网第 4 版大纲考点 + 爱企查第 4 版知识摘编 + CSDN 逐章备考笔记 + 教辅口诀版**四方交叉；样章 PDF **不含第 4 章**
- 4.2 高危误记已固化：
  1. **DCMM 8 个核心能力域**（国标 GB/T 36073）：数据战略 / 数据治理 / 数据架构 / 数据应用 / 数据安全 / 数据质量 / 数据标准 / 数据生存周期；「**元数据管理**」属**数据架构**、「**指标数据**」属**数据标准**
  2. **DCMM 五等级**「初受稳量优」；**稳健级** = 组织层面标准化流程 +「**实现组织绩效目标**的重要资产」；**量化管理级** =「**获取竞争优势**的重要资源」+ 量化分析监控（两级别别对调）
  3. **四个数据管理模型量词**：DCMM **五等级** · DGI **三维度**（10 组件）· DCAM **四组件** · DAMA **十一域**（7 要素）
  4. **IT 运维能力模型三部分**（GB/T 28827.1）：治理要求 · 运行维护服务能力体系 · 价值实现；**运行维护服务能力体系为价值实现赋能**
  5. **两套「四要素」**：运维能力建设 = 人员 / 过程 / 技术 / 资源（4 项，「人过技资」）；智能运维能力要素 = 人员 / 技术 / 过程 / 数据 / 算法 / 资源 / 知识（7 项，「人技过数算资知」，多数据 · 算法 · 知识）
  6. **四种「做事」配对**：人员选人做事 · 资源保障做事 · 技术高效做事 · 过程正确做事
  7. **智能运维能力框架**（T/CESA 1172）五部分 = 组织治理 / 智能特征 / 智能运维场景实现 / 能力域 / 能力要素，其中**能力要素是构建智能运维能力的基础**；**能力平台三域** = 数据管理 / 分析决策 / 自动控制
  8. **智能特征 7 项**「感描学诊决执适」；**运维场景三类** = 单一 / 复合 / 全局
  9. **两组四环节别混**：智能运维「**场景实现**」= 场景分析 · **场景构建** · 场景交付 · **效果评估**；「**能力应用**」= 场景分析 · **能力构建** · 服务交付 · **迭代调优**
  10. **CIA 三要素**用「**保密性** Confidentiality」（非「机密性」）；三要素是信息安全设计的基础但**并非全部**（还需合规性、可追溯性）
  11. **等保「两个五级」不是一回事**：安全保护等级五级（按**破坏后果**：公民→社会→国家）≠ 安全保护能力五级（GB/T 22239，按**威胁源 + 恢复程度**）

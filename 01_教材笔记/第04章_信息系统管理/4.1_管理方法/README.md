## 易混防坑

1. **两套「四要素」**：组织机制战略 = 钻石「**任务 / 结构 / 信息与控制 / 人员**」；信息系统战略 = 矩阵「**硬件 / 软件 / 网络 / 数据**」——模型与内容必须配对（「业务看波特 · 组织看莱维特 · 信息系统看矩阵」）
2. **「基于 Web 的架构」= SOA 的别称**，不是第四种模式；「主机架构」= 集中式、「基于服务器的架构」= 分布式
3. **事件管理 = 快速恢复**（治标）↔ **问题管理 = 查根因、防复发**（治本）——最高频调包点
4. **SIPOC 属定义阶段**（核心流程视图的首选工具）；**价值流分析属分析阶段**——别对调
5. **DMAIC vs DMADV**：替换只发生在**第 4、5 阶段**（改进→设计、控制→验证）；DMAIC 改现有过程、DMADV 设计新产品 / 过程
6. **四大领域落点**：含「**采购**」「与业务流程整合」的是**设计和实施**；出现「**一致性管理**」的是**优化和持续改进**
7. **「监督系统的设计和结构、监控整体性能」属管理层**（层次架构中信息系统之上是管理）
8. **「压倒一切」修饰业务战略**（不是组织机制 / 信息系统）
9. **「网络」不是信息系统的独立要素**——它属「技术」要素的组成部分（硬件、软件、网络）
10. **运行管理和控制四活动**（过程开发 / 标准制定 / 资源分配 / 过程管理）≠ **IT 服务管理 11 项**
11. **错误四类「系程通操」**（系统 / 程序 / 通信 / 操作员错误）
12. 本章旧真题无存货（第 4 版新增章），练题以本节自测题 + 2024 以后回忆题 + 教辅章节题为主

## 一、必背清单

### 模块 A ｜ 数字化转型总论

- [ ] **A0 · 本节引言（三元空间）**（常作题干背景）
  随着众多信息通信新技术的迅速发展与普及应用，**信息空间成长为第三空间**，并与**物理空间和社会空间**共同构成人类社会的**三元空间**
  - 新一代信息技术（**云计算、大数据、人工智能**等）成为驱动组织数字化转型的**关键要素**
  - 组织需打造**敏捷、韧性、创新**的数字化能力，重构传统业务流程和价值链，推动实现**全要素、全链条、全层级**的数字化转型
  - 元宇宙**本质上是对现实世界的虚拟化、数字化过程**，需要对**内容生产、经济系统、用户体验以及实体世界内容**等进行大量改造
  > 记法：三元空间 = **物理 + 社会 + 信息**（信息空间是「第三空间」）；数字化能力三词 = **敏捷 · 韧性 · 创新**（敏韧创）
- [ ] **A1 · 数字化转型定义** ⭕ 必背
  **数字化转型（Digital Transformation）是建立在数字化转换（Digitization）、数字化升级（Digitalization）基础上，进一步触及组织核心业务，以新建一种业务模式为目标的高层次转型。**
  - 另一句表述：数字化转型是**开发数字化技术及支持能力以新建一个富有活力的数字化商业模式**
  - 关键补充：**不仅仅是 IT**，而是对**组织活动、流程、业务模式、员工能力**等方面进行**系统性、彻底的**（重大和完全的）**重新定义**，成功才会得以实现
  > 三个限定词记牢：建立在「数字化转换 + 数字化升级」**基础**上 → 触及「**组织核心业务**」→ 以新建「**业务模式**」为目标
  > ⚠️ 高频错项：把目标写成「技术模式 / 组织模式 / 评估模式」——教材口径就是「**业务模式**」
- [ ] **A2 · 概念递进三级**（易混，务必分清）
  | 层级 | 术语（英文） | 含义 |
  |---|---|---|
  | 第 1 级 | **数字化转换**（Digitization） | 把模拟信息转成数字形式 |
  | 第 2 级 | **数字化升级**（Digitalization） | 利用数字技术改造业务流程 |
  | 第 3 级 | **数字化转型**（Digital Transformation） | 触及**核心业务**、以新建**业务模式**为目标的**高层次转型** |
  > 三层是**递进关系**：数字化转换 ⊂ 数字化升级 ⊂ 数字化转型。数字化转型的定语是「**高层次**」

### 模块 B ｜ 数字化转型驱动因素（四大项）

- [ ] **B0 · 总范式**（理解即可，但常做背景）
  纵观历史，无论是国际竞争关系、产业转型升级和新经济发展，还是我国社会主要矛盾变化带来的新特征新要求，都有其**发展规律和演进范式**，即：
  > 「**生产力飞跃、生产要素变化、信息传播效率突破和社会「智慧主体」规模扩容的叠加，将会促使人类社会生产关系的创新变革，最终引发经济与民生的深层发展**」
  - 这个范式驱动完成了**原始经济 → 农业经济 → 工业经济**的转型，同样会驱动**工业经济向数字经济**的转型
  > 口诀：**产 · 要 · 传 · 智**（生产力飞升 / 生产要素变化 / 信息传播效率突破 / 智慧主体规模扩容）→ 四者**叠加**引发生产关系创新变革
- [ ] **B1 · 驱动因素一：生产力飞升 —— 第四次科技革命** ⭕ 必考（四范式最易串）
  **科学技术是第一生产力**；已完成的**三次科技革命** + 正在经历的**第四次科技革命**，每次科技革命都对应一个**科学范式**
  | 范式 | 名称 | 核心表述 |
  |---|---|---|
  | 第一 | **经验范式** | 偏重**经验事实的描述**和明确具体的**实用性**；研究方法**以归纳为主**，带有较多**盲目性的观测和实验** |
  | 第二 | **理论范式** | 偏重**理论总结和理性概括**，强调**较高普遍的理论认识**而非直接实用意义 |
  | 第三 | **模拟范式** | 与**数据模型构建、定量分析方法以及利用计算机**来分析和解决科学问题相关 |
  | 第四 | **数据密集型研究范式** | 由传统的**假设驱动**向**基于科学数据进行探索**的科学方法转变；**研究方法 = 基于计算机生产实践产生的数据**，按驱动理论获得猜想与假设，完成数据自动化计算和原理探索，即**由计算机实施第一、第二、第三科学范式** |
  - 第四范式的价值：通过新型信息技术的**数据洞察**，从大数据中**自动化挖掘实践经验、理论原理**并**自行开展模拟仿真**，完成基于数据的**自决策和自优化**，极大繁荣应用科学技术
  > 记法：**经 → 理 → 模 → 数**（经验 / 理论 / 模拟 / 数据密集）
  > 一眼区分法：看到「**归纳为主、盲目性观测实验**」= 第一经验范式；看到「**理性概括、理论认识**」= 第二理论范式；看到「**数据模型构建 + 计算机分析**」= 第三模拟范式；看到「**假设驱动转向数据探索 / 由计算机实施前三范式 / 自决策自优化**」= 第四数据密集型
- [ ] **B2 · 驱动因素二：生产要素变化 —— 数据要素的诞生** ⭕ 常考
  数据是与**土地、劳动力、资本和技术**并列的主要生产要素，表明数据将会是未来社会**数字化、智能化发展的重要基础**
  - 数据是一项重要的**经济资源**，对经济社会全面持续发展、经济组织转型和参与个体生活质量非常重要且不可或缺
  - 链条表述：**数据记载信息，信息融合知识，知识孕育智慧**
  - 逻辑：过去几十年信息化建设，人们把**智慧解构成知识，把知识分解为信息，把信息拆解为数据**；随着人工智能、区块链、大数据等技术出现，过去分散在各环节的数据**重新归集为显性信息、知识和智慧**，数据的经济价值越发凸显
  - 因此数据与**土地、设备、原材料、资本、劳动、技术**同等重要，具备了**单列为生产要素的现实条件**
  > 记法：数据要素五并列 = **土地 · 劳动力 · 资本 · 技术**（+ 数据本身）
- [ ] **B3 · 驱动因素三：信息传播效率突破 —— 社会互联网新格局** ⭕ 必考（四性）
  人们的日常生活逐渐从**现实社交网络**转移到**互联网虚拟社交网络**；社交网络信息传输具有**永生性、无限性、即时性、方向性**四个特征
  | 特征 | 含义 |
  |---|---|
  | **永生性** | 尽管传播过程中可以控制信息，但它**并不会被破坏或者消灭** |
  | **无限性** | 信息可以像**病毒一样无限地传播**下去 |
  | **即时性** | 传播时间大大缩短，**甚至可以忽略** |
  | **方向性** | 信息传播具有**目的性**，某些信息的传播仅是为了**传递给特定的人** |
  - 互联网的特性：信息可以**跨越时间和地理障碍**在网络上迅速传播；互联网上传播信息已成为**信息扩散的主要渠道**
  > 口诀：**永无即方**（永生 / 无限 / 即时 / 方向）
- [ ] **B4 · 驱动因素四：社会「智慧主体」规模 —— 快速复制与「智能+」** ⭕ 必考
  — 过去「智慧主体」**都是自然人**，复制难度大、周期漫长，培育一个自然人「智慧主体」往往需要**超过 20 年**
  — 现在「智慧主体」**不单纯是自然人**，可以是：**互联网账号、自动驾驶的汽车、智能手机、工厂中的智能机器人**
  - 新兴「智慧主体」具备：**较强的可复制性、自我学习能力、更加广泛的连接能力、更加标准的交互手段**
  - 新兴主体在**数据生产、数据开发利用、劳动力贡献和决策能力**等方面具备自然人的很多关键特征；未来某一时刻无人驾驶汽车主体与自然人道路参与主体**享有同等道路权**
  - 后果：**劳动密集型**的社会劳动**逐步消退**，**智力密集型**的社会劳动**持续强化**；自然人甚至全面退出**生产制造**过程领域，竞争力聚焦在「**服务**」为典型代表的领域（面对更复杂的交互过程、更多风险融合应对和情感因素管控）
  > 口诀：新兴智慧主体四能力 = **复 · 学 · 连 · 互**（可复制 / 自我学习 / 连接广泛 / 交互标准）
  > ⚠️ 「20 年」是自然人的培育周期数字，别记成 10 年

### 模块 C ｜ 数字化转型基本原理（三条）

- [ ] **C1 · 原则一：能力因子定义和数字化「封装」** ⭕ 常考
  组织需要把**各项能力和活动**进行清晰的**结构化并定义**，形成细化的**可灵活调度和编排的能力因子**
  - 能力因子是**有层次或可组合**的，如：**能力域、能力子域、能力项、能力分项、能力子项**
  - 不同成熟度的组织，差异主要体现在**能力因子定义的颗粒度、学科性和有效性**
  > 记法：五种因子 = **域 → 子域 → 项 → 分项 → 子项**（由粗到细）
- [ ] **C2 · 原则二：基于「互联网+」的调度和决策** ⭕ 常考
  组织在已有**治理与管理体系、工艺体系、服务体系、产品体系**的基础上，通过使用「**互联网+**」的模式
  - 把组织沉淀的**各类知识经验进行数字化提炼**，形成**数字算法、模型和框架**等，满足**信息系统能够理解和使用**的方式
  - 核心目标：让**调度和决策脱离「自然人」**，从而提高调度和决策的**效率及其科学性**
  > ⚠️ 关键词是「**脱离自然人**」——与智慧转移的「**脑力替代**」是同一思路的两个说法
- [ ] **C3 · 原则三：转型控制** ⭕ 常考
  数字化转型往往**不是指一个结果的表达，而是一个持续的过程**；无论服务组织还是工业组织，都**不能一蹴而就**
  - 组织需要**有效管控转型过程**，充分借鉴**信息化与工业化、信息化与领域现代化**等深度融合的**最佳实践**
  - 结合自身实际情况，**持续建设、优化和改进**数字化转型过程
  > 记法：转型控制三动作 = **持续建设 · 优化 · 改进**；借鉴对象 = **两化融合**类最佳实践

### 模块 D ｜ 智慧转移（S8D 模型）与持续迭代

- [ ] **D0 · 智慧转移总论** ⭕ 必考（本节结构最复杂处）
  数字化转型基本原理揭示了：**个体智慧（知识、技能和经验等）由「自然人」个体，转移到组织智慧（计算机、信息系统等掌握的）**的必要性和重要性
  - 这种转移也称「**智慧转移**」，又称「**智慧移植**」；需经历**系列过程**才能完成，各组织的模式与方法存在差异（对应教材**图 1-10 「智慧转移」模型**）
  - 模型名称：**S8D 模型**，其基础是 **DIKW 模型**（Data 数据 → Information 信息 → Knowledge 知识 → Wisdom 智慧）
  - 核心目标：实现「**脑力替代**」
  > 一句话记住：**把自然人的智慧搬进信息系统**，叫智慧转移（= 智慧移植），目标是**脑力替代**
- [ ] **D1 · 「智慧—数据」过程 = 传统「信息化过程」** ⭕ 必考（四步）
  该过程通常指**信息系统规划、建设、运行过程**，也就是传统讲的「**信息化过程**」
  | 步 | 动作 | 落到 DIKW 哪一层 |
  |---|---|---|
  | ① | **智慧结构化** —— 明确了**业务体系**层面的内容 | 智慧 |
  | ② | **知识模型化** —— 定义**业务活动的逻辑关系** | 知识 |
  | ③ | **过程信息化**（管理和工艺流程化）—— 明确**各执行操作系列要求** | 信息 |
  | ④ | **数据平台化** —— 实现了数据的**采集、存储和共享** | 数据 |
  > 口诀：**慧 · 识 · 息 · 据** → 智慧结构化 / 知识模型化 / 过程信息化 / 数据平台化
- [ ] **D2 · 「数据—智慧」过程 = 「智慧化过程」** ⭕ 必考（四步）
  该过程通常指**数据的开发利用和资源管理**的过程，即人们常说的「**智慧化过程**」；重点解决基于各类组织组成对象（**人员、流程、业务、工艺、装备**等）「**数字关系**」的「**脑力替代**」
  - 前提是**大数据「筑底」**后，多元化数据能够被开发利用：
  | 步 | 动作 | 关键表述 |
  |---|---|---|
  | ① | **对象数字化** | 实现对**各类对象的数字化表达** |
  | ② | **孪生虚拟化** | 完成**物理对象到信息空间的映射** |
  | ③ | **架构可视化** | 实现**业务知识模型与经验沉淀的复用和创新** |
  | ④ | **计算智能化** | 实现**多元条件下的调度和决策** |
  > 口诀：**对 · 孪 · 架 · 计** → 对象数字化 / 孪生虚拟化 / 架构可视化 / 计算智能化
  > ⚠️ 两个过程方向相反：**「智慧—数据」= 信息化过程**（把智慧拆成数据）；**「数据—智慧」= 智慧化过程**（把数据还原成智慧）。题干问「信息化过程」选前者，问「智慧化过程」选后者
- [ ] **D3 · 持续迭代（了解）**（四项活动，形成**持续迭代闭环**）
  组织数字化转型需要在**能力因子不断细化**的基础上，针对能力因子实施迭代；可从**任何一项活动**开始，实施四项活动形成闭环
  | # | 活动 | 要点 |
  |---|---|---|
  | 1 | **信息物理世界建设** | 对能力因子中各类对象实施**数字孪生建设**，并加入该因子与其他因子之间的**配置关系**；实现数据挖掘与开发利用 |
  | 2 | **决策能力边际化部署** | 处置执行层面的**装置和人员**能够基于决策算法模型**敏捷取得更高的决策能力（权）**，达到**敏捷响应**；实现**决策权融合与调制** |
  | 3 | **科学物理赛博机制构筑** | 在 **CPS** 基础上，汇聚组织内能力因子的**环境因素力量**（或外部社会力量），建设**高密度数据框架**，参照社会运行原理，**封装、解构和重构**各能力因子协同关系 |
  | 4 | **数据框架与信息调制设计** | 能力因子**数字密度越高 → 可控性越高 → 安全可靠性越高**；优化数字框架模型 + 提升数据采集精准度和及时性，提升**应急与动员能力**，具备更可靠的**已知风险管控能力和未知风险应对能力** |
  > 四项活动英文缩写（了解）：**DFIM**（数据框架与信息调制设计）
  > ⚠️「决策能力**边际化**」= 决策权**下沉到执行端**——与 1.4 智慧城市五要素里的「**边际决策**」同源，但本节侧重「部署」动作

### 模块 E ｜ 元宇宙（1.5.2）

- [ ] **E0 · 元宇宙的本质与三位学者定义** ⭕ 常考（定义归属）
  元宇宙**本质上是对现实世界的虚拟化、数字化过程**，需要对**内容生产、经济系统、用户体验以及实体世界内容**等进行大量改造；元宇宙（Metaverse）是一个**新兴概念**，是**一大批技术的集成**
  | 学者 | 单位 | 定义要点 |
  |---|---|---|
  | **陈刚** | **北京大学** | 元宇宙是**利用科技手段进行链接与创造的，与现实世界映射与交互的虚拟世界**，具备**新型社会体系的数字生活空间** |
  | **沈阳** | **清华大学** | 元宇宙是**整合多种新技术而产生的新型虚实相融的互联网应用和社会形态**；基于**扩展现实技术**提供沉浸式体验，**数字孪生技术**生成现实世界的镜像，通过**区块链技术**搭建经济体系；将虚拟世界与现实世界在**经济系统、社交系统、身份系统**上密切融合；**允许每个用户进行内容生产和编辑** |
  | **左鹏飞** | **中国社会科学院** | 从**时空性、真实性、独立性、连接性**四方面**交叉定义** |

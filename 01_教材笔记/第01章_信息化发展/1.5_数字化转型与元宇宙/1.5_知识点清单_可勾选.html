一、必背清单

模块 A ｜ 数字化转型总论

随着众多信息通信新技术的迅速发展与普及应用，信息空间成长为第三空间，并与物理空间和社会空间共同构成人类社会的三元空间

• 新一代信息技术（云计算、大数据、人工智能等）成为驱动组织数字化转型的关键要素
• 组织需打造敏捷、韧性、创新的数字化能力，重构传统业务流程和价值链，推动实现全要素、全链条、全层级的数字化转型
• 元宇宙本质上是对现实世界的虚拟化、数字化过程，需要对内容生产、经济系统、用户体验以及实体世界内容等进行大量改造
记法：三元空间 = 物理 + 社会 + 信息（信息空间是「第三空间」）；数字化能力三词 = 敏捷 · 韧性 · 创新（敏韧创）

数字化转型（Digital Transformation）是建立在数字化转换（Digitization）、数字化升级（Digitalization）基础上，进一步触及组织核心业务，以新建一种业务模式为目标的高层次转型。

• 另一句表述：数字化转型是开发数字化技术及支持能力以新建一个富有活力的数字化商业模式
• 关键补充：不仅仅是 IT，而是对组织活动、流程、业务模式、员工能力等方面进行系统性、彻底的（重大和完全的）重新定义，成功才会得以实现
三个限定词记牢：建立在「数字化转换 + 数字化升级」基础上 → 触及「组织核心业务」→ 以新建「业务模式」为目标
⚠️ 高频错项：把目标写成「技术模式 / 组织模式 / 评估模式」——教材口径就是「业务模式」
层级术语（英文）含义
第 1 级数字化转换（Digitization）把模拟信息转成数字形式
第 2 级数字化升级（Digitalization）利用数字技术改造业务流程
第 3 级数字化转型（Digital Transformation）触及核心业务、以新建业务模式为目标的高层次转型
三层是递进关系：数字化转换 ⊂ 数字化升级 ⊂ 数字化转型。数字化转型的定语是「高层次」

模块 B ｜ 数字化转型驱动因素（四大项）

纵观历史，无论是国际竞争关系、产业转型升级和新经济发展，还是我国社会主要矛盾变化带来的新特征新要求，都有其发展规律和演进范式，即：

「生产力飞跃、生产要素变化、信息传播效率突破和社会「智慧主体」规模扩容的叠加，将会促使人类社会生产关系的创新变革，最终引发经济与民生的深层发展」
• 这个范式驱动完成了原始经济 → 农业经济 → 工业经济的转型，同样会驱动工业经济向数字经济的转型
口诀：产 · 要 · 传 · 智（生产力飞升 / 生产要素变化 / 信息传播效率突破 / 智慧主体规模扩容）→ 四者叠加引发生产关系创新变革

科学技术是第一生产力；已完成的三次科技革命 + 正在经历的第四次科技革命，每次科技革命都对应一个科学范式

范式名称核心表述
第一经验范式偏重经验事实的描述和明确具体的实用性；研究方法以归纳为主，带有较多盲目性的观测和实验
第二理论范式偏重理论总结和理性概括，强调较高普遍的理论认识而非直接实用意义
第三模拟范式与数据模型构建、定量分析方法以及利用计算机来分析和解决科学问题相关
第四数据密集型研究范式由传统的假设驱动向基于科学数据进行探索的科学方法转变；研究方法 = 基于计算机生产实践产生的数据，按驱动理论获得猜想与假设，完成数据自动化计算和原理探索，即由计算机实施第一、第二、第三科学范式
• 第四范式的价值：通过新型信息技术的数据洞察，从大数据中自动化挖掘实践经验、理论原理并自行开展模拟仿真，完成基于数据的自决策和自优化，极大繁荣应用科学技术
记法：经 → 理 → 模 → 数（经验 / 理论 / 模拟 / 数据密集）
一眼区分法：看到「归纳为主、盲目性观测实验」= 第一经验范式；看到「理性概括、理论认识」= 第二理论范式；看到「数据模型构建 + 计算机分析」= 第三模拟范式；看到「假设驱动转向数据探索 / 由计算机实施前三范式 / 自决策自优化」= 第四数据密集型

数据是与土地、劳动力、资本和技术并列的主要生产要素，表明数据将会是未来社会数字化、智能化发展的重要基础

• 数据是一项重要的经济资源，对经济社会全面持续发展、经济组织转型和参与个体生活质量非常重要且不可或缺
• 链条表述：数据记载信息，信息融合知识，知识孕育智慧
• 逻辑：过去几十年信息化建设，人们把智慧解构成知识，把知识分解为信息，把信息拆解为数据；随着人工智能、区块链、大数据等技术出现，过去分散在各环节的数据重新归集为显性信息、知识和智慧，数据的经济价值越发凸显
• 因此数据与土地、设备、原材料、资本、劳动、技术同等重要，具备了单列为生产要素的现实条件
记法：数据要素五并列 = 土地 · 劳动力 · 资本 · 技术（+ 数据本身）

人们的日常生活逐渐从现实社交网络转移到互联网虚拟社交网络；社交网络信息传输具有永生性、无限性、即时性、方向性四个特征

特征含义
永生性尽管传播过程中可以控制信息，但它并不会被破坏或者消灭
无限性信息可以像病毒一样无限地传播下去
即时性传播时间大大缩短，甚至可以忽略
方向性信息传播具有目的性，某些信息的传播仅是为了传递给特定的人
• 互联网的特性：信息可以跨越时间和地理障碍在网络上迅速传播；互联网上传播信息已成为信息扩散的主要渠道
口诀：永无即方（永生 / 无限 / 即时 / 方向）

— 过去「智慧主体」都是自然人，复制难度大、周期漫长，培育一个自然人「智慧主体」往往需要超过 20 年

— 现在「智慧主体」不单纯是自然人，可以是：互联网账号、自动驾驶的汽车、智能手机、工厂中的智能机器人

• 新兴「智慧主体」具备：较强的可复制性、自我学习能力、更加广泛的连接能力、更加标准的交互手段
• 新兴主体在数据生产、数据开发利用、劳动力贡献和决策能力等方面具备自然人的很多关键特征；未来某一时刻无人驾驶汽车主体与自然人道路参与主体享有同等道路权
• 后果：劳动密集型的社会劳动逐步消退，智力密集型的社会劳动持续强化；自然人甚至全面退出生产制造过程领域，竞争力聚焦在「服务」为典型代表的领域（面对更复杂的交互过程、更多风险融合应对和情感因素管控）
口诀：新兴智慧主体四能力 = 复 · 学 · 连 · 互（可复制 / 自我学习 / 连接广泛 / 交互标准）
⚠️ 「20 年」是自然人的培育周期数字，别记成 10 年

模块 C ｜ 数字化转型基本原理（三条）

组织需要把各项能力和活动进行清晰的结构化并定义，形成细化的可灵活调度和编排的能力因子

• 能力因子是有层次或可组合的，如：能力域、能力子域、能力项、能力分项、能力子项
• 不同成熟度的组织，差异主要体现在能力因子定义的颗粒度、学科性和有效性
记法：五种因子 = 域 → 子域 → 项 → 分项 → 子项（由粗到细）

组织在已有治理与管理体系、工艺体系、服务体系、产品体系的基础上，通过使用「互联网+」的模式

• 把组织沉淀的各类知识经验进行数字化提炼，形成数字算法、模型和框架等，满足信息系统能够理解和使用的方式
• 核心目标：让调度和决策脱离「自然人」，从而提高调度和决策的效率及其科学性
⚠️ 关键词是「脱离自然人」——与智慧转移的「脑力替代」是同一思路的两个说法

数字化转型往往不是指一个结果的表达，而是一个持续的过程；无论服务组织还是工业组织，都不能一蹴而就

• 组织需要有效管控转型过程，充分借鉴信息化与工业化、信息化与领域现代化等深度融合的最佳实践
• 结合自身实际情况，持续建设、优化和改进数字化转型过程
记法：转型控制三动作 = 持续建设 · 优化 · 改进；借鉴对象 = 两化融合类最佳实践

模块 D ｜ 智慧转移（S8D 模型）与持续迭代

数字化转型基本原理揭示了：个体智慧（知识、技能和经验等）由「自然人」个体，转移到组织智慧（计算机、信息系统等掌握的）的必要性和重要性

• 这种转移也称「智慧转移」，又称「智慧移植」；需经历系列过程才能完成，各组织的模式与方法存在差异（对应教材图 1-10 「智慧转移」模型）
• 模型名称：S8D 模型，其基础是 DIKW 模型（Data 数据 → Information 信息 → Knowledge 知识 → Wisdom 智慧）
• 核心目标：实现「脑力替代」
一句话记住：把自然人的智慧搬进信息系统，叫智慧转移（= 智慧移植），目标是脑力替代

该过程通常指信息系统规划、建设、运行过程，也就是传统讲的「信息化过程」

步动作落到 DIKW 哪一层
①智慧结构化 —— 明确了业务体系层面的内容智慧
②知识模型化 —— 定义业务活动的逻辑关系知识
③过程信息化（管理和工艺流程化）—— 明确各执行操作系列要求信息
④数据平台化 —— 实现了数据的采集、存储和共享数据
口诀：慧 · 识 · 息 · 据 → 智慧结构化 / 知识模型化 / 过程信息化 / 数据平台化

该过程通常指数据的开发利用和资源管理的过程，即人们常说的「智慧化过程」；重点解决基于各类组织组成对象（人员、流程、业务、工艺、装备等）「数字关系」的「脑力替代」

• 前提是大数据「筑底」后，多元化数据能够被开发利用：
步动作关键表述
①对象数字化实现对各类对象的数字化表达
②孪生虚拟化完成物理对象到信息空间的映射
③架构可视化实现业务知识模型与经验沉淀的复用和创新
④计算智能化实现多元条件下的调度和决策
口诀：对 · 孪 · 架 · 计 → 对象数字化 / 孪生虚拟化 / 架构可视化 / 计算智能化
⚠️ 两个过程方向相反：「智慧—数据」= 信息化过程（把智慧拆成数据）；「数据—智慧」= 智慧化过程（把数据还原成智慧）。题干问「信息化过程」选前者，问「智慧化过程」选后者

组织数字化转型需要在能力因子不断细化的基础上，针对能力因子实施迭代；可从任何一项活动开始，实施四项活动形成闭环

#活动要点
1信息物理世界建设对能力因子中各类对象实施数字孪生建设，并加入该因子与其他因子之间的配置关系；实现数据挖掘与开发利用
2决策能力边际化部署处置执行层面的装置和人员能够基于决策算法模型敏捷取得更高的决策能力（权），达到敏捷响应；实现决策权融合与调制
3科学物理赛博机制构筑在 CPS 基础上，汇聚组织内能力因子的环境因素力量（或外部社会力量），建设高密度数据框架，参照社会运行原理，封装、解构和重构各能力因子协同关系
4数据框架与信息调制设计能力因子数字密度越高 → 可控性越高 → 安全可靠性越高；优化数字框架模型 + 提升数据采集精准度和及时性，提升应急与动员能力，具备更可靠的已知风险管控能力和未知风险应对能力
四项活动英文缩写（了解）：DFIM（数据框架与信息调制设计）
⚠️「决策能力边际化」= 决策权下沉到执行端——与 1.4 智慧城市五要素里的「边际决策」同源，但本节侧重「部署」动作

模块 E ｜ 元宇宙（1.5.2）

元宇宙本质上是对现实世界的虚拟化、数字化过程，需要对内容生产、经济系统、用户体验以及实体世界内容等进行大量改造；元宇宙（Metaverse）是一个新兴概念，是一大批技术的集成

学者单位定义要点
陈刚北京大学元宇宙是利用科技手段进行链接与创造的，与现实世界映射与交互的虚拟世界，具备新型社会体系的数字生活空间
沈阳清华大学元宇宙是整合多种新技术而产生的新型虚实相融的互联网应用和社会形态；基于扩展现实技术提供沉浸式体验，数字孪生技术生成现实世界的镜像，通过区块链技术搭建经济体系；将虚拟世界与现实世界在经济系统、社交系统、身份系统上密切融合；允许每个用户进行内容生产和编辑
左鹏飞中国社会科学院从时空性、真实性、独立性、连接性四方面交叉定义
记法：陈刚 = 北大的「虚拟世界 + 数字生活空间」；沈阳 = 清华的「虚实相融 + 三系统融合」；左鹏飞 = 社科院「四性交叉」
沈阳定义里技术分工别搞错：扩展现实 → 沉浸式体验；数字孪生 → 现实世界的镜像；区块链 → 经济体系
视角表述
时空性元宇宙是一个空间维度上虚拟而时间维度上真实的数字世界
真实性元宇宙中既有现实世界的数字化复制物，也有虚拟世界的创造物
独立性元宇宙是一个与外部真实世界既紧密相连，又高度独立的平行空间
连接性元宇宙是一个把网络、硬件终端和用户囊括进来的一个永续的、广覆盖的虚拟现实系统
口诀：时空真独连（时空性 / 真实性 / 独立性 / 连接性）
⚠️ 「时空性」的坑：空间虚拟、时间真实（不是两个都虚拟）

随着虚拟现实、人工智能、数字孪生、云计算等关键技术逐步迭代发展，用户对更沉浸的虚拟世界有了更深入、更丰富的需求；元宇宙的流行是互联网发展到了一定的高度，也可以认为是互联网发展的另一阶段

#特征关键表述
1沉浸式体验基于人们对互联网体验的需求，这种体验就是即时信息基础上的沉浸式体验
2虚拟身份互联网账号的内涵和外延进一步丰富 → 发展成一个或若干个数字身份；身份就是数字世界的一个或一组角色
3虚拟经济虚拟身份的存在促使元宇宙具备开展虚拟社会活动的能力，这些活动需要一定的经济模式展开
4虚拟社会治理元宇宙中的经济与社会活动也需要一定的法律法规和规则的约束；元宇宙也需要社区化的社会治理
• 结论：元宇宙作为现实世界的孪生空间和虚拟世界，其物理属性淡化，但社会属性将会被强化
口诀：沉浸 · 身份 · 经济 · 治理（四特征）
⚠️⚠️ 本节最大防坑点：教材 1.5.2 的元宇宙特征是 4 条，没有「低延迟 / 随地 / 文明」——那是 Roblox 等业界提出的「元宇宙八大要素」口径（身份/朋友/沉浸感/低延迟/多样性/随地/经济/文明），不是教材口径。看到选项里出现「低延迟」「随地」「文明」要警惕
关键技术四词也别记错：虚拟现实 · 人工智能 · 数字孪生 · 云计算

元宇宙的发展一方面受各类技术创新、发展和演进的影响，另一方面受经济与社会发展进程的约束

演进顺序：社交、娱乐和文化领域 → 形成虚拟「数字人」 → 逐步向虚拟身份方向演进 → 形成「数字人生」（偏向个体用户需求） → 元宇宙向「数字组织」领域延伸 → 形成「数字生态」 → 形成「数字社会治理」 → 实现物理空间、社会空间和信息空间三元空间的协同发展新格局

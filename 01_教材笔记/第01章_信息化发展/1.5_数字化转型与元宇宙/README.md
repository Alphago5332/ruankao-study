## 学习目标

- [ ] 背出**数字化转型定义**：建立在**数字化转换（Digitization）+ 数字化升级（Digitalization）**基础上 → 触及**组织核心业务** → 以新建**业务模式**为目标的高层次转型；理解「**不仅仅是 IT**」
- [ ] 背出**四要素叠加范式**（生产力飞跃 / 生产要素变化 / 信息传播效率突破 / 智慧主体规模扩容）与**四大驱动因素**，尤其**四个科学范式**（经验 / 理论 / 模拟 / 数据密集型）的区分关键词
- [ ] 背出**数字化转型基本原理三条**（能力因子定义和数字化「封装」/ 基于「互联网+」的调度和决策 / 转型控制）+ 能力因子**五层级**
- [ ] 掌握**智慧转移（S8D 模型，基础为 DIKW 模型，目标为「脑力替代」）**两个过程各四步：「智慧—数据」= 信息化过程（智慧结构化→知识模型化→过程信息化→数据平台化）；「数据—智慧」= 智慧化过程（对象数字化→孪生虚拟化→架构可视化→计算智能化）
- [ ] 背出**元宇宙主要特征四条** + 三位学者定义口径（陈刚·北大 / 沈阳·清华 / 左鹏飞·社科院「四性」）+ **发展演进链条**（数字人 → 数字人生 → 数字组织 → 数字生态 → 数字社会治理）

## 易混防坑

- **元宇宙特征是 4 条，不是 5 条**：教材 = 沉浸式体验 / 虚拟身份 / 虚拟经济 / 虚拟社会治理；**「低延迟」「随地」「文明」不入教材**（业界八大要素口径）——本节最大陷阱
- **数字化转型的目标是「新建一种业务模式」**，不是技术模式 / 组织模式 / 评估模式
- **两个过程方向相反**：「智慧—数据」= **信息化过程**（把智慧拆成数据，智慧结构化→…→数据平台化）；「数据—智慧」= **智慧化过程**（把数据还原成智慧，对象数字化→…→计算智能化）。题干问「信息化过程」选前者
- **S8D 模型的基础是 DIKW 模型**（数据→信息→知识→智慧），核心目标是「**脑力替代**」；「智慧转移」又称「**智慧移植**」
- 数据的并列生产要素 = **土地 / 劳动力 / 资本 / 技术**（不含能源、管理）
- 自然人「智慧主体」的培育周期是**超过 20 年**；智慧主体扩容后是**劳动密集型消退、智力密集型强化**（方向别反）
- 左鹏飞「时空性」= **空间虚拟 + 时间真实**（不是两者都虚拟）
- 本节出现的「**数字生态**」（元宇宙演进链条一环）与 1.4.4 的「数字生态（数据要素市场 / 数字营商环境 / 网络安全保护）」**同名不同义**
- 「基于「互联网+」的调度和决策」的核心目标是「让调度和决策**脱离「自然人」**」，与智慧转移的「**脑力替代**」是同一思路的两种说法

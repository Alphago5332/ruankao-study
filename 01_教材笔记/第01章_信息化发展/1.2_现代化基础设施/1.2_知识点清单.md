## 模块 A：新型基础设施建设（1.2.1）⭐ 必背

### A1. 新基建定义（2024上真题考点）

- [ ] **必背**：新型基础设施以**新发展理念**为引领，以**技术创新**为驱动，以**信息网络**为基础，面向高质量发展需要，提供数字转型、智能升级、融合创新等服务的基础设施体系。
- 判断关键词：**引领=新发展理念 / 驱动=技术创新 / 基础=信息网络**（三个搭配勿互换）

### A2. 七大领域（通读，防冷门题）

- [ ] 通读：5G 基建、特高压、城际高速铁路和城际轨道交通、新能源汽车充电桩、大数据中心、人工智能、工业互联网

### A3. 三大方面 + 各自特点（最高频！必背）

| 方面 | 特点 | 包含内容 |
|---|---|---|
| **信息基础设施** | 凸显「**技术新**」 | ① 通信网络基础设施：**5G、物联网、工业互联网、卫星互联网**；② 新技术基础设施：**人工智能、云计算、区块链**；③ 算力基础设施：**数据中心、智能计算中心** |
| **融合基础设施** | 重在「**应用新**」 | **智能交通基础设施、智慧能源基础设施**（传统基础设施转型升级） |
| **创新基础设施** | 强调「**平台新**」 | **重大科技、科教、产业技术创新基础设施**（公益属性） |

- 口诀：**信息=技术新 / 融合=应用新 / 创新=平台新**
- 归属判断法：看到"智能交通/智慧能源"→融合；"科教/重大科技"→创新；"5G/AI/云/链/数据中心"→信息
- 真题（2025上）：智能交通基础设施 → **融合基础设施**；科教基础设施 → 创新；算力、人工智能 → 信息
- 信息基础设施拆三小类口诀：**通信（5G 物联 工互 卫星）/ 新技术（AI 云 链）/ 算力（数据中心 智算中心）**

## 模块 B：工业互联网（1.2.2）⭐ 必背

### B1. 定义

- [ ] **必背**：工业互联网是**新一代信息通信技术与工业经济深度融合**的新型基础设施、应用模式和工业生态，是**第四次工业革命的重要基石**。
- 内涵外延：既是工业**数字化、网络化、智能化**转型的基础设施，也是互联网、大数据、人工智能与实体经济深度融合的**应用模式**。

### B2. 平台体系四大层级（必背骨架）

- [ ] **必背**：工业互联网平台体系具有**四大层级**——
  **网络是基础、平台是中枢、数据是要素、安全是保障**
- 口诀：**网平数安 / 基中素保**

### B3. 网络是基础

- [ ] 网络体系三部分：**网络互联、数据互通、标识解析**
  - **网络互联**：实现要素间数据传输（企业外网 + 企业内网）；典型技术：工业总线、工业以太网、**TSN（时间敏感网络）、确定性网络、5G**
  - **数据互通**：标准化描述 + 统一建模，实现传输信息的相互理解
  - **标识解析**：实现要素的**标记、管理和定位**；由**标识编码、标识解析系统、标识数据服务**组成
- [ ] 企业内网技术发展三特征：**IT 与 OT 走向融合、工业现场总线向工业以太网演进、工业无线技术加速发展**

### B4. 平台是中枢

- [ ] 平台体系四层级：**边缘层、IaaS、PaaS、SaaS**（记住顺序：边→I→P→S）
- [ ] 相当于工业互联网的「**操作系统**」
- [ ] 四大作用：**数据汇聚、建模分析、知识复用、应用创新**（口诀：**汇建知创**）
- [ ] 边缘层=设备连接管理、数据互联互通互操作

### B5. 数据是要素

- [ ] 工业互联网数据**三个特性**：**重要性、专业性、复杂性**（口诀：**重专复**）

### B6. 安全是保障

- [ ] 核心任务：通过**监测预警、应急响应、检测评估、功能测试**等手段确保健康有序发展
- [ ] 安全三大特点：**涉及范围广、造成影响大、企业防护基础弱**（口诀：**广大小**→广、大、弱）

### B7. 融合应用六大典型模式（必背）

- [ ] **平台化设计、智能化制造、网络化协同、个性化定制、服务化延伸、数字化管理**
- 口诀：**设造制定延管**（平台化**设**计 / 智能**化制造** / 网络**化协**同 / 个性**化定**制 / 服务**化延**伸 / 数字**化管理**）
- 场景配对（易考）：
  - 设备健康管理、产品远程运维、融资租赁 → **服务化延伸**
  - 敏捷设计、并行设计、基于模型的设计 → **平台化设计**
  - 供应链企业共享信息、协同设计/生产/服务 → **网络化协同**
  - 用户全生命周期深度参与、柔性生产 → **个性化定制**

## 模块 C：车联网（1.2.3）⭐ 必背

### C1. 定义

- [ ] 车联网（**IoV**，Internet of Vehicles）= 新一代网络通信技术与**汽车、电子、道路交通运输**等领域深度融合的新兴产业形态。
- [ ] 通读：智能网联汽车=融合现代通信与网络技术，实现车与车、路、人、云端等智能信息交换共享，可实现「**安全、高效、舒适、节能**」行驶的新一代汽车。

### C2. 体系框架：端、管、云三层（必背）

| 层 | 关键词 | 要点 |
|---|---|---|
| **端系统** | 智能传感器 | 采集与获取车辆智能信息、感知行车状态与环境；**车内通信、车间通信、车网通信**的泛在通信终端；具备 **IoV 寻址和网络可信标识**能力 |
| **管系统** | 互联互通 | 解决**车与车、车与路、车与网、车与人**的互联互通；车辆自组网及异构网络通信与漫游；保障**实时性、可服务性、网络泛在性**；是**公网与专网的统一体** |
| **云系统** | 云平台 | 云架构的车辆运行信息平台；生态链含 ITS、物流、客货运、汽修汽配、保险、紧急救援等；**多源海量信息汇聚**；需要**虚拟化、安全认证、实时交互、海量存储**等云计算功能 |

### C3. 链接方式五种（必背）

- [ ] **车与云平台、车与车、车与路、车与人、车内设备**（口诀：**云车路车内**→云端+三外一内）
- 场景配对：
  - 车与云平台 → 卫星无线/移动蜂窝通信，接收控制指令、数据实时共享
  - 车与路 → 地面道路固定通信设施，监测路面、引导最佳路径
  - 车与人 → Wi-Fi、蓝牙、蜂窝，用户监测控制车辆

### C4. 场景应用三类（通读）

- [ ] **实用类**（自动碰撞通知、被盗车辆跟踪、道路救援）/ **便捷类**（语音手势控制、信息娱乐、预定餐厅）/ **效率类**（固件自动更新、远程启动、智能交通缓解拥堵）

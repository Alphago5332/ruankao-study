一、必背清单

模块 A ｜ 新型基础设施建设（1.2.1，P7）

以新发展理念为引领，以技术创新为驱动，以信息网络为基础，面向高质量发展需要，提供数字转型、智能升级、融合创新等服务的基础设施体系

记法：引领=新理念 / 驱动=技术创新 / 基础=信息网络（三个搭配勿互换）
类别特点典型内容
信息基础设施凸显「技术新」5G、物联网、工业互联网、卫星互联网、人工智能、云计算、区块链、数据中心、智能计算中心
融合基础设施重在「应用新」智能交通基础设施、智慧能源基础设施（传统基建 + 新技术改造升级）
创新基础设施强调「平台新」重大科技基础设施、科教基础设施、产业技术创新基础设施
判别法：纯数字底座 = 信息；传统设施被改造 = 融合；搞科研的 = 创新
• 通信网络基础设施：5G / 物联网 / 工业互联网 / 卫星互联网
• 新技术基础设施：人工智能 / 云计算 / 区块链
• 算力基础设施：数据中心 / 智能计算中心
记法：通信、新技术、算力（口诀：五物工卫、AI 云 链、数据中心 智算）

模块 B ｜ 工业互联网（1.2.2，P8）

工业互联网是新一代信息通信技术与工业经济深度融合的新型基础设施、应用模式和工业生态，是第四次工业革命的重要基石

网络是基础、平台是中枢、数据是要素、安全是保障

记法：网平数安 / 基中素保；口诀一字不易错

网络互联 / 数据互通 / 标识解析

• 网络互联：实现要素间数据传输（企业外网 + 企业内网）；典型技术：工业总线、工业以太网、TSN（时间敏感网络）、确定性网络、5G
• 数据互通：标准化描述 + 统一建模
• 标识解析：实现要素的标记、管理和定位；由标识编码、标识解析系统、标识数据服务组成

边缘层 → IaaS → PaaS → SaaS —— 相当于工业互联网的「操作系统」

四大作用：数据汇聚 / 建模分析 / 知识复用 / 应用创新

边缘层 = 设备连接管理、数据互联互通互操作

重要性、专业性、复杂性（口诀：重专复）

涉及范围广、造成影响大、企业防护基础弱（口诀：广、大、弱）

核心任务：监测预警、应急响应、检测评估、功能测试

平台化设计、智能化制造、网络化协同、个性化定制、服务化延伸、数字化管理

记法：设造制定延管（平台化设计 / 智能化制造 / 网络化协同 / 个性化定制 / 服务化延伸 / 数字化管理）
场景配对：远程运维/融资租赁 → 服务化延伸；敏捷/并行/基于模型的设计 → 平台化设计；供应链共享信息/协同生产 → 网络化协同

模块 C ｜ 车联网（1.2.3，P10）

车联网（IoV）= 新一代网络通信技术与汽车、电子、道路交通运输等领域深度融合的新兴产业形态

智能网联汽车=实现「安全、高效、舒适、节能」行驶

层核心职责
端系统智能传感器；采集车辆信息、感知行车状态与环境；具有车内通信、车间通信、车网通信的泛在通信终端；具备 IoV 寻址和网络可信标识能力
管系统解决车与车、车与路、车与网、车与人的互联互通；保障实时性、可服务性、网络泛在性；是公网与专网的统一体
云系统云架构的车辆运行信息平台；生态链含 ITS、物流、汽修汽配、保险、紧急救援等；多源海量信息汇聚；需要虚拟化、安全认证、实时交互、海量存储

车与云平台 / 车与车 / 车与路 / 车与人 / 车内设备

记法：云端 + 三外一内（云平台 + 三个外部 + 一个内部）

实用类（碰撞通知/被盗追踪/道路救援）/ 便捷类（语音手势/信息娱乐）/ 效率类（固件更新/远程启动/智能交通）

参考答案（先自己答完再展开） 1. **技术创新**（2024 上原题；引领=新发展理念、驱动=技术创新、基础=信息网络，勿互换） 2. 都属于**融合基础设施**，重在「**应用新**」；口诀：信息=技术新 / 融合=应用新 / 创新=平台新 3. **网络是基础、平台是中枢、数据是要素、安全为保障**；**平台**是中枢 4. **边缘层、IaaS、PaaS、SaaS**；相当于「**操作系统**」；四大作用：**数据汇聚、建模分析、知识复用、应用创新** 5. 网络体系三部分：**网络互联、数据互通、标识解析**；标识解析由**标识编码、标识解析系统、标识数据服务**三部分组成 6. **端系统**（智能传感器，IoV 寻址）/ **管系统**（互联互通，公网与专网的统一体）/ **云系统**（车辆运行信息平台，多源海量信息汇聚）；管系统解决**车与车、车与路、车与网、车人**的互联互通，保障实时性、可服务性、网络泛在性 7. 车与路 → 地面**道路固定通信设施**；车与云 → **卫星无线通信 / 移动蜂窝**无线通信技术 8. **服务化延伸**（从加工组装向价值链两端高附加值环节延伸）；口诀：**设造制定延管**（平台化**设**计 / 智能**化制造** / 网络**化协**同 / 个性**化定**制 / 服务**化延**伸 / 数字**化管理**）

1.2.1 新型基础设施建设
1新基建定义的三个搭配
  • 引领 = 新发展理念
  • 驱动 = 技术创新 ← 2024 上原题
  • 基础 = 信息网络
⚠️ 三个搭配千万不要互换，定义题最容易扣字眼。完整定义：以新发展理念为引领，以技术创新为驱动，以信息网络为基础，面向高质量发展需要，提供数字转型、智能升级、融合创新等服务的基础设施体系。
2新基建三大方面 + 三个「新」字特点
  • 信息基础设施 → 凸显「技术新」
  • 融合基础设施 → 重在「应用新」 ← 2025 上原题
  • 创新基础设施 → 强调「平台新」
判别口诀：纯数字底座 = 信息（5G、数据中心）；传统设施被改造 = 融合（智能交通、智慧能源）；搞科研的 = 创新（重大科技、科教、产业技术创新）
3信息基础设施三小类
  • 通信网络基础设施：5G / 物联网 / 工业互联网 / 卫星互联网
  • 新技术基础设施：人工智能 / 云计算 / 区块链
  • 算力基础设施：数据中心 / 智能计算中心
记法：「通信、新技术、算力」；或口诀「五物工卫、AI 云链、数据中心 智算」
1.2.2 工业互联网
4工业互联网定义
  • 工业互联网 = 新一代信息通信技术与工业经济深度融合的新型基础设施、应用模式和工业生态
  • 是第四次工业革命的重要基石
⚠️ 第 4 版口径（非旧版「工业以太网 + 互联网」的简单加和）
5平台体系四大定位
  • 网络 = 基础
  • 平台 = 中枢 ← 第 4 版新口径
  • 数据 = 要素
  • 安全 = 保障
口诀：网平数安 / 基中素保；⚠️ 旧资料常写「三大体系」按四项记
6网络体系三部分 + 标识解析三组成
  • 网络体系三部分：网络互联 / 数据互通 / 标识解析
  • 标识解析三组成：标识编码 / 标识解析系统 / 标识数据服务
  • 典型技术：工业总线、工业以太网、TSN（时间敏感网络）、确定性网络、5G
标识解析 = 实现要素的标记、管理和定位
7平台四层级 + 四大作用
  • 顺序：边缘层 → IaaS → PaaS → SaaS
  • 相当于工业互联网的「操作系统」
  • 四大作用：数据汇聚 / 建模分析 / 知识复用 / 应用创新
  • 边缘层 = 设备连接管理 + 数据互联互通互操作
顺序记法：边 I P S（像单词 EDIPS）
8工业互联网数据三特性
  • 重要性（数据是要素，地位核心）
  • 专业性（与行业知识深度耦合）
  • 复杂性（多源异构，标准化难）
口诀：重专复
9安全三特点 + 核心任务四手段
  • 三特点：涉及范围广 / 造成影响大 / 企业防护基础弱
  • 核心任务四手段：监测预警 / 应急响应 / 检测评估 / 功能测试
口诀：广、大、弱（三特点）；核心任务四手段 = 网络安全的常见四步法
10六大典型应用模式
  • 平台化设计（敏捷 / 并行 / 基于模型的设计）
  • 智能化制造
  • 网络化协同（供应链 / 协同生产）
  • 个性化定制
  • 服务化延伸（远程运维 / 融资租赁）
  • 数字化管理
口诀：设造制定延管（设计 / 制造 / 协同 / 定制 / 延伸 / 管理）
11「远程运维 / 融资租赁」对应模式
  • 对应 服务化延伸
  • 本质：制造业从加工组装向价值链两端高附加值环节延伸
两端 = 上游研发设计 + 下游运维服务；「设造制定延管」中「延」就是「服务化延伸」
1.2.3 车联网
12车联网「端、管、云」三层体系
  • 端系统：智能传感器；采集车辆信息 / 感知行车状态与环境；车内通信、车间通信、车网通信的泛在通信终端；具备 IoV 寻址和网络可信标识能力
  • 管系统：解决车与车 / 车与路 / 车与网 / 车与人的互联互通；保障实时性、可服务性、网络泛在性；是公网与专网的统一体
  • 云系统：云架构的车辆运行信息平台；生态链含 ITS、物流、汽修汽配、保险、紧急救援等；多源海量信息汇聚；需要虚拟化、安全认证、实时交互、海量存储
五种链接方式：车与云 / 车与车 / 车与路 / 车与人 / 车内设备（口诀：云端 + 三外一内）
总结区 本节本质 + 考点地图
本节本质：新一代信息基础设施（数字底座）+ 工业 / 交通行业的融合应用场景；上午 1~2 题，连续两年考「新基建归属」是高频套路。
考点地图（按考频排序）：① 新基建三大方面归属判断（2025 上原题）→ ② 新基建定义「引领/驱动/基础」（2024 上原题）→ ③ 工业互联网四大定位 + 平台四层级 → ④ 六大典型应用模式（场景反推模式名）→ ⑤ 信息基础设施三小类 → ⑥ 车联网端管云 + 五种链接方式 → ⑦ 数据三特性 / 安全三特点 / 核心任务四手段。
⚠️ 口径陷阱：①定义三搭配「引领/驱动/基础」勿互换；②信息基础设施 =「技术新」，融合 =「应用新」，创新 =「平台新」；③工业互联网「四大定位」非「三大体系」；④车联网第 4 版未提 DSRC/C-V2X，仅写 5 类链接方式。

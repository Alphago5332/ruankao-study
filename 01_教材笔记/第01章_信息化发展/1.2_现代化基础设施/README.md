## 学习目标

- [ ] 背熟"新基建"内容分类：信息基础设施（技术新）/ 融合基础设施（应用新）/ 创新基础设施（平台新）
- [ ] 能准确归属判断：信息基础设施拆三小类——通信网络（5G/物联网/工业互联网/卫星互联网）、新技术（AI/云计算/区块链）、算力（数据中心/智能计算中心）
- [ ] 背熟工业互联网平台体系四大层级：**网络是基础、平台是中枢、数据是要素、安全是保障**
- [ ] 背熟工业互联网六大典型应用模式：平台化设计、智能化制造、网络化协同、个性化定制、服务化延伸、数字化管理
- [ ] 掌握车联网「端、管、云」三层体系 + 五种链接方式（车与云/车/路/人/车内设备）

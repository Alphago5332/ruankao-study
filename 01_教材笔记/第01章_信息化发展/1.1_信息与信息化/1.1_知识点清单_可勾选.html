一、必背清单

模块 A ｜ 信息（1.1.1，P2）

属性判断关键词
精确性对事物状态描述的精准程度
完整性对事物状态描述的全面程度
可靠性信息来源、采集方法可被信任的程度
及时性获得信息的时刻与事件发生时刻的间隔长短
经济性信息获取、传输的成本可接受
可验证性主要质量属性可被证实或证伪的程度
安全性生命周期内被非授权访问的可能性最小
记法：精完可及经可安（精确、完整、可靠、及时、经济、可验证、安全）

「信息是用来消除随机不定性的东西」（香农，1948，创立信息论）

信息量的单位是比特（bit）；信息是物质、能量及其属性的标示的集合，是确定性的增加；信息不是物质，也不是能量

特征：客观性、普遍性、无限性、动态性、相对性、依附性、变换性、传递性、层次性、系统性、转化性

场景配对（教材原例）：金融信息 → 最重安全性；经济与社会信息 → 最重及时性

模块 B ｜ 信息系统（1.1.2，P2）

管理模型 + 信息处理模型 + 系统实现条件

• 管理模型：系统服务对象领域的专门知识，及分析和处理该领域问题的模型（又称对象的处理模型）
• 信息处理模型：系统处理信息的结构和方法
• 系统实现条件：可供应用的计算机技术和通信技术、从事对象领域工作的人员、对这些资源的控制与融合

部件（9 类）：硬件、软件、数据库、网络、存储设备、感知设备、外设、人员、把数据处理成信息的规程

按用途分：电子商务 / 事务处理 / 管理信息 / 生产制造 / 电子政务 / 决策支持系统

系统规划 → 系统分析 → 系统设计 → 系统实施 → 系统运行与维护

括号内对应（命题点）：规划=可行性分析与项目开发计划；分析=需求分析；设计=概要设计、详细设计；实施=编码、测试

逻辑 / 物理之辨：系统分析 → 逻辑模型（成果：系统说明书）；系统设计 → 物理模型（又称物理设计阶段，成果：系统设计说明书）

方法核心思想适用场景
结构化方法自顶向下、逐步求精、模块化需求明确、稳定
面向对象方法对象、封装、继承、多态复杂、可复用要求高
原型化方法快速建立原型、迭代需求不清、用户参与
面向服务方法（SOA）服务松耦合、可编排系统集成、异构

模块 C ｜ 信息化（1.1.3，P4）

产品信息化 / 产业信息化 / 社会生活信息化 / 国民经济信息化

注意：中级教材另有「5 层次」口径（含企业信息化），高项第 4 版按上述 4 项趋势表述

① 产品中信息比重日益增大、物质比重日益降低，物质产品特征向信息产品特征迈进

② 越来越多产品嵌入智能化元器件，具有越来越强的信息处理功能

要素地位
信息技术应用龙头（国家信息化建设的主阵地）
信息资源核心任务（开发利用；也是我国信息化的薄弱环节）
信息网络基础设施
信息技术和产业物质基础
信息化人才成功之本
信息化政策法规和标准规范保障
记法：应资网产人法；各自定位都可能单独出题

信息网络体系 / 信息产业基础 / 社会运行环境 / 效用积累过程

模块 D ｜ 现代化基础设施（1.2，P7）

类别典型内容
信息基础设施5G、物联网、工业互联网、卫星互联网、人工智能、云计算、区块链、数据中心、智能计算中心
融合基础设施智能交通基础设施、智慧能源基础设施等（传统基建 + 新技术改造升级）
创新基础设施重大科技基础设施、科教基础设施、产业技术创新基础设施
信息基础设施还分三小类 ⭕ 高频：通信网络基础设施（5G / 物联网 / 工业互联网 / 卫星互联网）、新技术基础设施（人工智能 / 云计算 / 区块链）、算力基础设施（数据中心 / 智能计算中心）
判别法：纯数字底座 = 信息；传统设施被改造 = 融合；搞科研的 = 创新

网络为基础、平台为中枢、数据为要素、安全为保障

⚠️ 旧资料常说「三大体系」，第 4 版增加了「数据为要素」，按四项记

边缘层、IaaS、PaaS、SaaS —— 相当于工业互联网的「操作系统」

四大作用：数据汇聚 / 建模分析 / 知识复用 / 应用创新

两化融合 = 信息化 + 工业化 融合

关联：「中国制造 2025」是智能制造的国家战略背景

三、本章自检题（做完再合书）

  1. 「信息在生命周期内被非授权访问的可能性最小」体现的是信息的哪个质量属性？（不看书答）
  2. 国家信息化体系六要素中，哪一项是龙头、哪一项是核心任务？
  3. 「智能计算中心」属于新基建的哪一类？「智慧能源」呢？
  4. 工业互联网平台体系的四大定位是什么？哪一个是中枢？
  5. 「工业互联网」属于数字经济里的数字产业化还是产业数字化？（思考题，答案见下）
  6. 信息系统生命周期五阶段的正确顺序是？系统分析阶段提出的是什么模型？
参考答案（先自己答完再展开） 1. **安全性** 2. 龙头 = 信息技术应用；核心任务 = 信息资源的开发利用（也是薄弱环节） 3. 智能计算中心 → 信息基础设施（其中的算力基础设施）；智慧能源 → 融合基础设施 4. 网络为基础、平台为中枢、数据为要素、安全为保障；中枢 = 平台 5. 需分语境：作为「技术产品/服务」供给时归数字产业化；作为「赋能传统工业」的能力时归产业数字化（考试中常作为辨析点，注意题干落脚点） 6. 系统规划 → 系统分析 → 系统设计 → 系统实施 → 系统运行与维护；系统分析提出**逻辑模型**（系统设计才是物理模型）

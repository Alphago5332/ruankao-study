## 一、必背清单

### 模块 A ｜ 信息（1.1.1，P2）

- [ ] **A1 · 信息的质量属性（7 项）** ⭕ 必考
  | 属性 | 判断关键词 |
  |---|---|
  | 精确性 | 对事物状态描述的**精准**程度 |
  | 完整性 | 对事物状态描述的**全面**程度 |
  | 可靠性 | 信息来源、采集方法**可被信任**的程度 |
  | 及时性 | 获得信息的时刻与事件发生时刻的**间隔长短** |
  | 经济性 | 信息获取、传输的**成本可接受** |
  | 可验证性 | 主要质量属性可被**证实或证伪**的程度 |
  | 安全性 | 生命周期内被**非授权访问的可能性最小** |
  > 记法：**精完可及经可安**（精确、完整、可靠、及时、经济、可验证、安全）
- [ ] **A2 · 信息的定义（香农表述）** ⭕ 必考
  「信息是用来**消除随机不定性**的东西」（香农，1948，创立信息论）
  信息量的单位是**比特（bit）**；信息是物质、能量及其属性的标示的集合，是**确定性的增加**；信息不是物质，也不是能量
- [ ] **A3 · 信息的特征 + 场景侧重** ⭕ 常考
  特征：客观性、普遍性、无限性、动态性、相对性、依附性、变换性、传递性、层次性、系统性、转化性
  **场景配对（教材原例）**：金融信息 → 最重**安全性**；经济与社会信息 → 最重**及时性**

### 模块 B ｜ 信息系统（1.1.2，P2）

- [ ] **B1 · 信息系统 = 三结合** ⭕ 必背
  **管理模型 + 信息处理模型 + 系统实现条件**
  - 管理模型：系统服务对象领域的专门知识，及分析和处理该领域问题的模型（又称对象的处理模型）
  - 信息处理模型：系统处理信息的结构和方法
  - 系统实现条件：可供应用的计算机技术和通信技术、从事对象领域工作的人员、对这些资源的控制与融合
- [ ] **B1.2 · 组成部件与用途分类**
  部件（9 类）：硬件、软件、数据库、网络、存储设备、感知设备、外设、人员、把数据处理成信息的**规程**
  按用途分：电子商务 / 事务处理 / 管理信息 / 生产制造 / 电子政务 / 决策支持系统
- [ ] **B2 · 信息系统的生命周期（5 阶段）** ⭕ 必背
  `系统规划 → 系统分析 → 系统设计 → 系统实施 → 系统运行与维护`
  括号内对应（命题点）：规划=**可行性分析与项目开发计划**；分析=**需求分析**；设计=**概要设计、详细设计**；实施=**编码、测试**
  逻辑 / 物理之辨：**系统分析 → 逻辑模型**（成果：系统说明书）；**系统设计 → 物理模型**（又称物理设计阶段，成果：系统设计说明书）
- [ ] **B3 · 信息系统开发方法（4 种）**（通用口径，高项第 4 版第 1 章未展开，第 5 章软件工程会涉及，了解即可）
  | 方法 | 核心思想 | 适用场景 |
  |---|---|---|
  | 结构化方法 | 自顶向下、逐步求精、模块化 | 需求**明确**、稳定 |
  | 面向对象方法 | 对象、封装、继承、多态 | 复杂、可复用要求高 |
  | 原型化方法 | 快速建立原型、迭代 | 需求**不清**、用户参与 |
  | 面向服务方法（SOA） | 服务松耦合、可编排 | 系统集成、异构 |

### 模块 C ｜ 信息化（1.1.3，P4）

- [ ] **C1 · 组织信息化的 4 大趋势** ⭕ 常考
  `产品信息化 / 产业信息化 / 社会生活信息化 / 国民经济信息化`
  > 注意：中级教材另有「5 层次」口径（含企业信息化），高项第 4 版按上述 4 项趋势表述
- [ ] **C1.2 · 产品信息化的两层含义** ⭕ 考过
  ① 产品中**信息比重日益增大、物质比重日益降低**，物质产品特征向信息产品特征迈进
  ② 越来越多产品**嵌入智能化元器件**，具有越来越强的信息处理功能
- [ ] **C2 · 国家信息化体系六要素** ⭕ 必考（**高频**）
  | 要素 | 地位 |
  |---|---|
  | 信息技术应用 | **龙头**（国家信息化建设的主阵地） |
  | 信息资源 | **核心任务**（开发利用；也是我国信息化的薄弱环节） |
  | 信息网络 | 基础设施 |
  | 信息技术和产业 | 物质基础 |
  | 信息化人才 | 成功之本 |
  | 信息化政策法规和标准规范 | 保障 |
  > 教材原话与表格关系：**「信息资源的开发利用」是核心任务**。「信息资源」是六要素名称（表格第一列），「开发利用」是其角色内涵（第二列补充）。
  > 易错点：题干问"____ 是核心任务"，答「信息资源的开发利用」是教材原话最完整；答「信息资源」也对（六要素名），但答题系统在判分时接受这两种写法。
  > 记法：**应资网产人法**；各自定位都可能单独出题
- [ ] **C3 · 信息化内涵 4 方面**（了解）
  信息网络体系 / 信息产业基础 / 社会运行环境 / 效用积累过程

### 模块 D ｜ 现代化基础设施（1.2，P7）

- [ ] **D1 · 新基建三大类** ⭕ 必考（给例子判归属）
  | 类别 | 典型内容 |
  |---|---|
  | **信息基础设施** | 5G、物联网、工业互联网、卫星互联网、人工智能、云计算、区块链、数据中心、智能计算中心 |
  | **融合基础设施** | 智能交通基础设施、智慧能源基础设施等（传统基建 + 新技术改造升级） |
  | **创新基础设施** | 重大科技基础设施、科教基础设施、产业技术创新基础设施 |
  > **信息基础设施还分三小类** ⭕ 高频：**通信网络基础设施**（5G / 物联网 / 工业互联网 / 卫星互联网）、**新技术基础设施**（人工智能 / 云计算 / 区块链）、**算力基础设施**（数据中心 / 智能计算中心）
  > 判别法：**纯数字底座 = 信息；传统设施被改造 = 融合；搞科研的 = 创新**
- [ ] **D2 · 工业互联网平台体系四大定位** ⭕ 必考（第 4 版口径）
  **网络为基础、平台为中枢、数据为要素、安全为保障**
  > ⚠️ 旧资料常说「三大体系」，第 4 版增加了「数据为要素」，按四项记
- [ ] **D2.2 · 平台体系四层级** ⭕ 必背
  `边缘层、IaaS、PaaS、SaaS` —— 相当于工业互联网的「**操作系统**」
  四大作用：**数据汇聚 / 建模分析 / 知识复用 / 应用创新**
- [ ] **D2.3 · 网络体系三部分**：**网络互联、数据互通、标识解析**
- [ ] **D3 · 车联网**（了解）：车与云、车与车、车与路、车与人（V2X）

### 模块 F ｜ 数字中国（1.4，P16）

- [ ] **F1 · 数字经济的两大组成** ⭕ 必考
  | 类型 | 含义 | 举例 |

## 三、本章自检题（做完再合书）

1. 「信息在生命周期内被非授权访问的可能性最小」体现的是信息的哪个质量属性？（不看书答）
2. 国家信息化体系六要素中，哪一项是**龙头**、哪一项是**核心任务**？
3. 「智能计算中心」属于新基建的哪一类？「智慧能源」呢？
4. 工业互联网平台体系的四大定位是什么？哪一个是**中枢**？
5. 「工业互联网」属于数字经济里的**数字产业化**还是**产业数字化**？（思考题，答案见下）
6. 信息系统生命周期五阶段的正确顺序是？系统分析阶段提出的是什么模型？

<details>
<summary>参考答案（先自己答完再展开）</summary>

1. **安全性**
2. 龙头 = 信息技术应用；核心任务 = 信息资源的开发利用（也是薄弱环节）
3. 智能计算中心 → 信息基础设施（其中的算力基础设施）；智慧能源 → 融合基础设施
4. 网络为基础、平台为中枢、数据为要素、安全为保障；中枢 = 平台
5. 需分语境：作为「技术产品/服务」供给时归数字产业化；作为「赋能传统工业」的能力时归产业数字化（考试中常作为辨析点，注意题干落脚点）
6. 系统规划 → 系统分析 → 系统设计 → 系统实施 → 系统运行与维护；系统分析提出**逻辑模型**（系统设计才是物理模型）

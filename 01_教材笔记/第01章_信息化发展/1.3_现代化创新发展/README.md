## 易混防坑

- 智能制造成熟度五级（规划 / **规范 / 集成** / 优化 / 引领）≠ 智慧城市成熟度五级（规划 / **管理 / 协同** / 优化 / 引领）
- 「产业**衍生**」不是「产业融合」；两化融合核心是「信息化支撑」不是「工业化支撑」
- 旧骨架笔记中「智能制造 4 个层级（设备/车间/工厂/供应链）」为错误口径，第 4 版 1.3 未讲此内容，已废弃

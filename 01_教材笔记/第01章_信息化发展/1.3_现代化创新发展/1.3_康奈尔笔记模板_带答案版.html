1.3.1 农业农村现代化
1农业现代化定义 + 核心手段
  • 用现代工业装备农业 / 用现代科学技术改造农业 / 用现代管理方法管理农业 / 用现代科学文化知识提高农民素质
  • 核心手段 = 农业信息化（既是目标也是手段）
农业信息化 = 利用信息技术和信息系统为农业产、供、销及相关管理、服务提供有效信息支持
2乡村振兴数字赋能三大重点
  • 建设基础设施：农村千兆光网、5G、移动物联网与城市同步规划建设；新建和改造两手抓
  • 发展智慧农业：农业农村大数据体系；数字田园、数字灌区、智慧农牧渔场
  • 建设数字乡村：乡村数字惠民服务体系；「互联网+」政务服务向农村基层延伸
记法：设施、农业、乡村（先修路 → 再种田 → 后惠民）
3智慧农业核心抓手
  • 体系：农业农村大数据体系
  • 四技术：物联网、大数据、人工智能、区块链与农业生产经营深度融合
  • 三载体：数字田园、数字灌区、智慧农牧渔场
数字乡村还有：乡村智慧社区建设；农村教育、医疗、文化数字化
1.3.2 两化融合
4两化融合定义与核心
  • 定义：信息化和工业化的高层次深度结合，以信息化带动工业化、以工业化促进信息化，走新型工业化道路
  • 核心 = 信息化支撑，追求可持续发展模式
两个「带动 / 促进」方向勿写反：信息化带动工业化
5四个方面融合
  • 技术融合：工业技术 + 信息技术 → 产生新技术（汽车电子技术、工业控制技术）
  • 产品融合：信息技术渗透到产品中（数控机床、智能家电、遥控飞机）
  • 业务融合：信息技术应用到研发设计、生产制造、经营管理、市场营销各环节（替代手工台账、网络营销）
  • 产业衍生：催生新产业、新兴业态（工业电子、工业软件、工业信息服务业）
判别法：出新东西 = 技术；装进产品 = 产品；进流程环节 = 业务；生出新产业 = 产业衍生（口诀「技产务衍」）
6例子归类
  • 数控机床 / 智能家电 → 产品融合
  • 网络营销 / 计算机管理替代手工台账 → 业务融合
  • 工业软件 / B2B 电商 / 信息化咨询 → 产业衍生
  • 汽车电子技术 / 工业控制技术 → 技术融合
工业电子含：机械、汽车、船舶、航空电子；工业软件含：设计软件、控制软件
7两化融合意义的三个「是」
  • 制造业数字化、网络化、智能化发展的必由之路
  • 中国特色新型工业化道路的集中体现
  • 建设制造强国、网络强国和数字中国的关键点
三个「是」按「路径 → 道路 → 关键点」梯度记
1.3.2 智能制造
8智能制造定义
  • 基于新一代信息通信技术与先进制造技术深度融合
  • 贯穿于设计、生产、管理、服务等制造活动的各个环节（口诀：设生管服）
  • 「五自」：自感知、自学习、自决策、自执行、自适应
五自记法：感、学、决、执、适；本质 = 新型生产方式
9GB/T 39116 成熟度五等级
  • 一级规划级：基础条件规划，核心业务活动流程化管理
  • 二级规范级：自动化 / 信息技术改造规范，单一业务活动数据共享
  • 三级集成级：装备、系统集成，跨业务活动数据共享
  • 四级优化级：数据挖掘形成知识、模型，精准预测和优化
  • 五级引领级：模型持续驱动优化创新，产业链协同并衍生新模式
⚠️ 易混：智慧城市五级 = 规划 / 管理 / 协同 / 优化 / 引领——第二、三级名称不同，勿背串！高等级涵盖低等级要求。
10能力要素四项
  • 人员：组织战略、人员技能（2 子域）
  • 技术：数据、集成、信息安全（3 子域）
  • 资源：装备、网络（2 子域）
  • 制造：设计、生产、物流、销售、服务（5 子域）
口诀：人技资制；「制造」5 子域 = 智能制造贯穿的五个环节
1.3.3 消费互联网
11消费互联网两大基本属性
  • 媒体属性：自媒体、社交媒体、资讯门户网站
  • 产业属性：在线旅游、为消费者提供生活服务的电子商务
定义关键词：个人用户为中心、日常生活场景为应用背景；实质是个人虚拟化过程
12「无身份社会」的实现基础
  • 互联网搭建更高层次的信任校验模式
  • 通过数据记录、存储、整合和共享，实现复杂校验和过程可追溯
  • 相关参与者无需花费时间完成「身份认定」
社交圈聚集 → 新型网络经济：网络商城、快递、外卖、网红带货（消费互联网的核心地位）
总结区 本节本质 + 考点地图
本节本质：创新驱动战略的四个落地场景（农业农村 / 工业两化融合 / 智能制造 / 消费互联网）；上午约 1 题，「四个方面融合」给例子判归类是高频套路。
考点地图（按考频排序）：① 两化融合四个方面 + 例子归类 → ② 智能制造成熟度五级（规划 / 规范 / 集成 / 优化 / 引领）→ ③ 智能制造定义「五自」+ 贯穿环节 → ④ 乡村振兴数字赋能三重点 → ⑤ 消费互联网两大属性 → ⑥ 农业现代化核心手段 = 农业信息化 → ⑦ 能力要素四项（人技资制）。
⚠️ 口径陷阱：①智能制造成熟度五级 ≠ 智慧城市成熟度五级（第二、三级「规范·集成」vs「管理·协同」）；②两化融合是「高层次深度结合」非简单叠加；③能力要素「技术」下是数据 / 集成 / 信息安全三个子域；④「产业衍生」不叫「产业融合」。

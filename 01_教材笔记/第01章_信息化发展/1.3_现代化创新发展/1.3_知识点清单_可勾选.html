一、必背清单

模块 A ｜ 农业农村现代化（1.3.1）

用现代工业装备农业、用现代科学技术改造农业、用现代管理方法管理农业、用现代科学文化知识提高农民素质的过程

农业现代化既是目标也是手段；核心手段 = 农业信息化

利用信息技术和信息系统为农业产、供、销及相关管理、服务提供有效信息支持，提高农业综合生产力和经营管理效率的过程

重点关键词
建设基础设施农村千兆光网、5G、移动物联网与城市同步规划建设；农业生产加工和农村基础设施数字化、智能化升级；新建和改造两手抓
发展智慧农业建立农业农村大数据体系；推动物联网、大数据、人工智能、区块链与农业生产经营深度融合；建设数字田园、数字灌区、智慧农牧渔场
建设数字乡村线上线下结合的乡村数字惠民服务体系；「互联网+」政务服务向农村基层延伸；乡村智慧社区；农村教育、医疗、文化数字化
记法：设施、农业、乡村（先修路 → 再种田 → 后惠民）

模块 B ｜ 两化融合（1.3.2 上）

两化融合是信息化和工业化的高层次深度结合，以信息化带动工业化、以工业化促进信息化，走新型工业化道路

核心 = 信息化支撑，追求可持续发展模式

① 制造业数字化、网络化、智能化发展的必由之路；② 中国特色新型工业化道路的集中体现；③ 建设制造强国、网络强国和数字中国的关键点

方面含义教材例子
技术融合工业技术与信息技术融合，产生新技术汽车制造技术 + 电子技术 = 汽车电子技术；工业 + 计算机控制技术 = 工业控制技术
产品融合电子信息技术 / 产品渗透到产品中，增加技术含量普通机床 + 数控系统 = 数控机床；传统家电 + 智能化技术 = 智能家电；飞机模型 + 控制芯片 = 遥控飞机
业务融合信息技术应用到研发设计、生产制造、经营管理、市场营销等各环节计算机管理替代手工台账；网络营销
产业衍生催生新产业、新兴业态工业电子（机械 / 汽车 / 船舶 / 航空电子）、工业软件（设计 / 控制软件）、工业信息服务业（B2B 电商、信息化咨询）
判别法：出新东西 = 技术；装进产品 = 产品；进流程环节 = 业务；生出新产业 = 产业衍生
记法：口诀「技产务衍」（技术、产品、业务、产业衍生）

模块 C ｜ 智能制造（1.3.2 下）

智能制造（IM）是基于新一代信息通信技术与先进制造技术深度融合，贯穿于设计、生产、管理、服务等制造活动的各个环节，具有自感知、自学习、自决策、自执行、自适应等功能的新型生产方式

「五自」记法：感、学、决、执、适；环节记法：设生管服

由智能机器和人类专家共同组成；制造过程中进行分析、推理、判断、构思和决策等智能活动；把制造自动化扩展到柔性化、智能化和高度集成化

能力要素四项：人员（组织战略、人员技能）/ 技术（数据、集成、信息安全）/ 资源（装备、网络）/ 制造（设计、生产、物流、销售、服务）

等级名称关键特征
一级规划级对实施智能制造的基础和条件进行规划；核心业务活动流程化管理
二级规范级采用自动化技术、信息技术改造和规范；实现单一业务活动的数据共享
三级集成级对装备、系统开展集成；实现跨业务活动间的数据共享
四级优化级对人员、资源、制造进行数据挖掘，形成知识、模型；实现精准预测和优化
五级引领级基于模型持续驱动业务活动的优化和创新；实现产业链协同并衍生新的制造模式和商业模式
⚠️ 易混：1.4 节智慧城市成熟度五级是「规划 / 管理 / 协同 / 优化 / 引领」——第二、三级名称不同，勿背串！

模块 D ｜ 消费互联网（1.3.3）

以个人用户为中心、以日常生活场景为应用背景的互联网类型；实质是个人虚拟化的过程，增强个人生活消费体验

媒体属性（自媒体、社交媒体、资讯门户网站）/ 产业属性（在线旅游、为消费者提供生活服务的电子商务）

社交圈因特定因素聚集 → 新型网络经济：网络商城、快递、外卖、网红带货；「无身份社会」：互联网搭建更高层次的信任校验模式，通过数据记录、存储、整合和共享实现复杂校验和过程可追溯

二、可以只通读、暂不背的（标记避免浪费时间）

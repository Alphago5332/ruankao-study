## 一、必背清单

### 模块 A ｜ 农业农村现代化（1.3.1）

- [ ] **A1 · 农业现代化定义** ⭕ 常考
  用**现代工业**装备农业、用**现代科学技术**改造农业、用**现代管理方法**管理农业、用**现代科学文化知识**提高农民素质的过程
  > 农业现代化既是**目标**也是**手段**；核心手段 = **农业信息化**
- [ ] **A2 · 农业信息化定义**（理解）
  利用信息技术和信息系统为农业**产、供、销及相关管理、服务**提供有效信息支持，提高农业综合生产力和经营管理效率的过程
- [ ] **A3 · 乡村振兴战略（数字赋能重点）** ⭕ 必背
  聚焦**数字赋能农业农村现代化建设**，重点三个方面：
  | 重点 | 关键词 |
  |---|---|
  | **建设基础设施** | 农村**千兆光网、5G、移动物联网**与**城市同步**规划建设；农业生产加工和农村基础设施数字化、智能化升级；**新建和改造两手抓** |
  | **发展智慧农业** | 建立**农业农村大数据体系**；推动**物联网、大数据、人工智能、区块链**与农业生产经营深度融合；建设**数字田园、数字灌区、智慧农牧渔场** |
  | **建设数字乡村** | 线上线下结合的乡村**数字惠民服务体系**；「**互联网+**」政务服务向农村基层延伸；**乡村智慧社区**；农村**教育、医疗、文化**数字化 |
  > 记法：**设施、农业、乡村**（先修路 → 再种田 → 后惠民）

### 模块 B ｜ 两化融合（1.3.2 上）

- [ ] **B1 · 定义** ⭕ 必背
  两化融合是信息化和工业化的**高层次深度结合**，以**信息化带动工业化**、以**工业化促进信息化**，走**新型工业化道路**
  > 核心 = **信息化支撑**，追求**可持续发展**模式
- [ ] **B2 · 意义三个「是」** ⭕ 常考
  ① 制造业**数字化、网络化、智能化**发展的**必由之路**；② **中国特色新型工业化道路**的集中体现；③ 建设制造强国、网络强国和数字中国的**关键点**
- [ ] **B3 · 四个方面融合** ⭕ 必考
  | 方面 | 含义 | 教材例子 |
  |---|---|---|
  | **技术融合** | 工业技术与信息技术融合，**产生新技术** | 汽车制造技术 + 电子技术 = **汽车电子技术**；工业 + 计算机控制技术 = **工业控制技术** |
  | **产品融合** | 电子信息技术 / 产品**渗透到产品中**，增加技术含量 | 普通机床 + 数控系统 = **数控机床**；传统家电 + 智能化技术 = **智能家电**；飞机模型 + 控制芯片 = **遥控飞机** |
  | **业务融合** | 信息技术应用到**研发设计、生产制造、经营管理、市场营销**等各环节 | 计算机管理**替代手工台账**；**网络营销** |
  | **产业衍生** | 催生**新产业、新兴业态** | **工业电子**（机械 / 汽车 / 船舶 / 航空电子）、**工业软件**（设计 / 控制软件）、**工业信息服务业**（B2B 电商、信息化咨询） |
  > 判别法：**出新东西** = 技术；**装进产品** = 产品；**进流程环节** = 业务；**生出新产业** = 产业衍生
  > 记法：**技产业衍** —— 口诀「**技产务衍**」（技术、产品、业务、产业衍生）

### 模块 C ｜ 智能制造（1.3.2 下）

- [ ] **C1 · 定义** ⭕ 必背
  智能制造（**IM**）是基于**新一代信息通信技术与先进制造技术深度融合**，贯穿于**设计、生产、管理、服务**等制造活动的各个环节，具有**自感知、自学习、自决策、自执行、自适应**等功能的新型生产方式
  > 「五自」记法：**感、学、决、执、适**；环节记法：**设生管服**
- [ ] **C2 · 人机一体化智能系统**（理解）
  由**智能机器和人类专家**共同组成；制造过程中进行**分析、推理、判断、构思和决策**等智能活动；把制造自动化扩展到**柔性化、智能化和高度集成化**
- [ ] **C3 · GB/T 39116《智能制造能力成熟度模型》** ⭕ 必考
  - **能力要素四项**：**人员**（组织战略、人员技能）/ **技术**（数据、集成、信息安全）/ **资源**（装备、网络）/ **制造**（设计、生产、物流、销售、服务）
  - **五个等级**（自低向高，高等级涵盖低等级要求）：
  | 等级 | 名称 | 关键特征 |
  |---|---|---|
  | 一级 | **规划级** | 对实施智能制造的基础和条件进行**规划**；核心业务活动**流程化**管理 |
  | 二级 | **规范级** | 采用**自动化技术、信息技术**改造和规范；实现**单一业务活动**的数据共享 |
  | 三级 | **集成级** | 对装备、系统开展**集成**；实现**跨业务活动**间的数据共享 |
  | 四级 | **优化级** | 对人员、资源、制造进行**数据挖掘**，形成**知识、模型**；实现精准**预测和优化** |
  | 五级 | **引领级** | 基于**模型持续驱动**业务活动的优化和创新；实现**产业链协同**并**衍生新的制造模式和商业模式** |
  > ⚠️ 易混：1.4 节智慧城市成熟度五级是「规划 / 管理 / 协同 / 优化 / 引领」——第二、三级名称不同，勿背串！

### 模块 D ｜ 消费互联网（1.3.3）

- [ ] **D1 · 定义**（理解）
  以**个人用户**为中心、以**日常生活场景**为应用背景的互联网类型；实质是**个人虚拟化**的过程，增强个人生活消费体验
- [ ] **D2 · 两大基本属性** ⭕ 必背
  **媒体属性**（自媒体、社交媒体、资讯门户网站）/ **产业属性**（在线旅游、为消费者提供生活服务的电子商务）
- [ ] **D3 · 应用新格局**（通读，记关键词）
  社交圈因特定因素**聚集** → 新型网络经济：**网络商城、快递、外卖、网红带货**；「**无身份社会**」：互联网搭建更高层次的**信任校验模式**，通过数据记录、存储、整合和共享实现**复杂校验和过程可追溯**

7. **人员、技术、资源、制造**；「技术」要素下含**数据、集成、信息安全** 3 个能力子域
8. **媒体属性**（自媒体、社交媒体、资讯门户网站）/ **产业属性**（在线旅游、生活服务电子商务）；靠互联网通过**数据记录、存储、整合和共享**实现更高层次的**信任校验**和**过程可追溯**

1.1 信息与信息化
1信息的 7 项质量属性
  • 精确性（精准程度）/ 完整性（全面程度）
  • 可靠性（来源/方法可被信任）/ 及时性（与事件发生的间隔）
  • 经济性（成本可接受）/ 可验证性（可证实/证伪）
  • 安全性（非授权访问可能性最小） ← 本题答案
口诀：精完可及经可安　场景配对：金融信息→安全性；经济社会信息→及时性
2香农对信息的定义
  • 信息是用来消除随机不定性的东西（香农，1948，创立信息论）
  • 信息量的单位 = 比特（bit）
  • 信息是物质、能量及其属性的标示的集合；是确定性的增加
  • 信息既不是物质、也不是能量
3信息系统 = 三结合
  • 管理模型（对象领域知识 + 处理模型）
  • 信息处理模型（处理信息的结构与方法）
  • 系统实现条件（计算机/通信技术 + 人员 + 控制融合）
⚠️ 第 4 版口径，不是中级教材的「人机一体化系统」
·组成部件（9 类）
  • 硬件、软件、数据库、网络、存储设备、感知设备、外设、人员、把数据处理成信息的规程
4信息系统生命周期 5 阶段
  • 顺序：规划 → 分析 → 设计 → 实施 → 运行与维护
  • 各阶段核心产出：可行性研究 / 需求说明书 / 系统设计说明书 / 软件+测试 / 运维
  • 系统分析 → 逻辑模型；系统设计 → 物理模型（常考辨析）
54 种开发方法适配场景
  • 结构化：需求明确、稳定（瀑布）
  • 原型化：需求不清、需快速验证
  • 面向对象：复杂、可复用要求高
  • 面向服务（SOA）：系统集成、异构环境
第 4 版第 1 章未展开，第 5 章软件工程会再涉及
6组织信息化 4 大趋势 + 产品信息化两层含义
  • 4 大趋势：产品信息化 / 产业信息化 / 社会生活信息化 / 国民经济信息化
  • 产品信息化①：信息比重日益增大、物质比重日益降低
  • 产品信息化②：嵌入智能化元器件，具越来越强的信息处理功能
⚠️ 中级教材另有「5 层次」（含企业信息化），高项第 4 版按 4 项趋势表述
7国家信息化体系六要素
  • 信息技术应用 → 龙头（主阵地）
  • 信息资源 → 核心任务（开发利用；薄弱环节）
  • 信息网络 → 基础设施
  • 信息技术和产业 → 物质基础
  • 信息化人才 → 成功之本
  • 信息化政策法规和标准规范 → 保障
口诀：应资网产人法（信息技术应用 / 信息资源 / 信息网络 / 信息技术和产业 / 信息化人才 / 政策法规）
1.2 现代化基础设施
8新基建三大类 + 信息基础设施三小类
  • 信息基础设施（纯数字底座）：5G / 物联网 / 工业互联网 / 卫星互联网 + AI / 云计算 / 区块链 + 数据中心 / 智能计算中心
  • 融合基础设施（传统设施被改造）：智能交通 / 智慧能源
  • 创新基础设施（搞科研的）：重大科技 / 科教 / 产业技术创新
信息基础设施三小类：通信网络（5G/物联网/工业互联网/卫星）+ 新技术（AI/云计算/区块链）+ 算力（数据中心/智能计算中心）
判别口诀：纯数字=信息；改造=融合；科研=创新
9工业互联网四大定位 + 平台四层级
  • 四大定位：网络为基础 / 平台为中枢 / 数据为要素 / 安全为保障
  • 平台四层级：边缘层、IaaS、PaaS、SaaS（=工业互联网的「操作系统」）
  • 平台四大作用：数据汇聚 / 建模分析 / 知识复用 / 应用创新
  • 网络体系三部分：网络互联 / 数据互通 / 标识解析
⚠️ 第 4 版新增「数据为要素」；旧资料常说「三大体系」，按四项记
1.3 ~ 1.5（通读）
10两化融合 + 智能制造
  • 两化融合 = 信息化 + 工业化
  • 智能制造三阶段：数字化制造 → 数字化网络化制造 → 数字化网络化智能化制造
  • 国家战略背景：「中国制造 2025」
11数字经济两条腿
  • 数字产业化（数字技术本身成产业）：电子信息制造、软件、通信、互联网
  • 产业数字化（数字技术赋能传统产业）：工业互联网、智能制造、数字农业、数字金融
  • 关键指标：数字经济核心产业增加值占 GDP 比重
辨析：「工业互联网」作为产品供给时归数字产业化；作为赋能能力时归产业数字化 —— 看题干落脚点
总结区 本章本质 + 考点地图
本章本质：信息化背景术语 + 政策框架；上午 2~4 题，不出大题、不进论文主线。
考点地图（按考频排序）：① 信息 7 属性（含场景配对）→ ② 国家信息化体系六要素（龙头/核心任务）→ ③ 新基建三大类 + 信息基础设施三小类 → ④ 工业互联网四大定位 + 平台四层级 → ⑤ 数字经济两条腿 → ⑥ 信息系统三结合 + 生命周期 5 阶段 → ⑦ 香农定义、组织信息化 4 大趋势、两化融合。
⚠️ 口径陷阱：①信息系统是「三结合」非「人机一体化」；②工业互联网「四大定位」非「三大体系」；③组织信息化按「4 大趋势」非「5 层次」；④系统分析→逻辑模型、系统设计→物理模型。

1.4.1 数字经济
1数字经济定位与本质
  • 定位：继农业经济、工业经济之后的更高级经济形态
  • 本质：是一种新的技术经济范式，建立在信息与通信技术重大突破的基础上；是以数字技术与实体经济融合驱动的产业梯次转型和经济创新发展的主引擎
  • 与农业 / 工业经济的差异体现在 4 方面：基础设施、生产要素、产业结构、治理结构
  • 技术经济范式结构 = 驱动力、新结构、价值创造、经济增长
「范式」由库恩在《科学革命的结构》中定义，多西引入技术创新提出「技术范式」。新形态举例：平台经济 / 分享经济 / 算法经济 / 服务经济 / 协同经济
2两种构成口径（最高频）
  • 产业构成：数字产业化 + 产业数字化（两大部分）
  • 整体构成：数字产业化 + 产业数字化 + 数字化治理 + 数据价值化（四部分）
  • 《数字经济及其核心产业统计分类（2021）》5 类：数字产品制造业、数字产品服务业、数字技术应用业、数字要素驱动业、数字化效率提升业
归属规则：前 4 类 = 数字产业化；第 5 类（数字化效率提升业）= 产业数字化
3数字产业化 与 产业数字化
  • 数字产业化：为产业数字化发展提供数字技术、产品、服务、基础设施和解决方案，以及完全依赖数字技术、数据要素的各类经济活动；含电子信息制造业、电信业、软件、信息技术、互联网行业；是数字经济的 基础部分
  • 数字产业化发展重点 8 项：云计算、大数据、物联网、工业互联网、区块链、人工智能、虚拟现实和增强现实
  • 产业数字化：以数据为关键要素、以价值释放为核心、以数据赋能为主线，对产业链上下游全要素数字化升级、转型和再造
  • 十四五抓手：「上云用数赋智」行动，推动数据赋能全产业链协同转型
6 条典型特征 →工要产市生机：数字科技变革生产工具 / 数据资源为关键生产要素 / 数字内容重构产品结构 / 信息网络为市场配置纽带 / 服务平台为产业生态载体 / 数字善治为发展机制条件
4数字化治理 与 数据价值化
  • 数字化治理核心特征：全社会的数据互通、数字化全面协同与跨部门的流程再造，形成「用数据说话、用数据决策、用数据管理、用数据创新」的治理机制
  • 内涵至少三方面：对数据的治理 / 运用数据进行治理 / 对数字融合空间进行治理
  • 数据资源化：基础，本质 = 提升数据质量，形成数据使用价值
  • 数据资产化：核心，本质 = 形成数据交换价值（通过流通交易带来经济利益）
  • 数据资本化：途径，本质 = 实现数据要素社会化配置；两种方式 = 数据信贷融资 + 数据证券化
⚠️ 别把「核心」安到资本化头上：资源=基础=使用价值 → 资产=核心=交换价值 → 资本=途径=社会化配置
1.4.2 数字政府
5数字政府定义
  • 以新一代信息技术为支撑，「业务数据化、数据业务化」为着力点
  • 通过数据驱动重塑政务信息化管理架构、业务架构、组织架构
  • 形成「用数据决策、数据服务、数据创新」的现代化治理模式
两组「三连」别串：着力点 = 业务数据化 / 数据业务化；目标 = 用数据决策 / 服务 / 创新
6五大新特征 + 三关键词
  • 协同化：组织互联互通，跨层级、地域、部门、系统、业务「五跨」协同
  • 云端化：云平台是政府数字化最基本的技术要求；政务上云 = 分散建设 → 集群集约式，整体转型的必要条件
  • 智能化：应对治理多元参与、环境复杂、内容多样化的关键手段
  • 数据化：现阶段建设的重点，建立在政务数据整合共享基础上
  • 动态化：数据驱动下动态发展、不断演进的过程
  • 关键词三：共享（数字政府数据先行，数据共享是效能抓手）/ 互通（打破地域阻隔与部门壁垒）/ 便利（利企便民，根本目标是服务企业与群众）
特征口诀 协云智数动；关键词口诀 享通便——两套完全不同，别混成一锅
7主要内容三件事
  • 一网通办：依托一体化在线政务服务平台，搭建统一的互联网政务服务总门户；企业群众办事线上只登录一次即可全网通办
  • 跨省通办：异地提出申请办理；模式 = 全程网办、代收代办、多地联办
  • 一网统管：从城市治理突出问题出发，以城市事件为牵引，统筹管理网格，构建多级城市运行应用体系；实现态势感知、体征指标监测、统一事件受理、智能调度指挥、联动协同处置、监督评价考核全流程监管
一网统管五要点 → 网屏联预创：一网（政务云 / 政务网 / 政务大数据中心）、一屏（多部门数据整合）、联动（跨部门区域层级）、预警（多维海量全息数据）、创新（管理需求带动智能化建设）
1.4.3 数字社会
8数字民生三重点
  • 普惠：扩大民生保障覆盖范围，解决民生资源配置不均衡
  • 赋能：与民生深度融合赋予新动能，促进民生保障实效指数式增长（互联网+教育 / 医疗 / 养老 / 交通）
  • 利民：拓展公共服务场景，使民生服务日趋智慧化、便利化和人性化
口诀 普赋利（普惠 / 赋能 / 利民）——注意与数字政府关键词「共享 / 互通 / 便利」区分
9智慧城市：五要素 / 全生命周期 / 五位一体
  • 五个核心能力要素：数据治理、数字孪生、边际决策、多元融合、态势感知
  • 全生命周期管理五阶段：规划设计、部署实施、运营管理、评估改进、创新发展
  • 「五位一体」高质量发展：城市治理、民生服务、生态宜居、产业经济、精神文明
  • 基本原理另两条：强调「人民城市为人民」，以面向政府、企业、市民提供服务为主要模式；持续推动城市治理体系与治理能力现代化
要素速记 数孪边多态：数据治理（责权利管控）/ 数字孪生（社会·城市·设备孪生）/ 边际决策（强化执行端决策）/ 多元融合（服务可编排与快速集成）/ 态势感知（可变与不可见因素）
10智慧城市成熟度五级
  • 规划级：围绕发展进行策划，明确职责分工与工作机制，初步开展数据采集和应用
  • 管理级：明确战略 / 原则 / 目标 / 实施计划，推进城市基础设施智能化改造，多领域实现信息系统单项应用，对全生命周期实施管理
  • 协同级：实施多业务、多层级、跨领域应用系统的集成，持续推进信息资源共享与交换，实现跨领域协同改进
  • 优化级：与城市经济社会发展深度融合，基于数据与知识模型实施精准化治理，推动数据要素价值挖掘
  • 引领级：构建敏捷发展能力，实现物理空间、社会空间、信息空间融合演进与共生共治，引领城市集群治理联动，形成高质量发展共同体
⚠️ 最大防坑：智慧城市 = 规划 / 管理 / 协同 / 优化 / 引领；智能制造 = 规划 / 规范 / 集成 / 优化 / 引领。城市管「管理·协同」，制造管「规范·集成」
1.4.4 数字生态
11数据要素市场
  • 双重属性：数据作为新型生产要素，具有劳动工具和劳动对象的双重属性；作为劳动对象经采集 / 加工 / 存储 / 流通 / 分析具备价值与使用价值，作为劳动工具通过融合应用提升生产效能
  • 定义：将尚未完全由市场配置的数据要素转向由市场配置的动态过程
  • 目的：形成以市场为根本调配机制，实现数据流动的价值或数据在流动中产生价值
  • 保障制度：数据产权、交易机制、定价机制、分配机制、监管机制、法律范围
  • 核心环节：数据流通
原话考点：数据要素市场化配置是一种「结果」，而不是「手段」——因为它建立在上述六项保障制度之上
12数字营商环境 + 网络安全保护
  • 全球数字营商环境评价指标体系（国家工业信息安全发展研究中心 2021.12 提出）5 个一级指标：数字支撑体系（普遍接入 / 智慧物流设施 / 电子支付设施）、数据开发利用与安全（公共数据开放 / 数据安全）、数字市场准入（业态准入 / 政务服务便利度）、数字市场规则（平台企业责任 / 商户权利与责任 / 数字消费者保护）、数字创新环境（创新生态 / 数字素养与技能 / 知识产权保护）
  • 网络安全三法一条例：《网络安全法》《数据安全法》《个人信息保护法》 + 《关键信息基础设施安全保护条例》
  • 标准体系：网络安全等级保护 2.0；关键判断：强大的网络安全产业实力是保障网络空间安全的根本和基石
营商环境五指标口诀 支撑 → 安全 → 准入 → 规则 → 创新（先有网 → 再保数据 → 再进门 → 再立规 → 最后创新）
总结区 本节本质 + 考点地图
本节本质：数字中国是国家战略层总纲，四个落地领域（数字经济 / 数字政府 / 数字社会 / 数字生态）；上午约 1 题，主流题型是「下列属于 X 的是」的归属 / 关键词配对。
考点地图（按考频排序）：① 数据价值化「三化」地位与本质 → ② 智慧城市成熟度五级（规划 / 管理 / 协同 / 优化 / 引领）→ ③ 数字经济构成两种口径 + 统计分类 5 类归属 → ④ 数字政府五特征 + 三关键词 + 一网通办 / 跨省通办 / 一网统管 → ⑤ 智慧城市五核心能力要素 → ⑥ 数字民生三重点（普惠 / 赋能 / 利民）→ ⑦ 数据要素市场（结果不是手段、双重属性）→ ⑧ 营商环境 5 指标 + 三法一条例。
⚠️ 口径陷阱：①智慧城市五级 ≠ 智能制造成熟度五级（第二、三级「管理·协同」vs「规范·集成」）；②「核心」是数据资产化不是资本化；③统计分类前 4 类属数字产业化、第 5 类属产业数字化；④数字政府特征（协云智数动）≠ 关键词（共享 / 互通 / 便利）≠ 数字民生（普惠 / 赋能 / 利民）；⑤数据要素市场化配置是「结果」不是「手段」；⑥数据具有劳动工具 + 劳动对象双重属性。

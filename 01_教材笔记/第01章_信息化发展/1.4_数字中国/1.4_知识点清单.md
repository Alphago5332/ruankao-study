## 一、必背清单

### 模块 A ｜ 数字中国总论

- [ ] **A0 · 数字中国定位**（引言，常作为题干背景）
  数字中国是新时代国家信息化发展的**新战略**，是满足人民日益增长的美好生活需要的**新举措**，是驱动引领经济高质量发展的**新动力**
  - 涵盖：**经济、政治、文化、社会、生态**等各领域信息化建设
  - 主要包括：**宽带中国、互联网+、大数据、云计算、人工智能、数字经济、电子政务、新型智慧城市、数字乡村**
  - 主旋律：「迎接数字时代，**激活数据要素潜能**，推进**网络强国**建设，加快建设**数字经济、数字社会、数字政府**，以数字化转型整体驱动**生产方式、生活方式和治理方式**变革」
  > 记法：主旋律 = 「三数字 + 三方式」——数字经济/社会/政府，生产/生活/治理方式

### 模块 B ｜ 数字经济（1.4.1）

- [ ] **B1 · 数字经济定位与本质** ⭕ 常考
  数字经济是继**农业经济、工业经济**之后的**更高级经济形态**
  - 本质：是一种**新的技术经济范式**，建立在**信息与通信技术**重大突破的基础上
  - 是**以数字技术与实体经济融合驱动的产业梯次转型和经济创新发展的主引擎**
  - 在**基础设施、生产要素、产业结构和治理结构**四方面表现出与农业经济、工业经济显著不同的新特点
  > ⚠️ 别写成「继信息经济、知识经济之后」——教材口径就是农业经济、工业经济
- [ ] **B2 · 范式概念（通读，防冷门题）**
  **库恩**在《**科学革命的结构**》中首先定义「**范式**」；**多西**把该概念引入技术创新，提出「**技术范式**」
  数字经济的技术经济范式的结构 = **驱动力、新结构、价值创造、经济增长**
  - 常见经济新形态：**平台经济、分享经济、算法经济、服务经济、协同经济**
- [ ] **B3 · 两种构成口径（本节最高频考点）** ⭕ 必考
  | 口径 | 构成 |
  |---|---|
  | **从产业构成看** | **数字产业化** + **产业数字化**（两大部分） |
  | **从整体构成看** | **数字产业化** + **产业数字化** + **数字化治理** + **数据价值化**（四部分） |
  | 《数字经济及其核心产业统计分类（2021）》 | 5 类：**数字产品制造业、数字产品服务业、数字技术应用业、数字要素驱动业、数字化效率提升业** |
  > **归属规则**：前 **4** 类 = **数字产业化**部分；第 **5** 类（**数字化效率提升业**）= **产业数字化**部分
- [ ] **B4 · 数字产业化** ⭕ 必考
  定义：为**产业数字化发展提供数字技术、产品、服务、基础设施和解决方案**，以及**完全依赖数字技术、数据要素**的各类经济活动
  - 包括：**电子信息制造业、电信业、软件、信息技术、互联网行业**等
  - 地位：**数字经济的基础部分**
  - **发展重点 8 项**：**云计算、大数据、物联网、工业互联网、区块链、人工智能、虚拟现实和增强现实**
  > 口诀：**云物大 工区 人虚**（云计算、物联网、大数据 / 工业互联网、区块链 / 人工智能、虚拟现实和增强现实）
  > 常考干扰项：智慧农业、数字田园、智能网联汽车（这些不是 1.4.1 列的 8 个重点）
- [ ] **B5 · 产业数字化** ⭕ 必考
  定义：在**新一代数字科技**支撑和引领下，以**数据为关键要素**，以**价值释放为核心**，以**数据赋能为主线**，对产业链上下游的**全要素数字化升级、转型和再造**的过程
  - 地位：是实现**数字经济和传统经济深度融合发展**的重要途径，是新时代使用数字经济发展的**必由之路和战略抉择**
  - 十四五抓手：实施「**上云用数赋智**」行动，推动数据赋能**全产业链协同转型**
  - **典型特征 6 条**：
  | # | 表述 | 记忆钩 |
  |---|---|---|
  | 1 | 以**数字科技**变革**生产工具** | 工具 |
  | 2 | 以**数据资源**为关键**生产要素** | 要素 |
  | 3 | 以**数字内容**重构**产品结构** | 产品 |
  | 4 | 以**信息网络**为**市场配置纽带** | 市场 |
  | 5 | 以**服务平台**为**产业生态载体** | 生态 |
  | 6 | 以**数字善治**为**发展机制条件** | 机制 |
  > 口诀：**工要产市生机**（工具 / 要素 / 产品 / 市场 / 生态 / 机制），每句都是「以 A 为 B」的句式——A 是手段，B 是对象
- [ ] **B6 · 数字化治理** ⭕ 常考
  定义：依托**互联网、大数据、人工智能**等技术和应用，**创新社会治理方法与手段，优化社会治理模式**，推进社会治理的**科学化、精细化、高效化**，助力社会治理现代化
  - 包括但不限于：**多元治理**、以「**信息技术+治理**」为典型特征的**技管结合**、**数字化公共服务**
  - **核心特征**：全社会的**数据互通**、**数字化全面协同**与**跨部门的流程再造**，形成「**用数据说话、用数据决策、用数据管理、用数据创新**」的治理机制
  - **内涵至少包含**：① **对数据的治理**；② **运用数据进行治理**；③ **对数字融合空间进行治理**
  > 记法：「三用数据」= 说话 / 决策 / 管理 / 创新（四用），别漏「创新」
- [ ] **B7 · 数据价值化** ⭕ 必考
  包括但不限于：数据采集、数据标准、**数据确权**、数据标注、**数据定价**、**数据交易**、数据流转、数据保护
  - 定义：以**数据资源化**为起点，经历**数据资产化、数据资本化**阶段，实现数据价值化的经济过程
  - **「三化」框架**（地位 + 本质必须一一对上）：
  | 阶段 | 地位 | 本质 | 关键内容 |
  |---|---|---|---|
  | **数据资源化** | **基础** | 提升**数据质量**，形成**数据使用价值** | 使无序、混乱的原始数据成为有序、有使用价值的数据资源；通过采集、整理、聚合、分析，形成**可采、可见、标准、互通、可信**的高质量数据资源 |
  | **数据资产化** | **核心** | 形成**数据交换价值** | 数据通过**流通交易**给使用者或所有者带来经济利益的过程 |
  | **数据资本化** | **途径** | 实现**数据要素社会化配置** | 两种方式：**数据信贷融资**与**数据证券化** |
  > 口诀：**资源=基础=使用价值 → 资产=核心=交换价值 → 资本=途径=社会化配置**
  > ⚠️ 易错：「核心」是**资产化**不是资本化；「交换价值」对应**资产化**，「使用价值」对应**资源化**

### 模块 C ｜ 数字政府（1.4.2）

- [ ] **C1 · 定义** ⭕ 必背
  数字政府通常是指以**新一代信息技术**为支撑，以「**业务数据化、数据业务化**」为**着力点**，通过**数据驱动**重塑政务信息化**管理架构、业务架构和组织架构**，形成「**用数据决策、数据服务、数据创新**」的**现代化治理模式**
  > 三个抓手别搞混：着力点 = 业务数据化 / 数据业务化；重塑 = 管理 / 业务 / 组织三架构；形成 = 用数据决策 / 服务 / 创新
- [ ] **C2 · 五大新特征** ⭕ 必考
  | 特征 | 关键词 |
  |---|---|
  | **协同化** | 强调组织的**互联互通**；实现跨**层级、地域、部门、系统、业务**（五跨）的高效协同管理和服务 |
  | **云端化** | **云平台**是政府数字化**最基本的技术要求**；政务上云 = 由**分散建设**向**集群集约式**规划与建设演化，是政府整体转型的**必要条件** |
  | **智能化** | 政府应对**社会治理多元参与、治理环境越发复杂、治理内容多样化**趋势的关键手段 |
  | **数据化** | 现阶段数字政府建设的**重点**；建立在**政务数据整合共享**基础上的数字化转型 |
  | **动态化** | 数字政府是在**数据驱动下动态发展、不断演进**的过程 |
  > 口诀：**协云智数动**（协同 / 云端 / 智能 / 数据 / 动态）
- [ ] **C3 · 建设关键词三** ⭕ 常考
  ① **共享**：推动政务数据共享，推进政务服务事项集成化办理；「**数字政府，数据先行**」，数据共享是提升政务服务效能的重要抓手
  ② **互通**：国家政务服务平台持续推动与各地区、各部门政务业务办理系统**全面对接融合**，**打破地域阻隔与部门壁垒**
  ③ **便利**：「数字政府，**利企便民**」；加强数字政府建设的**根本目标是更好地服务企业和群众**
- [ ] **C4 · 主要内容三件事** ⭕ 必考
  《「十四五」国家信息化规划》提出打造**协同高效的数字政府服务体系**；从面向社会大众政务服务视角看，重点体现在：
  | 事项 | 定位 | 要点 |
  |---|---|---|
  | **一网通办** | 政务服务网上办理 | 依托**一体化在线政务服务平台**，规范网上办事标准、优化流程、搭建统一的**互联网政务服务总门户**、整合政府服务数据资源和完善配套制度；企业群众办事**线上只登录一次即可全网通办** |
  | **跨省通办** | 异地办理 | 申请人在办理地之外的省市提出事项申请，或本地提出办理其他省市事项申请；办理模式 = **全程网办、代收代办、多地联办** |
  | **一网统管** | **城市治理** | 从城市治理突出问题出发，以**城市事件**为牵引，统筹管理网格，统一城市运行事项清单，构建**多级城市运行「一网统管」应用体系**；实现城市运行**态势感知、体征指标监测、统一事件受理、智能调度指挥、联动协同处置、监督评价考核**等全流程监管 |
  > **一网统管建设强调五点**：**一网**（政务云 / 政务网 / 政务大数据中心）、**一屏**（多部门数据整合，反映城市运行情况）、**联动**（跨部门、跨区域、跨层级联勤联动）、**预警**（多维、海量、全息数据汇集，智能预警）、**创新**（以管理需求带动智能化建设）
  > 记法：**一网一屏、联动预警创新**（网屏联预创）

### 模块 D ｜ 数字社会（1.4.3）

- [ ] **D1 · 数字民生建设三重点** ⭕ 必背
  | 重点 | 关键词 |
  |---|---|
  | **普惠** | 充分开发利用信息技术体系，**扩大民生保障覆盖范围**，助力普惠型民生建设，解决**民生资源配置不均衡**等问题 |
  | **赋能** | 信息技术体系与民生**深度融合**赋予民生建设**新动能**，促进民生保障实效**指数式增长**（互联网+教育 / 医疗 / 养老 / 交通） |
  | **利民** | 创新**拓展公共服务场景**，推动数字技术**全面融入社会交往和日常生活**，使民生服务日趋**智慧化、便利化和人性化** |
  > 口诀：**普赋利**（普惠 / 赋能 / 利民）
- [ ] **D2 · 智慧城市定义**（理解）
  智慧城市是**运用信息通信技术**，有效**整合各类城市管理系统**，实现城市各系统间**信息资源共享和业务协同**，推动城市**管理和服务智慧化**，提升城市运行管理和公共服务水平，提高城市居民**幸福感和满意度**，实现**可持续发展**的一种创新型城市
- [ ] **D3 · 智慧城市基本原理五条** ⭕ 常考
  ① 强调「**人民城市为人民**」，以面向**政府、企业、市民**等主体提供智慧化服务为主要模式
  ② 重点强化**数据治理、数字孪生、边际决策、多元融合、态势感知**五个核心能力要素建设
  ③ 更加注重**规划设计、部署实施、运营管理、评估改进、创新发展**在内的智慧城市**全生命周期管理**
  ④ 目标旨在推动**城市治理、民生服务、生态宜居、产业经济、精神文明**「**五位一体**」的高质量发展
  ⑤ 持续推动**城市治理体系与治理能力现代化**水平提升
- [ ] **D4 · 五个核心能力要素** ⭕ 必考（解释要能对上）
  | 要素 | 围绕什么构建 | 关键表述 |
  |---|---|---|
  | **数据治理** | **数据这一新的生产要素** | 数据**责权利管控**、全生命周期管理及其开发利用 |
  | **数字孪生** | **现实世界与信息世界的互动融合** | **社会孪生、城市孪生、设备孪生**；推动城市空间摆脱物理约束，进入数字空间 |
  | **边际决策** | **决策算法和信息应用** | 强化**执行端**的决策能力，快速反应、高效决策，满足对社会发展的**敏捷需求** |
  | **多元融合** | **社会关系和社会活动的动态性及融合的高效性** | 实现**服务可编排和快速集成** |
  | **态势感知** | **对社会状态的本质反映及模拟预测** | 洞察**可变因素与不可见因素**对社会发展的影响 |
  > 口诀：**数孪边多态**（数据治理 / 数字孪生 / 边际决策 / 多元融合 / 态势感知）
  > ⚠️「边际决策」= 把决策权**下沉到执行端**（edge decision），不是「边缘计算」
- [ ] **D5 · 智慧城市成熟度五等级** ⭕ 必考
  | 等级 | 名称 | 关键特征 |
  |---|---|---|
  | 一级 | **规划级** | 围绕智慧城市发展进行**策划**，明确相关**职责分工和工作机制**；初步开展**数据采集和应用** |
  | 二级 | **管理级** | 明确智慧城市发展**战略、原则、目标和实施计划**；推进**城市基础设施智能化改造**；多领域实现**信息系统单项应用**；对**全生命周期实施管理** |
  | 三级 | **协同级** | 管控各项发展目标；实施**多业务、多层级、跨领域应用系统的集成**；持续推进**信息资源共享与交换**；推动**惠民服务、城市治理、生态宜居、产业发展**等融合创新，实现**跨领域协同改进** |
  | 四级 | **优化级** | 聚焦智慧城市与城市经济社会发展**深度融合**；基于**数据与知识模型**实施城市经济、社会**精准化治理**；推动**数据要素的价值挖掘和开发利用** |
  | 五级 | **引领级** | 构建智慧城市**敏捷发展能力**；实现城市**物理空间、社会空间、信息空间**的**融合演进和共生共治**；引领**城市集群治理联动**，形成**高质量发展共同体** |
  > ⚠️⚠️ **本节最大防坑点**：智慧城市五级 = **规划 / 管理 / 协同 / 优化 / 引领**；智能制造五级 = **规划 / 规范 / 集成 / 优化 / 引领**——**第二、三级名称不同**！
  > 一眼区分法：**城市讲「管理、协同」**（管人管事管资源），**制造讲「规范、集成」**（管装备管系统）
- [ ] **D6 · 数字乡村** ⭕ 常考
  数字乡村是伴随**网络化、信息化和数字化**在农业农村经济社会发展中的应用，以及**农民现代信息技能**的提高而**内生**的农业农村现代化发展和转型进程
  > 两个定位：既是**乡村振兴的战略方向**，也是**建设数字中国的重要内容**
- [ ] **D7 · 数字生活三方面**（通读，能答出三个小标题即可）
  ① **生活工具数字化**（智能手机等；依据**摩尔定律**与**梅特卡夫定律**，技术成本下降、价值增加）
  ② **生活方式数字化**（工作更弹性化自主化、终身学习与随时随地学习、网络购物成主流消费方式、人际交往范围无限扩大；**数字家庭**是未来家庭发展趋势）

### 模块 E ｜ 数字生态（1.4.4）

- [ ] **E0 · 总纲** ⭕ 常考
  《「十四五」规划和 2035 年远景目标纲要》指出：「**坚持放管并重，促进发展与规范管理相统一，构建数字规则体系，营造开放、健康、安全的数字生态**」
  - 营造良好数字生态的意义：激发数字技术的**创新活力、要素潜能、发展空间**，引领和驱动**经济结构调整、产业发展升级、消费需求增长、治理格局优化**
  > 教材 1.4.4 的三个小标题 = **数据要素市场 / 数字营商环境 / 网络安全保护**
- [ ] **E1 · 数据要素市场** ⭕ 必考
  - 数据的**双重属性**：数据作为新型生产要素，具有**劳动工具和劳动对象的双重属性**
    - 作为**劳动对象**：通过**采集、加工、存储、流通、分析**环节，具备了**价值和使用价值**
    - 作为**劳动工具**：通过**融合应用**能够**提升生产效能**，促进生产力发展
  - 定义：数据要素市场就是将**尚未完全由市场配置**的数据要素转向**由市场配置**的**动态过程**
  - 目的：形成以**市场为根本调配机制**，实现**数据流动的价值**或者**数据在流动中产生价值**
  - ⚠️ **数据要素市场化配置是一种「结果」，而不是「手段」**（原文表述，原话考点）
  - 保障制度：明确的**数据产权、交易机制、定价机制、分配机制、监管机制、法律范围**
  - 各环节关注点：采集（准确度、全面性）/ 储存（安全性、调用实时性）/ 加工（精度）/ **流通（核心环节，合理合规流通）** / 分析（深度挖掘）/ 应用（产生价值、降低成本）
  > 记法：保障制度六项 —— **产权、交易、定价、分配、监管、法律**
- [ ] **E2 · 数字营商环境** ⭕ 必考
  良好营商环境是**国家或地区经济软实力和综合竞争力**的重要体现；要打造**市场化、法治化、国际化、便利化**的营商环境
  - 《「十四五」数字经济发展规划》（2022 年 1 月）提出：**更加优化数字营商环境，加速弥合数字鸿沟**
  - **国家工业信息安全发展研究中心**（2021 年 12 月）提出**全球数字营商环境评价指标体系**，含 **5 个一级指标**：
  | # | 一级指标 | 包含内容 |
  |---|---|---|
  | 1 | **数字支撑体系** | **普遍接入**、智慧物流设施、电子支付设施 |
  | 2 | **数据开发利用与安全** | **公共数据开放**、数据安全 |
  | 3 | **数字市场准入** | 数字经济业态市场准入、**政务服务便利度** |
  | 4 | **数字市场规则** | 平台企业责任、商户权利与责任、**数字消费者保护** |
  | 5 | **数字创新环境** | 数字创新生态、数字素养与技能、**知识产权保护** |
  > 口诀：**支撑 → 安全 → 准入 → 规则 → 创新**（先有网、再保数据、再进门、再立规矩、最后谈创新）
- [ ] **E3 · 网络安全保护** ⭕ 常考（法规名称要背）
  随着 **《中华人民共和国网络安全法》《中华人民共和国数据安全法》《中华人民共和国个人信息保护法》《关键信息基础设施安全保护条例》** 等法律法规颁布，以及 **网络安全等级保护 2.0 标准体系**发布，我国网络安全法律法规和制度标准更加健全
  - 形势：国际环境日趋复杂，**网络霸权主义**对世界和平与发展构成威胁；网络空间对抗趋势突出，**安全漏洞、数据泄露、网络诈骗**等风险增加
  - 对策：坚持**总体国家安全观**和**正确的网络安全观**，构建**网络安全新格局**，全面加强网络安全保障体系和能力建设
  - 关键判断：**强大的网络安全产业实力是保障网络空间安全的根本和基石**
  - 总书记指示：「要坚持**网络安全教育、技术、产业融合发展**，形成**人才培养、技术创新、产业发展**的良性生态」
  > 记法：**三法一条例** + 等保 2.0

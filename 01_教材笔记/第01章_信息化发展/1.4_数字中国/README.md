## 学习目标

- [ ] 掌握**数字经济两种构成口径**：产业构成（数字产业化 / 产业数字化）+ 整体构成（+ 数字化治理 + 数据价值化）；能判《数字经济及其核心产业统计分类（2021）》5 类的归属
- [ ] 背熟**数据价值化「三化」**：数据资源化（基础 / 使用价值）→ 数据资产化（核心 / 交换价值）→ 数据资本化（途径 / 数据要素社会化配置）
- [ ] 背熟**数字政府五大新特征**（协同 / 云端 / 智能 / 数据 / 动态）+ 建设三关键词（共享 / 互通 / 便利）+ 主要内容三件事
- [ ] 掌握**智慧城市五个核心能力要素**（数据治理 / 数字孪生 / 边际决策 / 多元融合 / 态势感知）与**成熟度五级**（规划 / 管理 / 协同 / 优化 / 引领）
- [ ] 记住**数字生态**三块要点：数据要素市场（「结果不是手段」+ 数据双重属性）/ 数字营商环境 5 个一级指标 / 网络安全三法一条例 + 等保 2.0

## 易混防坑

- **智慧城市成熟度五级**（规划 / **管理 / 协同** / 优化 / 引领）≠ **智能制造成熟度五级**（规划 / **规范 / 集成** / 优化 / 引领）——第二、三级名称不同，本节最大陷阱
- 数字政府**新特征**（协同化 / 云端化 / 智能化 / 数据化 / 动态化）≠ **建设关键词**（共享 / 互通 / 便利）≠ **数字民生三重点**（普惠 / 赋能 / 利民）——三套名词同章出现，极易串行
- 数据价值化的「**核心**」是**数据资产化**（交换价值），不是资本化；资本化是「途径」（社会化配置）
- 《统计分类（2021）》5 类中，**前 4 类属数字产业化**，只有第 5 类（**数字化效率提升业**）属**产业数字化**
- 数据要素市场化配置是「**结果**」不是「**手段**」（原文原话）
- 数据作为新型生产要素具有**劳动工具 + 劳动对象双重属性**（不是「使用价值 + 交换价值」）

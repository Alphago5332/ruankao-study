6.3 项目经理的角色 · 知识点清单

教材：《信息系统项目管理师教程（第 4 版）》第 6 章第 3 节（P196 ~ P201）
学习日：2026-10-26（Day 20）
上午分值：本章综合知识约 3~5 题，本节常出 1 题左右（定义辨析 / 权力类型 / 领导力风格配对）；但「三类技能 + 权力 + 领导力」是论文写作的人设基础——写论文时你就是那个「平衡三种技能、主动寻求权力、按情境切换领导风格」的项目经理
本节定位：人物角色章。高频块：三经理辨析 / 影响力范围五层面 / 三类关键技能「项·战·领」/ 权力 14 种表现形式 / 六种领导力风格
⚠️ 口径提醒：① 本节与 PMBOK 同源，旧教辅常考的「情商（EI）五要素」在第 4 版教材 6.3 没有独立小节（相关表述仅在「个性特征」中的『情绪』『社会』），刷旧题注意甄别；② 「PMI 人才三角」的新版叫法（工作方式 Ways of Working / 商业敏锐度 / 权力技能）是 PMI 2022 年培训口径，教材本节用的仍是老三角叫法：项目管理技能、战略和商务管理技能、领导力技能——以教材为准；③ 教材明确权力要在组织政策、协议和程序许可范围内主动寻求，不是坐等组织授权

今日目标（学完要能做到）

  1. 默写项目经理的定义：由执行组织委派，负责领导团队实现项目目标
  2. 三经理辨析：项目经理 / 职能经理（职能领域或业务部门的管理监督）/ 运营经理（业务运营的高效性）
  3. 列出影响力范围五个层面：项目、组织、行业、专业学科、跨领域
  4. 说清项目层面的角色：沟通者 + 软技能平衡冲突达成共识（共识 ≠ 100% 赞同）；非正式人际网络比正式的更重要
  5. 列出组织层面与其他项目互相影响的 4 个原因 + 项目经理对组织的 3 项贡献
  6. 说清行业 / 专业学科 / 跨领域层面各自做什么（关注趋势 / 知识传递与整合 / 非正式宣传大使）
  7. 默写三类关键技能「项·战·领」及各自定义，说清「需平衡三种技能」
  8. 列出顶尖项目经理的 4 条关键技能（关注关键要素 / 裁剪工具方法 / 制订完整计划排优先级 / 管理制约因素）
  9. 说清战略和商务管理技能的内涵与商业因素（NPV、ROI 等成本效益分析）
  10. 列出领导力技能六项：协商、抗压、沟通、解决问题、批判性思考、人际关系；记住「人际交往占据项目经理工作的绝大部分」
  11. 配对权力 14 种表现形式中的高频 6 种：地位（= 正式 / 权威 / 合法）、专家、参考、情境、奖励、处罚
  12. 说清管理 vs 领导力的教材定义差异，列出六种领导力风格及各自特点（放任 / 交易 / 服务 / 变革 / 魅力 / 交互）

一、必背清单

模块 A ｜ 项目经理的定义（6.3.1）

项目经理由执行组织委派，负责领导团队实现项目目标。

• 三个关键词：执行组织委派（不是自封、不是团队选举）、领导团队（不是单打独斗）、实现项目目标（对目标负责）
很多项目经理从项目启动时参与项目，直到项目结束；教材总述：项目经理在领导项目团队达成项目目标方面发挥着至关重要的作用
角色核心职责记忆锚点
项目经理由执行组织委派，领导团队实现项目目标对「项目」负责
职能经理专注于对某个职能领域或业务部门的管理监督对「部门」负责
运营经理负责保证业务运营的高效性对「日常运转效率」负责
出题套路：给一句职责描述反问是谁——「保证业务运营的高效性」→ 运营经理；「职能领域或业务部门的管理监督」→ 职能经理

模块 B ｜ 项目经理的影响力范围（6.3.2）

项目经理在其影响力范围内可担任多种角色（反映能力、体现价值和作用），涉及 5 个层面：

项目 → 组织 → 行业 → 专业学科 → 跨领域

记法：「项 · 组 · 行 · 专 · 跨」（由内向外扩散）；判断题常拿「五个层面」里的具体行为让你反配层面
• 领导项目团队实现项目目标和干系人期望，利用可用资源，平衡相互竞争的制约因素
• 承担项目发起人、团队成员与其他干系人之间的沟通者，提供指导、展示项目成功的愿景和目标
• 使用软技能（人际关系技能、人员管理技能）平衡干系人相互冲突和竞争的目标，以达成共识
• ⚠️ 共识的教材定义：即便不能做到 100% 赞同，干系人也会支持项目的决定和行动
高频陷阱：「共识 = 全体一致同意」❌——教材明确共识不要求 100% 赞同
• 正式人际网络：如组织架构图
• 非正式人际网络：与专家和具有影响力的领导者建立的个人人际关系
• 教材明确：项目经理发展、维护和培养的非正式人际网络更加重要
出题套路：「项目经理拓展人际网络，最重要的是维护组织架构图体现的正式关系」→ 判错
• 与组织内其他项目经理积极互动——其他项目可能因以下原因影响本项目：① 对相同资源的需求 ② 资金分配的优先顺序 ③ 可交付成果的接受或发布 ④ 项目与组织战略和目标的一致性
• 项目经理对组织的贡献（还应）：① 展现项目管理的价值 ② 提高组织对项目管理的接受度 ③ 提高组织内现有 PMO 的效率
• 汇报关系：可能向职能经理报告，也可能与其他项目经理一起向 PMO、项目组合或项目集经理报告；某些情况下可以是临时被委任的外部顾问
记法：4 原因「资源 · 资金 · 成果 · 战略」；3 贡献「展价值 · 提接受 · 提 PMO」

项目经理应时刻关注行业的最新发展趋势，获取并判断这些信息对当前项目的影响。趋势包括：产品和技术开发、新兴且正在变化的市场空间、标准（项目管理 / 质量管理 / 信息安全管理标准等）、技术支持工具、影响当前项目的经济力量、影响项目管理学科的各种力量、过程改进和可持续发展战略等

抓「关注 → 获取 → 判断影响」三步；高频：问「关注行业趋势属于项目经理影响力范围的哪个层面」→ 行业层面
• 专业学科：持续的知识传递和整合非常重要——向其他专业人员分享知识和专业技能（实践社区、国际组织）；参与培训、继续教育和发展（项目管理专业、相关专业、其他专业）
• 跨领域：指导和教育其他专业人员（生产、市场、销售、财务等）了解项目管理方法对组织的价值；可担任非正式的宣传大使，宣传项目管理在按时交付、质量、创新和资源管理方面的优势
记法：专业学科 = 对「同行」分享知识 + 终身学习；跨领域 = 对「外行」宣传教育 + 非正式宣传大使

模块 C ｜ 三类关键技能（6.3.3）

项目经理需重点关注三个方面的关键技能，这些技能有助于支持更长远的战略目标、实现盈利；为最有效地开展工作，项目经理需要平衡这三种技能：

技能教材定义帮助达成
项目管理技能与项目、项目集和项目组合管理特定领域相关的知识、技能和行为帮助达成项目目标
战略和商务管理技能关于行业和组织的知识和专业技能有助于提高绩效并取得更好的业务成果
领导力技能指导、激励和带领团队所需的知识、技能和行为可以帮助组织达成业务目标
⚠️ 这是教材口径（PMI 人才三角老叫法）——别选「工作方式 / 商业敏锐度 / 权力技能」的新叫法；三技能答题锚点：项目目标 / 业务成果 / 业务目标

项目管理技能指有效运用项目管理知识实现项目集或项目的预期成果的能力（项目经理经常依赖专家判断来有效开展工作）。顶尖的项目经理往往具备：

• ① 重点关注并随之准备好所管理各项目的关键项目管理要素：项目成功的关键因素、进度表、指定的财务报告和问题日志
• ② 针对每个项目裁剪，有选择地使用传统工具、敏捷工具、技术、方法
• ③ 花时间制订完整计划并谨慎排定优先顺序
• ④ 管理项目制约因素：进度、成本、资源、风险等
记法：「盯要素 · 会裁剪 · 定计划 · 控制约」；「关键项目管理要素」四件 = 成功关键因素 / 进度表 / 财务报告 / 问题日志

战略和商务管理技能包括了解组织概况、有效协商，以及执行有利于战略调整和创新的决策及行动的能力。这些知识可以帮助项目经理：向其他人解释关于项目的必要商业信息；与项目发起人、团队和专家合作制定合适的项目交付策略；以实现项目业务价值最大化的方式执行策略。

• 了解得越多越好，可向干系人说明：组织战略、使命、项目目标、产品和服务；运营情况；市场和市场条件；竞争等信息
• 商业因素包括：风险和问题、财务影响、成本效益分析（净现值 NPV、投资回报率 ROI 等，含各种可选方案）、业务价值、效益预期实现情况和战略、范围 / 预算 / 进度 / 质量等
高频：NPV、ROI 这类「成本效益分析」出现在本技能的商业因素里——与 6.2.3 项目成功标准的财务指标呼应，别混章节

模块 D ｜ 领导力技能（6.3.3.4）

领导力即能指导、激励和带领团队的能力，项目经理需要运用领导力技能与所有项目干系人进行合作。这些技能（教材列举）包括：

协商、抗压、沟通、解决问题、批判性思考和人际关系技能等

记法：「协抗沟解批人」六项；出题常给五个对的 + 混入一个不属于的（如「投资决策」「市场推广」）让你排除
• 人际交往占据项目经理工作的绝大部分；项目经理需要研究人的行为和动机，尽力成为一个好的领导者
• 应注意自己与他人的关系，借助人际关系让项目相关事项得到落实
高频判断：「项目经理最主要的工作是技术攻关」❌——是人际交往

领导者的品质和技能主要包括：心有远见（描述项目的产品、目的和目标，构建梦想并诠释愿景）、积极乐观、乐于合作；通过特定方式管理关系和冲突（建立信任、解决顾虑、寻求共识、平衡相互竞争和对立的目标、运用说服 / 协商 / 妥协和解决冲突的技能）；花大量时间沟通、管理期望、诚恳接受反馈、提出建设性意见；尊重他人、诚信正直和文化敏感性、果断、勇敢；终身学习、以结果和行动为导向、关注重要的事情（持续优化工作、区分战略优先级、对主要制约因素保持警惕）；创建高效团队、以服务为导向、展现幽默等

抓关键词答题即可，不必逐字背全表；高频考「心有远见（愿景）」「建立信任」「终身学习」

模块 E ｜ 政策与权力（6.3.3.4）

权力体现个人或组织的特征；权力的表现形式包括：

高频 6 种教材括注（例子）
地位有时称为正式的、权威的、合法的——组织或团队授予的正式职位
专家拥有的技能和信息、经验、培训、教育、证书
参考因为他人的尊重和赞赏而获得的信任
情境在危机等特殊情况下获得的权力
奖励相关能够给予表扬、金钱或其他奖励
处罚或强制力给予纪律处分或施加负面后果的能力

其余 8 种：信息（对信息收集或分发的控制）、个性或魅力、关系（人际交往、联系和结盟）、迎合（恭维等常用手段赢得青睐）、施加压力、引发愧疚、说服力、回避（拒绝参与）等

记法：高频 6 种「位 · 专 · 参 · 情 · 奖 · 罚」；最高频辨析 = 地位 ↔ 正式 / 权威 / 合法（同一权力的别称）；参考权力来自他人尊重（不是自己有魅力——那是「个性或魅力」）

在权力方面，卓越的项目经理积极主动且目的明确：会在组织政策、协议和程序许可的范围内，主动寻求所需的权力和职权，而不是坐等组织授权（更不是越权行事）

高频判断：「项目经理的权力只能由组织正式授予，应被动等待授权」❌——教材强调主动寻求

模块 F ｜ 领导力与管理、领导力风格（6.3.3.5）

教材定义
管理指挥一个人执行一系列已知的预期行为，从一个位置到另一个位置
领导力通过讨论或辩论方式与他人合作，带领他们从一个位置到另一个位置
• 「领导力」不等同于「管理」；为获得成功，项目经理必须同时采用领导力和管理两种方式，针对不同的情况找到恰当的平衡点
记法：管理 = 指挥 + 已知行为；领导力 = 讨论辩论 + 与人合作；高频错项「领导力关注近期目标 / 可操作性问题」——领导力关注长远愿景，近期可操作性问题属管理范畴

项目经理会根据个人偏好，或综合考虑与项目有关的 4 个因素后，选择并调整适合自己的领导力风格：

① 领导者的特点（态度、心情、需求、价值观、道德观）② 团队成员的特点（同上）③ 组织的特点（目标、结构、工作类型）④ 环境特点（社会形势、经济状况和政策因素）

记法：「领 · 员 · 组 · 环」；注意「选择并调整」——风格不是一成不变
风格核心特点记忆锚点
放任型允许团队自主决策和设定目标又被称为「无为而治型」
交易型根据目标、反馈和成就给予奖励「按绩给奖」
服务型做出服务承诺，处处先为他人着想；关注他人的成长、学习、发展、自主性和福利；关注人际关系、团体与合作服务优先于领导
变革型通过理想化特质和行为、鼓舞性激励、促进创新和创造、个人关怀，提高追随者的能力「四件套：理想·鼓舞性激励·促创新·个人关怀」
魅力型能够激励他人；精神饱满、热情洋溢、充满自信；说服力强「个人魅力」
交互型结合了交易型、变革型和魅力型领导的特点「三合一」
高频陷阱：「关注他人的成长、学习、发展、自主性和福利」是服务型，不是放任型也不是变革型；交互型 = 交易 + 变革 + 魅力（不含服务型）

二、只通读（低频扫盲）

产品和技术开发 / 新兴且正在变化的市场空间 / 标准（项目管理、质量管理、信息安全管理标准）/ 技术支持工具 / 影响当前项目的经济力量 / 影响项目管理学科的各种力量 / 过程改进和可持续发展战略——选择题偶尔给一两个让你判断「属于行业层面的关注内容」，抓「技术、市场、标准、工具、经济」几个代表词即可

组织战略、使命、项目目标、产品和服务 / 运营情况（类型、技术等）/ 市场和市场条件（客户、市场状况（发展或萎缩）、上市时间因素等）/ 竞争（竞争什么、与谁竞争、市场地位）——通读留印象，考「商业因素」别漏「范围、预算、进度和质量」也属商业因素

个性指人与人之间在思维、情感、行为的特征模式方面的差异。个性特征包括：真诚、谦恭、创造力（抽象思维、不同看法、创新的能力等）、文化、情绪、智力、管理、以服务为导向、社会（能够理解和管理他人）、系统化（了解和构建系统的驱动力）

第 4 版教材 6.3 没有 PMBOK 那种「情商 / 情绪能力（EI）五要素（自我意识 / 自我调节 / 内在动机 / 同理心 / 社交技能）」独立小节——相关内容仅零散出现在个性特征（情绪、社会）与领导者品质（文化敏感性）中。旧教辅或旧真题考「情商五要素」时按 PMBOK 口径，教材内考以本节清单为准；同理「PMI 新人才三角（工作方式 / 商业敏锐度 / 权力技能）」是 PMI 2022 培训口径，教材仍用「项·战·领」老三角

三、自检题（合上清单，口答）

点击展开自检参考答案
  1. 项目经理的定义？由谁委派？

答：由执行组织委派，负责领导团队实现项目目标。

  1. 职能经理与运营经理各自的职责？

答：职能经理 = 对某个职能领域或业务部门的管理监督；运营经理 = 保证业务运营的高效性。

  1. 项目经理的影响力范围有哪五个层面？

答：项目、组织、行业、专业学科、跨领域（「项·组·行·专·跨」）。

  1. 项目层面，教材给「共识」下的定义是什么？

答：即便不能做到 100% 赞同，干系人也会支持项目的决定和行动——共识 ≠ 全体一致同意。

  1. 正式人际网络与非正式人际网络，哪个更重要？非正式的例子？

答：非正式的更重要；正式如组织架构图，非正式 = 与专家和具有影响力的领导者建立的个人人际关系。

  1. 组织层面，其他项目影响本项目的 4 个原因？

答：对相同资源的需求 / 资金分配的优先顺序 / 可交付成果的接受或发布 / 项目与组织战略和目标的一致性。

  1. 项目经理对组织的 3 项贡献？

答：展现项目管理的价值 / 提高组织对项目管理的接受度 / 提高组织内现有 PMO 的效率。

  1. 跨领域层面，项目经理扮演什么角色？宣传什么优势？

答：担任非正式的宣传大使；宣传项目管理在按时交付、质量、创新和资源管理方面的优势。

  1. 三类关键技能是哪三类？需怎样使用？

答：项目管理技能、战略和商务管理技能、领导力技能（「项·战·领」）；需平衡三种技能（支持更长远的战略目标、实现盈利）。

  1. 顶尖项目经理的 4 条关键项目管理技能？

答：关注关键项目管理要素（成功关键因素 / 进度表 / 财务报告 / 问题日志）/ 针对每个项目裁剪（传统 + 敏捷工具）/ 制订完整计划并排定优先顺序 / 管理项目制约因素。

  1. 领导力技能包括哪六项？哪项占据工作的绝大部分？

答：协商、抗压、沟通、解决问题、批判性思考、人际关系技能；人际交往占据绝大部分，需研究人的行为和动机。

  1. 权力的 6 种高频表现形式？「地位」又叫什么？

答：地位、专家、参考、情境、奖励相关、处罚或强制力；地位 = 正式的、权威的、合法的（正式职位）。

  1. 「参考权力」从哪来？「情境权力」从哪来？

答：参考 = 因他人的尊重和赞赏而获得的信任；情境 = 危机等特殊情况下获得的权力。

  1. 卓越的项目经理如何对待权力？

答：在组织政策、协议和程序许可的范围内主动寻求权力和职权，而不是坐等组织授权。

  1. 教材分别如何定义「管理」和「领导力」？

答：管理 = 指挥一个人执行一系列已知的预期行为从一个位置到另一个位置；领导力 = 通过讨论或辩论方式与他人合作，带领他们从一个位置到另一个位置。

  1. 选择领导力风格要综合考虑哪 4 个因素？

答：领导者的特点 / 团队成员的特点 / 组织的特点 / 环境特点（「领·员·组·环」）。

  1. 六种领导力风格？「关注他人的成长、学习、发展、自主性和福利」是谁？交互型结合了哪三种？

答：放任（无为而治）/ 交易（按绩给奖）/ 服务 / 变革 / 魅力 / 交互；该描述是服务型（服务优先于领导）；交互型 = 交易 + 变革 + 魅力。

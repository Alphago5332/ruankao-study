## 小节结构

- **6.3.1 项目经理的定义**（P196~197）：PM 由执行组织委派、领导团队实现项目目标；与职能经理（职能领域 / 业务部门的管理监督）、运营经理（业务运营的高效性）辨析
- **6.3.2 项目经理的影响力范围**（P197~198）：五层面「项 · 组 · 行 · 专 · 跨」——项目（沟通者 / 软技能 / 共识）、组织（4 影响 + 3 贡献）、行业（关注趋势）、专业学科（知识传递整合）、跨领域（非正式宣传大使）
- **6.3.3 项目经理的能力**（P199~201）：
  - 三类关键技能「项 · 战 · 领」（项目管理 / 战略和商务 / 领导力，需平衡）
  - 项目管理技能（顶尖 PM 4 条关键技能）、战略和商务管理技能（商业因素：NPV / ROI 等）
  - 领导力技能（六项「协抗沟解批人」+ 人际交往占绝大部分 + 领导者品质）
  - 政策与权力（14 种表现形式，高频 6 种「位专参情奖罚」；组织许可范围内主动寻求）
  - 领导力与管理（教材定义辨析）+ 六种领导力风格（放任 / 交易 / 服务 / 变革 / 魅力 / 交互）+ 个性特征

## 学习目标

1. 默写项目经理定义，做对「三经理辨析」配对题
2. 列出影响力范围五层面并能给具体行为反配层面
3. 默写三类关键技能「项 · 战 · 领」及各自「帮助达成什么」（项目目标 / 业务成果 / 业务目标）
4. 配对权力高频 6 种（地位 = 正式权威合法；参考 = 他人尊重；情境 = 危机）
5. 配对六种领导力风格（服务型「先为他人着想」、交互 = 交易 + 变革 + 魅力、放任 = 无为而治）
6. 说清管理 vs 领导力的教材定义，避开「领导力关注近期目标」错误项

## 易混 / 防坑

- **地位 ↔ 正式 / 权威 / 合法**：同一权力的别称，不是四种权力；「参考权力」来自**他人尊重**，不是自己的魅力（那是「个性或魅力」权力）
- **共识 ≠ 100% 赞同**：教材定义是「即便不能 100% 赞同，干系人也支持项目的决定和行动」
- **非正式人际网络比正式（组织架构图）更重要**
- **权力要主动寻求**：在组织政策、协议和程序许可范围内，而非坐等授权、更非越权
- **管理 vs 领导力**：管理 = 指挥已知预期行为；领导力 = 讨论辩论合作带领；**须并用找平衡**；「领导力关注近期目标 / 可操作性问题」是错误项（那是管理）
- **风格配对三陷阱**：「关注他人成长学习发展自主性福利」= **服务型**（不是变革型 / 放任型）；交互型 = 交易 + 变革 + 魅力（**不含服务型**）；「精神饱满热情洋溢充满自信」= 魅力型
- **组织层面 4 影响原因**：资源 / 资金优先顺序 / 成果接受或发布 / 战略一致性——「团队成员个人爱好」不在列
- **旧题甄别**：教材 6.3 **无「情商五要素」独立小节**（相关表述仅在个性特征的「情绪」「社会」中）；「PMI 新人才三角（工作方式 / 商业敏锐度 / 权力技能）」是 PMI 2022 培训口径，教材仍用老三角「项 · 战 · 领」

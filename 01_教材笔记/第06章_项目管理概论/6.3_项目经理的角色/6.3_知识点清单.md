## 一、必背清单

### 模块 A ｜ 项目经理的定义（6.3.1）

- [ ] **A0 · 项目经理的定义** ⭕ 必背（本节起点）
  **项目经理由执行组织委派，负责领导团队实现项目目标。**
  - 三个关键词：**执行组织委派**（不是自封、不是团队选举）、**领导团队**（不是单打独斗）、**实现项目目标**（对目标负责）
  > 很多项目经理从项目启动时参与项目，直到项目结束；教材总述：项目经理在领导项目团队达成项目目标方面发挥着**至关重要的作用**
- [ ] **A1 · 三经理辨析** ⭕ 必背（高频配对）
  | 角色 | 核心职责 | 记忆锚点 |
  |---|---|---|
  | **项目经理** | 由执行组织委派，**领导团队实现项目目标** | 对「项目」负责 |
  | **职能经理** | 专注于对某个**职能领域或业务部门的管理监督** | 对「部门」负责 |
  | **运营经理** | 负责**保证业务运营的高效性** | 对「日常运转效率」负责 |
  > 出题套路：给一句职责描述反问是谁——「保证业务运营的高效性」→ 运营经理；「职能领域或业务部门的管理监督」→ 职能经理

### 模块 B ｜ 项目经理的影响力范围（6.3.2）

- [ ] **B0 · 影响力范围五层面** ⭕ 必背（总览，必考清单）
  项目经理在其影响力范围内可担任**多种角色**（反映能力、体现价值和作用），涉及 5 个层面：
  **项目 → 组织 → 行业 → 专业学科 → 跨领域**
  > 记法：**「项 · 组 · 行 · 专 · 跨」**（由内向外扩散）；判断题常拿「五个层面」里的具体行为让你反配层面
- [ ] **B1 · 项目层面：沟通者 + 软技能达成共识** ⭕ 必背（行为细节）
  - **领导**项目团队实现项目目标和干系人期望，利用可用资源，**平衡相互竞争的制约因素**
  - 承担**项目发起人、团队成员与其他干系人之间的沟通者**，提供指导、展示项目成功的愿景和目标
  - 使用**软技能**（人际关系技能、人员管理技能）平衡干系人相互冲突和竞争的目标，**以达成共识**
  - ⚠️ **共识的教材定义**：即便不能做到 **100% 赞同**，干系人也会**支持项目的决定和行动**
  > 高频陷阱：「共识 = 全体一致同意」❌——教材明确共识**不要求 100% 赞同**
- [ ] **B2 · 人际网络：非正式比正式更重要** ⭕ 必背（反向陷阱）
  - 正式人际网络：如**组织架构图**
  - **非正式人际网络**：与**专家**和**具有影响力的领导者**建立的个人人际关系
  - 教材明确：项目经理发展、维护和培养的**非正式人际网络更加重要**
  > 出题套路：「项目经理拓展人际网络，最重要的是维护组织架构图体现的正式关系」→ 判错
- [ ] **B3 · 组织层面：4 个影响原因 + 3 项贡献** ⭕ 必背（两个小清单）
  - 与组织内其他项目经理积极互动——其他项目可能因以下原因影响本项目：**① 对相同资源的需求 ② 资金分配的优先顺序 ③ 可交付成果的接受或发布 ④ 项目与组织战略和目标的一致性**
  - 项目经理对组织的贡献（还应）：**① 展现项目管理的价值 ② 提高组织对项目管理的接受度 ③ 提高组织内现有 PMO 的效率**
  - 汇报关系：可能向**职能经理**报告，也可能与其他项目经理一起向 **PMO、项目组合或项目集经理**报告；某些情况下可以是**临时被委任的外部顾问**
  > 记法：4 原因「**资源 · 资金 · 成果 · 战略**」；3 贡献「**展价值 · 提接受 · 提 PMO**」
- [ ] **B4 · 行业层面：关注最新发展趋势** ⭕ 必背（定位句）
  项目经理应**时刻关注行业的最新发展趋势**，获取并**判断这些信息对当前项目的影响**。趋势包括：**产品和技术开发、新兴且正在变化的市场空间、标准**（项目管理 / 质量管理 / 信息安全管理标准等）、**技术支持工具、影响当前项目的经济力量、影响项目管理学科的各种力量、过程改进和可持续发展战略**等
  > 抓「**关注 → 获取 → 判断影响**」三步；高频：问「关注行业趋势属于项目经理影响力范围的哪个层面」→ **行业层面**
- [ ] **B5 · 专业学科与跨领域层面** ⭕ 必背（两个层面一起记）
  - **专业学科**：**持续的知识传递和整合非常重要**——向其他专业人员分享知识和专业技能（实践社区、国际组织）；**参与培训、继续教育和发展**（项目管理专业、相关专业、其他专业）
  - **跨领域**：指导和教育**其他专业人员**（生产、市场、销售、财务等）了解项目管理方法对组织的价值；可担任**非正式的宣传大使**，宣传项目管理在**按时交付、质量、创新和资源管理**方面的优势
  > 记法：专业学科 = 对「同行」分享知识 + 终身学习；跨领域 = 对「外行」宣传教育 + 非正式宣传大使

### 模块 C ｜ 三类关键技能（6.3.3）

- [ ] **C0 · 三类关键技能「项 · 战 · 领」** ⭕ 必背（本节核心，必背表）
  项目经理需重点关注三个方面的关键技能，这些技能有助于支持**更长远的战略目标、实现盈利**；为最有效地开展工作，项目经理需要**平衡**这三种技能：
  | 技能 | 教材定义 | 帮助达成 |
  |---|---|---|
  | **项目管理技能** | 与项目、项目集和项目组合管理**特定领域相关**的知识、技能和行为 | 帮助达成**项目目标** |
  | **战略和商务管理技能** | 关于**行业和组织**的知识和专业技能 | 有助于**提高绩效**并取得更好的**业务成果** |
  | **领导力技能** | **指导、激励和带领团队**所需的知识、技能和行为 | 可以帮助组织达成**业务目标** |
  > ⚠️ 这是**教材口径（PMI 人才三角老叫法）**——别选「工作方式 / 商业敏锐度 / 权力技能」的新叫法；三技能答题锚点：**项目目标 / 业务成果 / 业务目标**
- [ ] **C1 · 项目管理技能与顶尖 PM 的 4 条关键技能** ⭕ 必背（列举）
  **项目管理技能指有效运用项目管理知识实现项目集或项目的预期成果的能力**（项目经理经常依赖**专家判断**来有效开展工作）。顶尖的项目经理往往具备：
  - ① 重点关注并随之准备好所管理各项目的**关键项目管理要素**：**项目成功的关键因素、进度表、指定的财务报告和问题日志**
  - ② 针对每个项目**裁剪**，有选择地使用**传统工具、敏捷工具、技术、方法**
  - ③ 花时间制订**完整计划**并谨慎**排定优先顺序**
  - ④ 管理**项目制约因素**：进度、成本、资源、风险等
  > 记法：**「盯要素 · 会裁剪 · 定计划 · 控制约」**；「关键项目管理要素」四件 = 成功关键因素 / 进度表 / 财务报告 / 问题日志
- [ ] **C2 · 战略和商务管理技能与商业因素** ⭕ 必背（定义 + 清单）
  **战略和商务管理技能包括了解组织概况、有效协商，以及执行有利于战略调整和创新的决策及行动的能力**。这些知识可以帮助项目经理：向其他人解释关于项目的必要商业信息；与项目发起人、团队和专家合作制定合适的项目交付策略；**以实现项目业务价值最大化的方式执行策略**。
  - 了解得越多越好，可向干系人说明：**组织战略、使命、项目目标、产品和服务；运营情况；市场和市场条件；竞争**等信息
  - **商业因素**包括：**风险和问题、财务影响、成本效益分析（净现值 NPV、投资回报率 ROI 等，含各种可选方案）、业务价值、效益预期实现情况和战略、范围 / 预算 / 进度 / 质量**等
  > 高频：NPV、ROI 这类「成本效益分析」出现在本技能的**商业因素**里——与 6.2.3 项目成功标准的财务指标呼应，别混章节

### 模块 D ｜ 领导力技能（6.3.3.4）

- [ ] **D0 · 领导力技能的定义与六项** ⭕ 必背（定义 + 配对）
  **领导力即能指导、激励和带领团队的能力**，项目经理需要运用领导力技能与**所有项目干系人**进行合作。这些技能（教材列举）包括：
  **协商、抗压、沟通、解决问题、批判性思考和人际关系技能**等
  > 记法：**「协抗沟解批人」**六项；出题常给五个对的 + 混入一个不属于的（如「投资决策」「市场推广」）让你排除
- [ ] **D1 · 人际交往占据绝大部分** ⭕ 必背（金句）
  - **人际交往占据项目经理工作的绝大部分**；项目经理需要**研究人的行为和动机**，尽力成为一个好的领导者
  - 应注意自己与他人的关系，**借助人际关系**让项目相关事项得到落实
  > 高频判断：「项目经理最主要的工作是技术攻关」❌——是**人际交往**
- [ ] **D2 · 领导者的品质和技能** ⭕ 必背（关键词群）
  领导者的品质和技能主要包括：**心有远见**（描述项目的产品、目的和目标，构建梦想并诠释愿景）、**积极乐观、乐于合作**；通过特定方式**管理关系和冲突**（**建立信任**、解决顾虑、寻求共识、平衡相互竞争和对立的目标、运用说服 / 协商 / 妥协和解决冲突的技能）；**花大量时间沟通**、管理期望、诚恳接受反馈、提出建设性意见；**尊重他人**、诚信正直和文化敏感性、果断、勇敢；**终身学习**、以**结果和行动为导向**、关注重要的事情（持续优化工作、区分战略优先级、对主要制约因素保持警惕）；创建高效团队、以服务为导向、展现幽默等
  > 抓关键词答题即可，不必逐字背全表；高频考「心有远见（愿景）」「建立信任」「终身学习」

### 模块 E ｜ 政策与权力（6.3.3.4）

- [ ] **E0 · 权力的 14 种表现形式** ⭕ 必背（6 高频 + 8 眼熟）
  权力体现**个人或组织的特征**；权力的表现形式包括：
  | 高频 6 种 | 教材括注（例子） |
  |---|---|
  | **地位** | 有时称为**正式的、权威的、合法的**——组织或团队授予的**正式职位** |
  | **专家** | 拥有的**技能和信息、经验、培训、教育、证书** |
  | **参考** | 因为**他人的尊重和赞赏**而获得的**信任** |
  | **情境** | 在**危机等特殊情况**下获得的权力 |
  | **奖励相关** | 能够给予**表扬、金钱或其他奖励** |
  | **处罚或强制力** | 给予**纪律处分或施加负面后果**的能力 |
  其余 8 种：**信息**（对信息收集或分发的控制）、**个性或魅力**、**关系**（人际交往、联系和结盟）、**迎合**（恭维等常用手段赢得青睐）、**施加压力**、**引发愧疚**、**说服力**、**回避**（拒绝参与）等
  > 记法：高频 6 种「**位 · 专 · 参 · 情 · 奖 · 罚**」；最高频辨析 = **地位 ↔ 正式 / 权威 / 合法**（同一权力的别称）；**参考权力**来自他人尊重（不是自己有魅力——那是「个性或魅力」）
- [ ] **E1 · 主动寻求权力** ⭕ 必背（反向陷阱）
  在权力方面，卓越的项目经理**积极主动且目的明确**：会在**组织政策、协议和程序许可的范围内，主动寻求**所需的权力和职权，**而不是坐等组织授权**（更不是越权行事）
  > 高频判断：「项目经理的权力只能由组织正式授予，应被动等待授权」❌——教材强调**主动寻求**

### 模块 F ｜ 领导力与管理、领导力风格（6.3.3.5）

- [ ] **F0 · 「管理」与「领导力」的教材定义** ⭕ 必背（两句对照，必考辨析）
  | | 教材定义 |
  |---|---|
  | **管理** | 指挥一个人执行**一系列已知的预期行为**，从**一个位置到另一个位置** |
  | **领导力** | 通过**讨论或辩论方式与他人合作**，带领他们从**一个位置到另一个位置** |
  - **「领导力」不等同于「管理」**；为获得成功，项目经理必须**同时采用**领导力和管理**两种方式**，针对不同的情况找到**恰当的平衡点**
  > 记法：管理 = **指挥** + 已知行为；领导力 = **讨论辩论** + 与人合作；高频错项「领导力关注近期目标 / 可操作性问题」——领导力关注**长远愿景**，近期可操作性问题属管理范畴
- [ ] **F1 · 领导力风格的选择因素** ⭕ 必背（4 因素）
  项目经理会根据个人偏好，或综合考虑与项目有关的 4 个因素后，**选择并调整**适合自己的领导力风格：
  **① 领导者的特点**（态度、心情、需求、价值观、道德观）**② 团队成员的特点**（同上）**③ 组织的特点**（目标、结构、工作类型）**④ 环境特点**（社会形势、经济状况和政策因素）
  > 记法：**「领 · 员 · 组 · 环」**；注意「选择并调整」——风格不是一成不变
- [ ] **F2 · 六种领导力风格** ⭕ 必背（配对表，最高频）
  | 风格 | 核心特点 | 记忆锚点 |
  |---|---|---|
  | **放任型** | 允许团队**自主决策和设定目标** | 又被称为「**无为而治型**」 |
  | **交易型** | 根据**目标、反馈和成就**给予**奖励** | 「按绩给奖」 |
  | **服务型** | 做出服务承诺，**处处先为他人着想**；关注他人的**成长、学习、发展、自主性和福利**；关注人际关系、团体与合作 | **服务优先于领导** |
  | **变革型** | 通过**理想化特质和行为、鼓舞性激励、促进创新和创造、个人关怀**，提高追随者的能力 | 「四件套：理想·鼓舞性激励·促创新·个人关怀」 |
  | **魅力型** | 能够激励他人；**精神饱满、热情洋溢、充满自信**；说服力强 | 「个人魅力」 |
  | **交互型** | **结合了交易型、变革型和魅力型**领导的特点 | 「三合一」 |
  > 高频陷阱：**「关注他人的成长、学习、发展、自主性和福利」是服务型**，不是放任型也不是变革型；**交互型 = 交易 + 变革 + 魅力**（不含服务型）

## 三、自检题（合上清单，口答）

<details>
<summary>点击展开自检参考答案</summary>

1. **项目经理的定义？由谁委派？**
   答：由**执行组织**委派，负责**领导团队实现项目目标**。
2. **职能经理与运营经理各自的职责？**
   答：职能经理 = 对某个**职能领域或业务部门的管理监督**；运营经理 = **保证业务运营的高效性**。
3. **项目经理的影响力范围有哪五个层面？**
   答：项目、组织、行业、专业学科、跨领域（「项·组·行·专·跨」）。
4. **项目层面，教材给「共识」下的定义是什么？**
   答：即便不能做到 **100% 赞同**，干系人也会**支持项目的决定和行动**——共识 ≠ 全体一致同意。
5. **正式人际网络与非正式人际网络，哪个更重要？非正式的例子？**
   答：**非正式的更重要**；正式如组织架构图，非正式 = 与**专家**和**具有影响力的领导者**建立的个人人际关系。
6. **组织层面，其他项目影响本项目的 4 个原因？**
   答：对相同资源的需求 / 资金分配的优先顺序 / 可交付成果的接受或发布 / 项目与组织战略和目标的一致性。
7. **项目经理对组织的 3 项贡献？**
   答：展现项目管理的价值 / 提高组织对项目管理的接受度 / 提高组织内现有 PMO 的效率。
8. **跨领域层面，项目经理扮演什么角色？宣传什么优势？**
   答：担任**非正式的宣传大使**；宣传项目管理在**按时交付、质量、创新和资源管理**方面的优势。
9. **三类关键技能是哪三类？需怎样使用？**
   答：项目管理技能、战略和商务管理技能、领导力技能（「项·战·领」）；需**平衡**三种技能（支持更长远的战略目标、实现盈利）。
10. **顶尖项目经理的 4 条关键项目管理技能？**
    答：关注关键项目管理要素（成功关键因素 / 进度表 / 财务报告 / 问题日志）/ 针对每个项目裁剪（传统 + 敏捷工具）/ 制订完整计划并排定优先顺序 / 管理项目制约因素。
11. **领导力技能包括哪六项？哪项占据工作的绝大部分？**
    答：协商、抗压、沟通、解决问题、批判性思考、人际关系技能；**人际交往**占据绝大部分，需研究**人的行为和动机**。
12. **权力的 6 种高频表现形式？「地位」又叫什么？**
    答：地位、专家、参考、情境、奖励相关、处罚或强制力；地位 = **正式的、权威的、合法的**（正式职位）。
13. **「参考权力」从哪来？「情境权力」从哪来？**
    答：参考 = 因**他人的尊重和赞赏**而获得的**信任**；情境 = **危机等特殊情况**下获得的权力。
14. **卓越的项目经理如何对待权力？**
    答：在**组织政策、协议和程序许可的范围内主动寻求**权力和职权，而不是坐等组织授权。
15. **教材分别如何定义「管理」和「领导力」？**
    答：管理 = 指挥一个人执行**一系列已知的预期行为**从一个位置到另一个位置；领导力 = 通过**讨论或辩论**方式与他人合作，带领他们从一个位置到另一个位置。
16. **选择领导力风格要综合考虑哪 4 个因素？**
    答：领导者的特点 / 团队成员的特点 / 组织的特点 / 环境特点（「领·员·组·环」）。
17. **六种领导力风格？「关注他人的成长、学习、发展、自主性和福利」是谁？交互型结合了哪三种？**
    答：放任（无为而治）/ 交易（按绩给奖）/ 服务 / 变革 / 魅力 / 交互；该描述是**服务型**（服务优先于领导）；交互型 = **交易 + 变革 + 魅力**。

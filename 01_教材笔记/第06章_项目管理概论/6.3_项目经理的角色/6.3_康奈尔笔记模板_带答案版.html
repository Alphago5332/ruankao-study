6.3.1 项目经理的定义
1项目经理定义 + 三经理辨析
  • 项目经理由执行组织委派，负责领导团队实现项目目标——关键词：执行组织委派 / 领导团队 / 实现项目目标
  • 职能经理：专注于对某个职能领域或业务部门的管理监督（对「部门」负责）
  • 运营经理：负责保证业务运营的高效性（对「日常运转效率」负责）
  • 很多项目经理从项目启动时参与项目，直到项目结束
出题套路：给职责描述反问是谁——「业务运营的高效性」→ 运营经理；「职能领域 / 业务部门的管理监督」→ 职能经理
6.3.2 影响力范围
2五层面 + 项目层面角色
  • 影响力范围五层面（记法「项 · 组 · 行 · 专 · 跨」）：项目 → 组织 → 行业 → 专业学科 → 跨领域（由内向外扩散）
  • 项目层面：领导项目团队实现项目目标和干系人期望，利用可用资源平衡相互竞争的制约因素
  • 承担项目发起人、团队成员与其他干系人之间的沟通者；提供指导、展示项目成功的愿景和目标
  • 使用软技能（人际关系技能、人员管理技能）平衡干系人相互冲突和竞争的目标，以达成共识
  • ⚠️ 共识的教材定义：即便不能做到 100% 赞同，干系人也会支持项目的决定和行动
🚩 高频陷阱：「共识 = 全体一致同意」❌——教材明确不要求 100% 赞同
3人际网络 + 组织层面
  • 正式人际网络：如组织架构图；非正式 = 与专家和具有影响力的领导者建立的个人人际关系——教材明确非正式的更加重要
  • 组织层面，其他项目影响本项目 4 原因（记法「资源 · 资金 · 成果 · 战略」）：对相同资源的需求 / 资金分配的优先顺序 / 可交付成果的接受或发布 / 项目与组织战略和目标的一致性
  • PM 对组织的 3 项贡献（记法「展价值 · 提接受 · 提 PMO」）：展现项目管理的价值 / 提高组织对项目管理的接受度 / 提高组织内现有 PMO 的效率
  • 汇报关系：可能向职能经理报告，也可能与其他 PM 一起向 PMO、项目组合或项目集经理报告；某些情况下可以是临时被委任的外部顾问
🚩 「最重要的是维护组织架构图的正式关系」→ 判错，非正式人际网络更重要
4行业 / 专业学科 / 跨领域
  • 行业层面：时刻关注行业的最新发展趋势，获取并判断这些信息对当前项目的影响（产品和技术开发 / 新兴市场空间 / 标准 / 技术支持工具 / 经济力量 / 影响项目管理学科的力量 / 过程改进和可持续发展战略）
  • 专业学科层面：持续的知识传递和整合非常重要——向其他专业人员分享知识和专业技能（实践社区、国际组织）；参与培训、继续教育和发展
  • 跨领域层面：指导和教育其他专业人员（生产、市场、销售、财务等）了解项目管理方法对组织的价值；担任非正式的宣传大使，宣传项目管理在按时交付、质量、创新和资源管理方面的优势
记法：专业学科 = 对「同行」分享 + 终身学习；跨领域 = 对「外行」宣传教育 + 宣传大使
6.3.3 三类关键技能
5三类关键技能「项 · 战 · 领」
  • 项目经理需重点关注三个方面的关键技能，有助于支持更长远的战略目标、实现盈利；为最有效地开展工作，需平衡三种技能
  • 项目管理技能：与项目、项目集和项目组合管理特定领域相关的知识、技能和行为 → 帮助达成项目目标
  • 战略和商务管理技能：关于行业和组织的知识和专业技能 → 有助于提高绩效并取得更好的业务成果
  • 领导力技能：指导、激励和带领团队所需的知识、技能和行为 → 可以帮助组织达成业务目标
⚠️ 这是教材口径（PMI 人才三角老叫法）——别选「工作方式 / 商业敏锐度 / 权力技能」的新叫法
6项目管理技能 + 顶尖 PM 的 4 条
  • 项目管理技能 = 有效运用项目管理知识实现项目集或项目预期成果的能力；PM 经常依赖专家判断开展工作
  • ① 重点关注并准备好各项目的关键项目管理要素 = 项目成功的关键因素、进度表、指定的财务报告和问题日志（四件）
  • ② 针对每个项目裁剪，有选择地使用传统工具、敏捷工具、技术、方法
  • ③ 花时间制订完整计划并谨慎排定优先顺序
  • ④ 管理项目制约因素：进度、成本、资源、风险等
记法「盯要素 · 会裁剪 · 定计划 · 控制约」
7战略和商务管理技能 + 商业因素
  • 内涵：了解组织概况、有效协商，以及执行有利于战略调整和创新的决策及行动的能力
  • 帮助：向其他人解释项目的必要商业信息 / 与发起人、团队和专家合作制定合适的项目交付策略 / 以实现项目业务价值最大化的方式执行策略
  • 了解得越多越好：组织战略、使命、项目目标、产品和服务 / 运营情况 / 市场和市场条件 / 竞争
  • 商业因素：风险和问题 / 财务影响 / 成本效益分析（净现值 NPV、投资回报率 ROI 等，含各种可选方案） / 业务价值 / 效益预期实现情况和战略 / 范围、预算、进度和质量
NPV、ROI 这类「成本效益分析」属本技能的商业因素——与 6.2.3 成功标准的财务指标呼应，别混章节
6.3.3 领导力技能与权力
8领导力技能 + 人际交往
  • 领导力即能指导、激励和带领团队的能力；PM 需运用领导力技能与所有项目干系人合作
  • 六项技能（记法「协 · 抗 · 沟 · 解 · 批 · 人」）：协商、抗压、沟通、解决问题、批判性思考和人际关系技能
  • ⚠️ 人际交往占据项目经理工作的绝大部分；需研究人的行为和动机，尽力成为好的领导者
  • 借助人际关系让项目相关事项得到落实
高频判断：「PM 最主要的工作是技术攻关」❌——是人际交往；出题常给五对一错混入「投资决策」等不属于六项的
9权力 6 高频 + 主动寻求
  • 权力体现个人或组织的特征；高频 6 种（记法「位 · 专 · 参 · 情 · 奖 · 罚」）：
  • 地位 = 有时称为正式的、权威的、合法的（组织或团队授予的正式职位）；专家 = 技能和信息、经验、培训、教育、证书
  • 参考 = 因为他人的尊重和赞赏而获得的信任；情境 = 危机等特殊情况下获得的权力
  • 奖励相关 = 给予表扬、金钱或其他奖励；处罚或强制力 = 给予纪律处分或施加负面后果的能力
  • 其余 8 种：信息 / 个性或魅力 / 关系 / 迎合 / 施加压力 / 引发愧疚 / 说服力 / 回避
  • 卓越 PM 积极主动且目的明确：在组织政策、协议和程序许可的范围内主动寻求权力和职权，而不是坐等组织授权
🚩 最高频辨析：地位 ↔ 正式 / 权威 / 合法是同一权力的别称；「参考权力」来自他人尊重，不是自己的魅力
6.3.3 领导力与管理 · 风格与个性
10管理 vs 领导力 + 风格选择 4 因素
  • 管理：指挥一个人执行一系列已知的预期行为，从一个位置到另一个位置
  • 领导力：通过讨论或辩论方式与他人合作，带领他们从一个位置到另一个位置
  • 「领导力」不等同于「管理」；成功须同时采用两种方式，针对不同情况找到恰当的平衡点
  • 风格选择 4 因素（记法「领 · 员 · 组 · 环」）：领导者的特点 / 团队成员的特点 / 组织的特点 / 环境特点；风格要「选择并调整」
高频错项「领导力关注近期目标 / 可操作性问题」——领导力关注长远愿景，近期可操作性问题属管理范畴
11六种领导力风格
  • 放任型：允许团队自主决策和设定目标，又称「无为而治型」
  • 交易型：根据目标、反馈和成就给予奖励（按绩给奖）
  • 服务型：处处先为他人着想，关注他人的成长、学习、发展、自主性和福利；服务优先于领导
  • 变革型：四件套——理想化特质和行为、鼓舞性激励、促进创新和创造、个人关怀，提高追随者的能力
  • 魅力型：能够激励他人；精神饱满、热情洋溢、充满自信；说服力强
  • 交互型：结合了交易型、变革型和魅力型领导的特点（三合一，不含服务型）
🚩 「关注他人的成长、学习、发展、自主性和福利」是服务型，不是放任型 / 变革型——高频陷阱
12个性特征 + 旧题甄别
  • 个性 = 人与人之间在思维、情感、行为的特征模式方面的差异
  • 个性特征 10 项：真诚、谦恭、创造力（抽象思维、不同看法、创新的能力）、文化、情绪、智力、管理、以服务为导向、社会（能够理解和管理他人）、系统化（了解和构建系统的驱动力）
  • 旧题甄别：① 第 4 版教材 6.3 没有「情商（EI）五要素」独立小节（相关表述仅零散在个性特征的情绪、社会与领导者品质的文化敏感性）；② 「PMI 新人才三角（工作方式 / 商业敏锐度 / 权力技能）」是 PMI 2022 培训口径，教材本节仍用「项 · 战 · 领」老三角
刷软考达人旧真题见「情商五要素」类题：按其题库口径选，但教材内考以本节清单为准
总结区 本节本质 + 考点地图
本节本质：一篇「项目经理说明书」——PM 是谁（执行组织委派、带团队达目标）、影响谁（项目 / 组织 / 行业 / 专业学科 / 跨领域五层）、会什么（项 · 战 · 领三类技能要平衡）、靠什么推动人（14 种权力、组织许可内主动寻求）、怎么带人（管理 ≠ 领导力，六种风格按「领员组环」选择并调整）。上午约 1 题，但这是论文人设的地基——写论文时你就是这个平衡三技能、主动寻权、按情境切换风格的 PM。
考点地图（按考频排序）：① 六种领导力风格配对（服务型「先为他人着想」/ 交互型三合一 / 放任 = 无为而治）→ ② 权力高频 6 种（地位 = 正式权威合法、参考 = 他人尊重、情境 = 危机）→ ③ 三经理辨析（PM 委派带团队 / 职能管部门 / 运营管效率）→ ④ 三类关键技能「项战领」各自帮助达成什么（项目目标 / 业务成果 / 业务目标）→ ⑤ 管理 vs 领导力定义 → ⑥ 影响力五层面归属 → ⑦ 共识定义（≠ 100% 赞同）+ 非正式人际网络更重要 → ⑧ 顶尖 PM 4 条关键技能 → ⑨ 主动寻求权力 → ⑩ 商业因素（NPV / ROI）。
⚠️ 口径陷阱：①「地位」又叫正式 / 权威 / 合法权力；②「参考权力」来自他人尊重，不是个人魅力；③共识不要求 100% 赞同；④非正式人际网络比正式（组织架构图）更重要；⑤权力要主动寻求、在组织政策协议程序许可范围内；⑥管理 = 指挥已知预期行为，领导力 = 讨论辩论合作带领，两者须并用；⑦「关注他人成长发展自主性福利」是服务型不是变革型；⑧交互型 = 交易 + 变革 + 魅力，不含服务型；⑨教材无「情商五要素」独立小节、仍用 PMI 老三角「项战领」——旧题甄别。

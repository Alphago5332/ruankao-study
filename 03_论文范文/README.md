# 03_论文范文

论文范文、写作模板与素材积累。

## 论文考试要求

- 满分 75 分，及格 45 分
- 约 2500 字左右，机考写作
- 摘要 + 正文（项目背景、实践过程、总结）

## 高频方向（第 4 版）

- **绩效域**（2023 下第 2 批、2025 上均考过，重点）
- 十大知识领域：整合 / 范围 / 进度 / 成本 / 质量 / 资源 / 沟通 / 风险 / 采购 / 干系人

## 素材可用项目

- fault-simulator（仿真数据模拟系统）
- H3C-NMS（网络管理系统）

## 建议放这里

- `范文/` —— 历年高分范文
- `模板/` —— 论文写作框架模板
- `素材/` —— 个人项目素材、数据、案例
